Refs: https://linear.app/shel-bernstein/issue/SHE-403/joytouch-reversible-sandbox-interactions-with-one-step-undo

policy and actual WorkflowScreen dependencies before changes. GitHub search found
no Undo PR; open adjacent Joy/Touch draft PRs #129–134 cover motion, status,

## Implemented

Local Undo covers sample filters (including chips/reset), comparison additions,
removals/order, sponsor movement by pointer or dropdown, hypothetical household
presets/reset and synthesis sliders. The newest action replaces the prior record
and gets 20 seconds. Focus/hover pauses expiration; leaving renews the interval.
A polite atomic live region names restoration; the 44px button remains mounted
and focusable after use/expiry, with aria-disabled and a guarded handler. No global
shortcut intercepts typing. History is component-local and disappears on unmount.
Sponsor restoration preserves unrelated cards and refuses mismatched local state
or failed saves. Existing typed transitions and reduced-motion fallbacks remain.
Synthesis restoration invalidates stale requests and requests only preview=true.

No publication, advisory ballot, saved synthesis commit or governance operation
is registered with local Undo. No redo, server endpoints or persisted Undo history
were added. Real, synthetic, official and revision-bound comparison lanes remain
separate. Source/repository identities, PR head/base bindings, records and receipts
are unchanged. Existing explicit public journal Undo is separate and untouched.

## Validation

Focused component checks: 12 tests pass, including touch pointer movement/cancel
and restoration, rapid preset changes, focus-paused and expired Undo, comparison
removal restoration, empty/loading filter states, reduced motion and stale preview
requests. Household interaction verifies no network/storage. Typecheck passes.

Full `bun test`: 475 pass, 26 fail. Server integration tests fail to bind the local
server (`EADDRINUSE`, port 0) under this execution environment. `bun run test:routes`
fails on the same startup error. These required checks must pass in an environment
that permits the isolated server. No production data or listener was substituted.
Manual screen-reader, actual keyboard activation and physical touch-device review
remain pending; DOM pointer/focus checks do not establish those acceptance results.
