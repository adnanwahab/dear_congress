Implemented a first public catalog exhibit on `/account#exhibit-export`, linked
from existing shared desktop/More navigation. Both phone and wide SVGs include
all sample need goals, metrics and scopes, with equal styling in catalog-ID
order. Standalone responsive HTML provides equivalent text, and JSON binds

not arbitrary-route screenshot capture, live measured data or simulation output.

The exporter only reads explicitly projected built-in catalog fields. It accepts
no operational state, DOM, URLs, user text, PRs or ballots. Preparing an export
writes no application state, changes no settings, and performs no API call. New
exports clear old download URLs; errors expose an expandable copy/print fallback.
UI controls retain the civic theme and existing motion foundation. No duplicate
motion system, first-run demo or theme switch was introduced; exports are static
for reduced motion and low-power use. See [layout-snapshots.md](../layout-snapshots.md)
for format, reproducibility, limitations and manual checks.
