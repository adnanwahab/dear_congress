## Fallback and manual verification

1. On `/map`, choose **Use text-only county view**, pause playback, and use
   **Improve one revision** at your own pace. Use **Find a county** (name, state
   or FIPS) and the ordinary county buttons to inspect the same source, revision,
   thresholds and 0–100 commitments. Narrow searches with more than 60 matches.
   Legend buttons still filter; selection and denominators stay unchanged.
2. On Needs, open **Shared needs map values (text alternative)**. It remains
   available without map configuration, fonts, GPU or tiles. Rankings continue
   below the optional graphic. On Synthesize use jurisdiction priorities and the
   budget allocation table, which retain units and source limitations.
3. For the law comparison, pause playback and use the native time slider or open
   **Recorded chart values (text alternative)**. The table includes every recorded
   pair; no animation or hovering is required. Use actor inspection for identities.
4. Before printing, open the relevant text disclosures and clear any filters for
   the desired complete view. Print in grayscale with backgrounds both enabled
   and disabled. Even when backgrounds disappear, names, counts, units and tables
   remain the primary fallback. Narrow tables scroll with keyboard focus on screen.
5. Follow docs/accessibility-acceptance.md for VoiceOver/Safari or NVDA/Firefox,
   real keyboard and touch, actual 200% zoom, 390px, both themes, forced colors,
   reduced motion and a low-power device. Check each legend, pause/step, text-only
   toggle and draft-preserving navigation. Human screen-reader/device review is
   still required; simulated DOM tests do not establish acceptance.

Browser regression `tests/accessibility/chart-encodings.pw.ts` adds approximate
protanopia, deuteranopia, tritanopia and grayscale-print filters to the real county
page in all existing accessibility projects. It checks patterned states, names,
unchanged numeric data, keyboard graphic removal and touch county selection;
per-mode screenshots are attached for visual review. These matrices are review
aids, not clinical vision models. Run with the existing isolated accessibility
runner; never substitute production data or a live origin.
