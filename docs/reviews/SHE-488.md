## Behavior

Map and the six-stage workflow's Outcomes destination share a read-only comparison
panel. It defaults to No comparable data because no verified pair is connected.
Explicit opt-in loads fictional examples with policy definitions/effective dates,
observation windows, source revision/record identities, metric definitions, units,
populations, sampling, confounders and illustrative lessons. Source links identify
the repository fixture, never a real institution as evidence for invented results.
The fixture is separate from measured outcomes, synthesis and persistent data.

Definitions, methods and confounders appear before numeric results. Differences
in definitions, units, population, sampling or observation periods, missing values,
nonfinite values or missing provenance withhold numeric comparison. Equal metadata
does not establish genuine comparability. Every result remains descriptive with
causal attribution unestablished; no ranking, proven-effect statement or inferred
policy success is produced. No resident data, location inference or external write
is involved. Retry and loading states have text/announcement roles. Native checkbox,
select and button controls support keyboard operation; cards stack below 640px,
wrap text and add no motion (including under reduced-motion preferences).

## Validation and remaining acceptance

Focused evaluator and isolated DOM tests cover method/provenance mismatches,
missing/nonfinite and zero values, no load before opt-in, loading, failure, retry,
pair changes, numeric withholding and return to the no-data state. Public guide
contract asserts synthetic, no-data, causality and consent disclosures.

Real jurisdiction acceptance remains open: a steward must select policies and
provide original implementation records, archived dated sources and genuinely
comparable observations, sampling and uncertainty. This work invents none of that
evidence. Native mobile/keyboard, zoom and assistive-technology review remains
unverified; DOM checks and responsive CSS do not establish visual acceptance.
