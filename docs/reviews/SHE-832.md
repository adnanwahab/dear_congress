# SHE-832 — Native sharing and copy-link candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-832/cs-l100023-one-tap-native-share-and-reliable-copy-link-on-mobile

Implemented direct Share link and Copy link beside the sample advisory controls
on /votes, preserving the existing optional SVG preview. Native sharing is
called directly from the user click before any asynchronous work. Unsupported
sharing falls back to clipboard; clipboard denial or absence exposes a selectable
read-only link. Native cancellation does not copy anything. Native errors offer
an explicit copy retry. Success, cancellation and failure have live status text;
share-sheet completion explicitly does not verify delivery. Pending actions are
disabled and guarded against duplicate dispatch. Buttons have 44px minimum touch
targets and wrap at narrow widths.

Only the allowlisted sample ID and the current origin construct the URL:
/votes?proposal=<sample-id>. Titles come from the static sample catalog. No saved
vote, optional SVG stance, journal, storage, receipt, current query/hash, live-round
code, counts or simulation output enters the native payload or copied link.
Links identify a public fictional sample, not an immutable revision. Live rounds
retain their existing exclusion of these sample share controls. Citizen proposals,
repository issues/PRs and official legislation are not coerced into sample IDs.
No endpoint, persistence, tracking, rewards, contact access or automatic messaging
was added. No usefulness or meaningful-participation claim is inferred from sharing.
