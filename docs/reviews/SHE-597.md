Read AGENTS.md, readme.md, docs/motion.md, launch-merge-policy.md and the
SHE-349 provenance review. Inspected ProposalProvenance, WorkflowScreen,
Navigation, motion helpers, sample metadata and existing integration/browser tests.
Connected GitHub search found no SHE-597 PR. Related open candidates include

#237 (patch screenshot provenance). Inspected #203's diff: its explorer is a
separate documentation feature, not a merged dependency. No pending changes were
copied or treated as accepted.

The existing sample proposal source block now contains nested native disclosures:
observation, methodology and uncertainty. All layers preserve the original source
URL, publisher, jurisdiction, scope and freshness. Sample claims and interpretation
are explicitly illustrative, never official findings. Missing evidence remains
unknown; unsafe URLs remain suppressed. These fixtures have no extracted studies
or immutable public document revisions, and the UI says so.

Fine-pointer desktop layouts optionally lift opened cards with perspective and
scaled transform motion. Text stays selectable and in document flow. Touch,
reduced motion, motion=off and unsupported CSS use the native flat accordion.
Native summaries expose expanded state, Enter/Space activation and reading order
without duplicate ARIA or gesture capture. Changing proposal identity resets the
nested disclosures. No fetch or submission is attached to opening a layer.

Existing typed proposal transitions and chapter routes remain intact; local
disclosures do not need View Transition snapshots or asynchronous navigation state.
This avoids a second navigation mechanism and lets links leave during animation.
Existing explicit advisory-vote actions remain separate.
