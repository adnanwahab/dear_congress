## Changes

- Compute polygon area centroids from bundled SVG geometry once per module load.
  Recompute normalized distances only when selection changes. County fill delays
  range from 0 at the selected county to 550ms, followed by the existing 650ms
  fill transition, settling within 1.2s of each revision (ticks remain 1.8s apart).
  Alaska and Hawaii follow displayed inset geometry.
- Animate header support, percentage and revision over 1.2s in an isolated child.
  Its animation frames do not rerender county paths or the directory. Static
  total coverage stays fixed. Detailed methodology and accessible map totals
  continue reporting the actual current revision rather than interpolated values.
- Mount one pointer-transparent SVG gradient sweep on completion, delayed until
  the final ripple settles. Unrelated renders retain the same animation element;
  Restart removes it so a later completion mounts a new one. Existing role=status
  announces completion, and the top status explicitly says Simulation complete.
- Reduced motion disables county transitions, hides the sweep and immediately
  displays actual figures. A live preference change cancels an active counter.
  Animation frames and media listeners are cleaned up on changes/unmount.

Simulation wording, unavailable verified participation, all county identities,
synthetic requirements, model algorithm and disclosures remain intact. This
changes only local presentation; no APIs, votes, records or receipts are changed.
