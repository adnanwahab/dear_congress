## Plan, owned files and implementation

Only `src/client/policy-impact/ImpactView.tsx`, its isolated CSS/test and this
review record are owned. Shared App.tsx, server.ts, route composition and shared
planning files remain untouched. SHE-1032 owns integration.

`ImpactView` is a read-only presentation component with explicit public-only
props, exact before/after clause strings, selected/base version IDs and legal
diff hash, mappings/parameter units/review versions/assumptions/limitations,
uncertainty, explicit job status/progress and version navigation. It preserves
whitespace and renders untrusted text through React escaping. It neither accepts
raw server records nor serializes them. No requests, analytics, account IDs,
ballots, journal data, secrets or postMessage bridge are added.

The route owner supplies stable Civic-local permalink and Revise URLs. The local
link guard rejects external/protocol-relative/executable paths. Remote URL must
be returned by HBL, HTTPS at the configured exact origin, `/world/impact`, with
only `preview=pp_<64 lowercase hex>` matching returned ID and no credentials or
fragment. No URL is fabricated from an ID. Frame loads only after explicit user
action, with no-referrer and sandbox scripts/same-origin, after exact approved
Civic origin configuration; same-origin HBL framing is refused. Native error and
15-second load deadline show fallback. Cross-origin load cannot establish renderer
success, so visible text fallback and full link remain. Frame state resets when
proposal/base/version/hash/remote identity changes. Stale/revised-source,
unsupported and out-of-bounds data cannot offer a current simulator.
