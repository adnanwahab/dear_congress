# SHE-600 — read-only proposal presentation

Refs: https://linear.app/shel-bernstein/issue/SHE-600/civicplaymotion-theatrical-but-neutral-proposal-card-reveal-in

Implemented presenter query mode on the six existing chapter routes, reachable
from Navigation's page actions. Includes Previous/Next links, reversible blackout,
text zoom, user-requested fullscreen with denial recovery, synthetic labeling and
existing source provenance. This surface mounts independently of interactive
workflow controls. It performs only GET /api/demo and preserves proposal/topic
query context. Exiting is a separate navigation action; no public submission is
initiated. No autofocus, modal focus loop, popularity-dependent treatment, or timer
advancement is introduced. B/Escape shortcuts are scoped to the focused presenter.
