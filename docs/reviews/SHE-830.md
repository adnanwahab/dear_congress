# SHE-830 canonical proposal pages

Refs: https://linear.app/shel-bernstein/issue/SHE-830/cs-l100021-deep-link-every-proposal-to-its-canonical-shareable-page

Implementation candidate; human acceptance and native private-browser verification
remain pending. No deployment, merge, external message or issue transition occurred.

## Audit and behavior

Read repository instructions, README, citizen-proposal, bill-catalog,
legislative-metadata and launch-merge-policy documentation. GitHub PR search for
permalink, deep-link and SHE-830 found related stage defaults PR #46 (SHE-294),
not a duplicate canonical-page implementation.

Existing immutable citizen proposals keep `/proposals/:id`; curated editorial
bill drafts keep `/bills/:id`. Neither identity is rewritten into a sample or
Congress.gov record. Browser-private drafts remain private and are not published.

Samples now link from source/feed cards and the selected feed detail to
`/samples/:id/:sha256`. Advisory card exports include the same public URL.
The checked-in sample-permalinks artifact retains exact sample snapshots;
keep earlier entries when adding revisions, and update the current-link lookup
when introducing a newer revision. Do not replace historical snapshots.
Tests verify the current fixture matches each retained snapshot and digest.

Official metadata cards link to
`/official-records/:encoded-source-id/:sourceHash`. The reader selects the exact
archived successful observation, validates raw bytes and reparses source identity.
A later correction does not change an earlier link. Corrupt archives return 503;
unknown source/revision pairs return 404. No importer is run by this feature.

Both new detail families render escaped public content on the server without a
React bootstrap, browser storage, cookie choices or automatic actions. They retain
source-kind notices and show revision hashes; sample response counts are not
presented as real activity. Official snapshots explicitly say historical metadata,
not a live legal-status check. Existing stage URLs continue working.
