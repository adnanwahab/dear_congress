# SHE-751 linked research desk

Refs: https://linear.app/shel-bernstein/issue/SHE-751/civicplayinteraction-craft-resizable-linked-research-desk-with

Implemented a read-only desk at `/draft#research-desk`, linked from existing
navigation and Participation & privacy. It uses the loaded fictional sample's
exact current/proposed text and summary, existing source provenance and an ordered
text outcome graph. The graph is explicitly hypothetical; no claim-level citations,
causal evidence or measured results are invented. Official metadata and repository
PRs are separate. Selection is reset when the sample/text revision changes.

## Interaction and fallback

Drag either 24px divider with mouse/touch or focus it and use Left/Right by 2%,
Home/End to limits. Each pane retains at least 20% of available pane space.
Native buttons highlight corresponding labeled passages across all three panes,
with pressed state and a visible border/text indicator, without moving focus.
Sources continue to say when claim evidence is missing.

The single-column checkbox and automatic fallback at 1000px preserve all text,
links and highlighting controls. Hidden dividers leave the tab order. Reset desk
layout restores equal panes. Layout alone is saved under
`civic_research_layout_v1`; malformed data falls back to defaults and denied
storage retains the current page layout with a status notice. Existing drafts,
votes and source records are never read or written by the desk. Changing layout
never unmounts the existing amendment editor. Browser-local layout is not an
account preference or cross-device backup.

The desk has no animation, canvas, polling, observers or background work. Existing
motion settings are reused by Navigation's Top control so reduced/off motion
also disables its smooth scrolling. All source text is escaped by React.

## Verification and remaining acceptance

Automated regression covers linked selection, exact revision change reset,
adjacent size bounds, keyboard resize, pointer resize/cancellation, layout reload,
malformed and denied storage, source limitations and preservation of an unrelated
draft and input fixtures. Focused tests pass; typecheck passes.

Native VoiceOver/Safari or NVDA/Firefox, actual touch capture, narrow/zoom reflow,
forced colors, light/dark themes and low-power hardware still require human
verification under docs/accessibility-acceptance.md. Test the desk at 1440px,
390px, actual 200% zoom and reduced/off motion; select every passage from every
pane; resize and cancel drags; reload layout; confirm an unsaved amendment remains
while resizing/resetting. DOM tests alone do not establish accessibility acceptance.
