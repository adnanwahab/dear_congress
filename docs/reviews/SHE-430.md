## Implemented candidate

The demo/sandbox inspector opens from the selected outcome and follows the metric
and checkpoint controls. It separates observed simulation correlation, the local
reviewed parameter/mechanism mapping, and unavailable causal interpretation.
Export is a JSON download with the selected observation, local scenario revision,
parameter mapping, seed, model version, provider origin/endpoint, source law ID,
and full validated receipt. Code version and events are explicitly null; missing
evidence is enumerated. Model version is never relabeled as code revision.
Input changes clear the inspector and old receipt. Existing request identity,
cancellation, timeout, error, unsupported mechanism, and retry handling remain.
Native button/select/range/link semantics support keyboard and touch; the new
controls have 44px minimum heights. No new animation or automatic playback is
introduced. Existing reduced-motion CSS remains in effect. No new browser or
screen-reader acceptance evidence was collected.

## Remaining acceptance

This is a checkpoint evidence inspector, not a completed event-level why-chain.
Provider v1 does not expose event IDs, event timestamps, executed mechanisms or
code version. Full acceptance needs a reviewed provider contract with those
fields and explicit event-to-output links, then validation/rendering/export here.
Do not infer that nearby checkpoint changes are causal events. No provider
schema was invented and no other repository was modified. Human accessibility,
provider integration and acceptance review remain required; keep the issue open.
