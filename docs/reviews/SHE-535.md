## Behavior and privacy boundary

Share preview is an inline explicit action on existing sample advisory controls.
It prepares an SVG graphic and identical copyable alt text before offering a
Download link. Nothing is posted automatically. No additional API or persistence
is introduced. Closing resets consent; changing proposal remounts the preview.
Stance is unchecked initially, unavailable without a chosen stance and accepts
only Support/Oppose/Not sure. It is explicitly not proof of a saved vote.

The exporter accepts only a public sample ID and optional numeric stance. It
looks up the repository catalog itself instead of serializing the vote payload,
DOM, browser URL, storage or arbitrary proposal object. Identity, journal text,
receipt IDs, live-round codes, counts, and simulation results have no input path.
Live rounds do not expose this control. Exported source repository and sample
kind are explicit; no citizen, legislative or repository PR item is coerced into
this sample kind. Existing data, source identities and revision bindings remain
unchanged.

The graphic and alt text both say “Non-binding advisory action · not an official
election,” identify the fictional scenario, and retain the existing background
publisher/URL/scope and unchecked-source caveats via ProposalProvenance. These
links do not establish official proposal text. A full SHA-256 content version
covers title, summary, current and proposed wording and provenance, independently
of stance/tallies. This identifies exported build catalog content, not a stored
server revision or proof of an acknowledged vote. No immutable server snapshot
or official decision archive is claimed. Downloaded copies cannot be revoked.

## Validation and remaining acceptance

Seven focused tests pass, including existing authoritative tally tests. New
coverage checks version stability across stance changes, distinct proposal
versions, default omission, all three explicit stances, invalid IDs/stances,
loading with export unavailable, optional stance, reset on close, proposal
switching, missing choice, unavailable/retry and native focusability. Async
completion is cancelled on cleanup and keyed to proposal/stance, preventing a
stale export from appearing for another selection. All new controls use native
buttons, checkbox, link and textarea; no added animation, timer or motion effect.
Touch controls have minimum sizes and the image uses responsive width.

`bun run typecheck` passes. `bun test`: 478 pass, 26 fail (504 tests); failures
are HTTP tests unable to bind the server with EADDRINUSE / port 0 in this sandbox.
`bun run test:routes` also fails at that server startup boundary. Required checks
must run successfully in CI before human merge. `git diff --check` passes.

A standalone browser bundle compiled, but native Chromium launch failed with
MachPortRendezvousServer permission denied in the sandbox. Consequently rendered
desktop/mobile, real keyboard/Tab/Space, touch, downloaded SVG appearance and
reduced-motion browser acceptance remain unverified. The simulated DOM regression
is not a substitute. Human review must open previews at 1440px and 390px, exercise
keyboard and touch opt-in/download, check no clipping at 200% zoom, read graphic
and alt text with a screen reader, and verify reduced motion and unavailable
WebCrypto recovery. SVG is the current export format; platforms requiring PNG
need conversion. No external share was performed.
