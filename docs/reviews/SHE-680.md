## Implemented

Outcomes now includes a separate read-only study matrix, sortable in both
directions by case, kind, design, sample, jurisdiction, outcome, date, limitations
and disclosures. It uses native table headers, buttons, a keyboard-focusable
horizontal scroll region, 44px controls, and print styling. JSON export includes
criteria, stable row IDs, citations and initial revision/review history; download
failure leaves a copyable textarea. Print failure also exposes that fallback.
No runtime evidence registration or approval interface exists. Material edits
must append history rather than silently changing prior editorial revisions.

The sourced example is Baicker et al. (2013), DOI 10.1056/NEJMsa1212321,
[author manuscript](https://pmc.ncbi.nlm.nih.gov/articles/PMC3701298/), Abstract
Methods/Conclusions. The source was opened during this work. Sample, publication
date, mixed outcomes and short follow-up are retained. Funding/disclosure review
is explicitly incomplete; a primary source is not human approval. The conflicting
case is an explicitly editorial interpretation of mixed endpoints from this SAME
study, not independent contradictory research or replication. The missing-source
user claim and transit estimate are clearly invented demonstrations. This is not
a completed systematic review or evidence for any selected policy.

All entries are pending human review with no reviewer asserted. There is no
numeric quality or political viewpoint score. Built-in records render with the
page and introduce no separate fetch/loading state; existing proposal API failure
cannot hide the matrix. Offline use means an already-loaded page; no service
worker/offline reload capability is claimed. External citations require network.

The public guide documents the distinctions and export. Existing synthetic
measurements, demo background provenance, policy selection, votes and storage are
unchanged. No selected proposal inherits the example study as supporting evidence.
