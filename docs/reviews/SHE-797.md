Refs: https://linear.app/shel-bernstein/issue/SHE-797/cs-l100008-make-not-sure-and-skip-equally-easy-without-dark-patterns

## Audit and change

Reviewed this repository's README, launch merge policy, repository-voting docs,
shared advisory controls, WorkflowScreen, LiveRound and launch statistics code.
GitHub PR searches scoped to adnanwahab/dear_congress for SHE-797 and “Not sure”
returned no matches on November 16, 2026. This is a keyword audit, not proof that
no overlapping PR exists.

Support, Oppose and Not sure already share styles, native button behavior and
acknowledged-choice state. Undefined choice selects nothing; saved choices remain
visible. The shared controls lacked a prominent explicit Skip path.

Added “Skip — read without voting” alongside the three choices, using the same
background, border, typography, padding, width and minimum target height. Native
buttons support Tab/Enter/Space; the native navigation link supports Tab/Enter
and the existing visible focus outline. It opens the matching sample draft and
does not invoke the vote callback, withdraw a prior choice or claim participation.
Skip remains available during submission and in read-only live rounds. An already
submitted vote may still complete; navigation does not cancel it. The public guide
now explains the optional path and unchanged saved-choice behavior.

Telemetry retains separate page-view and accepted-vote stores. Reading the draft
may record a page view, never a vote. No statistics, API, auth, stored votes,
identities, source records, repository/item scopes, PR head/base bindings or
receipts were changed. Synthetic tallies remain labeled separately.
