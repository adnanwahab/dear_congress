# SHE-462 implementation and review

Refs: https://linear.app/shel-bernstein/issue/SHE-462/joylocal-civic-source-treasure-hunt

Adds a source treasure hunt in Documentation, reachable from the guide navigation
and public-guide starting paths. Houston prompts cover the city's historical FY2025
expenditure summary and September 10–11, 2024 agenda. Harris County uses Census
QuickFacts, explicitly identifying the 2020–2024 survey period and mixed row dates.
Sources retain their original governmental URLs and publisher identities. Historical
records are not labeled current. Prompts are demo learning activities, never verified
participation, official claims or proof of policy effects. Census conditions alone do
not attribute outcomes to a policy. Existing Published/Outcomes stage routes are reused.

No API, storage, server writes or new dependencies. Opening a source enables a
separate self-reported learning checkbox; it does not complete the activity. Progress
resets on reload. Unavailable/expired reports clear completion and expose the official
recovery index without asserting an unperformed HTTP health check. Clearing that
report allows retry. No remote fetch means no app-level loading state; external-tab
loading and failure guidance is visible before opening links.

## Validation and pending acceptance

Focused guide and interaction tests pass; typecheck passes. Tests cover original source
URLs/dates, opening without completion, learning completion, unavailable-source recovery,
undo and independent card state. Full-suite and route results are recorded below.

Manual browser acceptance remains pending:
- At 390px and desktop widths, check wrapping, touch target spacing and no horizontal overflow.

Native labeled controls have 44px minimum rows and 24px checkbox targets. These CSS and
DOM checks are not a substitute for the pending browser/screen-reader review.
