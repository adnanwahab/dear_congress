Implemented presentation-only history entries for all six WorkflowScreen stages.
Entries preserve proposal, committed search/topic/outcome/jurisdiction filters,
focus path, scroll and available lifecycle direction. Existing arbitrary history
keys survive proposal URL replacements. The existing forward/backward stage
transition types provide reversal; unsupported engines retain native navigation
and scroll restoration. Existing reduced-motion/off CSS remains authoritative.
Navigation links and touch routing still use full document navigation. Filters
initialize from the entry; focus and scroll restoration waits for data loading to
settle, including errors/empty results. BFCache pages restore on pageshow. Missing
focus targets use the main landmark. Jurisdiction restoration does not rewrite
the browser's saved preference.

History contains no vote payloads, sponsor records, journal text or server data.
Restoration focuses controls without invoking them. Existing advisory/synthetic
presentation separation, explicit voting and publication behavior are unchanged.
