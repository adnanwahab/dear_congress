# SHE-329 — Visible synthesis re-ranking

Refs: https://linear.app/shel-bernstein/issue/SHE-329/demomotion-animate-how-synthesis-re-ranks-the-plan

Implemented presentation changes in LegacyApp's Synthesis view. Each real or
simulated package retains its previous result independently. Retained proposals
get signed rank markers (↑2 / ↓1), additions get an Added badge and slide in,
and removed rows fade through View Transition snapshots with a separate Removed
title list. Markers clear after four seconds. The initial plan does not label
every row as newly added. No scoring, selection or synthesis API contracts change.

The result commit uses document.startViewTransition and React flushSync. Names
start with plan-item- and encode the side, package and proposal ID without
sanitization collisions. Transition styles target those identities only. Retained
rows use a position animation fallback where View Transitions are unavailable;
added rows and removal text still animate. Budget/support bars transition widths.
Budget spend, budget limit, average support, average change level and money moved
count toward their new values over 700ms, canceling pending frames on changes or
unmount. Reduced motion bypasses the transition, width/position/entry/exit motion
and counters, while retaining textual movement, Added and Removed indicators.
Network failures leave the current results visible and allow retry.

implementation-plan.md, launch-merge-policy.md and the SHE-310 sandbox notes;
inspected SynthView, PlanRow, bar styles and PackageResult. Read-only GitHub search
