# SHE-333 — scroll reveals and document reading position

The browser entry enrolls offscreen cards and document blocks after rendering,
including asynchronous content. Initial viewport content stays visible. CSS view
timelines control opacity and translation using the shared motion duration/ease,
entry 0% through cover 25%. An observer starts completion tracking and the CSS
animation's finished promise retires each reveal permanently, avoiding reverse
replays. No scroll event handler or layout-affecting animation is installed.
Mutation observation watches child lists only, avoiding feedback from classes.
Reduced motion and unsupported timelines leave content in its normal visible state.
Switching to reduced motion immediately clears pending reveals.

Documentation has a sticky 3px root-scroll progress indicator immediately below
its header. It reserves no new document space. The bar tracks position directly,
including under reduced motion. Unsupported scroll timelines omit the decorative
fill. The section observer watches document blocks across a reading line at 30%
of the viewport, computes the preceding h3, and sets aria-current="location" on
one TOC link. Ordinary anchors remain usable without IntersectionObserver.
Tracking responds to reverse movement, hashes and resize and disconnects on unmount.
