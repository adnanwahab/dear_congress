# SHE-392 — six-stage journey ribbon

Refs: https://linear.app/shel-bernstein/issue/SHE-392/joymotion-scrubbable-six-stage-journey-ribbon

Implemented a read-only ribbon on the six WorkflowScreen routes. A native range
supports drag, touch and keyboard arrows; labelled stage buttons provide direct
preview selection. A separate Open link uses the existing topic/proposal route
builder. Narrow screens use a compact three-column, two-row step rail. Native
range semantics, pressed buttons, labelled help and a polite artifact announcement
remain the same at every width. Preview changes are immediate; no animation needs
to be disabled for reduced motion, and existing typed route transitions remain
unchanged.

Artifacts project the currently selected proposal and current loaded data:
background publisher/scope/URL, feed summary, separated advisory browser and
synthetic tallies, current/proposed draft text, local sponsor card/possible offices,
and that proposal's simulated outcome. No new requests, writes, vote callbacks,
publication controls, tracker mutations or production changes are introduced.
Loading/error/empty states suppress stale artifacts. This ribbon is explicitly a
fictional sample overview; it does not combine official metadata or real citizen
proposals with fictional scenarios or claim measured outcomes.

Read readme.md, docs/motion.md, docs/launch-merge-policy.md and actual stage and
workflow source. GitHub PR audit found no SHE-392 PR; related candidates included
#86 (home journey), #110 (accessibility), #123 (simulation), and #1/#2 (participation
isolation). Their metadata does not establish acceptance. The supplied live
reference could not be read by the web tool.
