## Audit and scope

Read AGENTS.md, readme.md, launch-merge-policy and the SHE-357 provenance/module
review. Inspected WorkflowScreen, ProposalProvenance, demo metadata, workflow CSS
and existing DOM integration checks. Connected read-only GitHub search found no
matching SHE-404 candidate (it returned unrelated #7). Open-PR audit included
adjacent #133 (law comparison), #132 (sound), #131 (haptics), #130 (motion) and
#129 (motion preferences); no remote code was imported. The reference origin
could not be opened by the web tool; no live-site equivalence is claimed.
Existing untracked before screenshots were preserved.

Compact provenance disclosures now open on mouse hover, keyboard focus and tap.
Activation pins the disclosure; Escape, an explicit Close button, focus departure
or an outside pointer dismisses it. Escape/Close retain or restore trigger focus
when focus was inside. Expanded content stays in document flow to avoid clipping
or covering nearby civic actions. Native summary keyboard activation remains.
Wrapped source labels have a 44px minimum target height. Existing reduced-motion
rules disable disclosure and arrow transitions; unsupported animation features
retain ordinary native disclosure behavior.

Publisher, jurisdiction, source scope, check freshness and limitations remain
attached to their original sample identity. No original claim quotation or
publication date is stored: those fields explicitly report unavailable. Scenario
wording is never substituted for a publisher claim. Source check dates do not
become publication dates. Unsafe/missing URLs or missing publishers explicitly
flag an unsupported source; original links require safe HTTPS and publisher
metadata and open separately with noopener/noreferrer. Current route, query and
local civic context remain in the original tab. No new data fetching is needed;
existing workflow loading, error/retry and empty-data behavior stays in place.
