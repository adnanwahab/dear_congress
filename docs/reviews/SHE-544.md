## Changes

The tour now starts paused for reduced motion and pauses if that preference turns
on. Explicit Resume remains available. Native tour-button Space/Enter behavior
is preserved; keyboard Enter and form submissions outside the overlay are blocked,
just like touch-generated and pointer clicks. The tour explicitly distinguishes
reading, saving a draft, and making an advisory choice after exit. Pausing never
unlocks writes. No vote API, source identity, storage or provenance was changed.

`civic-non-coercion.test.tsx` compares actual rendered Support/Oppose/Not sure
controls under a stance swap, including selected state, disabled state, pulse and
track presentation, zero totals and absence of audio/video. Mounted tests verify
that clicks alone do not celebrate and all three acknowledged choices get the
same confirmation class. Existing feedback tests exercise uncertain/error saves,
exact-choice retry and reload recovery. Tour tests cover blocked submissions,
page activation, Space, native button keys, step navigation, Escape, reduced
motion and cleanup. These DOM tests do not simulate a physical touch screen or
screen reader.
