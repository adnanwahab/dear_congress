## Implemented first delivery slice

`/outcomes#mission-control` now contains a responsive read-only evidence wall.
Choose a separate official record, inspect its reported introduction and latest
action, and expand its primary source and metadata receipt. Origin, retrieval and
upstream timestamps, snapshot hash, method, freshness rule and coverage limitations
remain visible. A successful metadata read never promotes a bill to implemented.
There is no completion percentage, verified consensus count or fabricated effect.
Bill/congress numbers are source identifiers, not measured progress.

Next action, meeting deadline and sponsor reply panes explicitly report Unknown
and expand to explain the missing evidence. No primary-source link is invented
for absent evidence. The existing PolicyMeasurements component remains available
even during proposal/metadata failures, with its synthetic fixture histories,
uncertainty limits and noncausal assessments. It is rendered once inside the wall.
The existing model receipt explorer is linked at `/synth`; no official-record/run
binding is invented and no run starts on opening the link. This is navigation
reuse, not a new model receipt ingestion interface.

The shared OfficialBills loader retains the existing minute polling and adds a
manual retry. Failed reads mark retained records as refresh-failed. An explicitly
selected record that disappears does not silently select a different bill.
Native select/details/links provide keyboard interactions; CSS wraps long hashes,
stacks the wall on narrow screens and handles forced colors. The wall adds no
animation, browser storage writes, analytics, remote provider calls or dependencies.
Existing browser-local sample outreach remains separately labeled and unchanged.

## Demo script

1. Open `/outcomes#mission-control`. Explain the independent, read-only prototype
   notice and the separation from the fictional sample chooser above it.
2. With no imported records, show Unknown and the explicit catalog coverage limit.
   Do not seed official-looking fixtures or imply that absence means no legislation.
3. In a disposable local environment with a legitimately imported record (see
   `docs/legislative-metadata.md`), choose it and expand its metadata receipt.
   Compare the source identity, reported dates, retrieval time and hash. The hash
   identifies archived content; it is not authentication of the institution.
4. Expand each missing-evidence pane. No deadline, sponsor reply or next official
   action is asserted. Explain that a source steward must supply reviewed evidence.
5. Expand synthetic measurements: show mixed results and missing/stale observations.
   None establishes a real policy benefit or feeds this wall's official status.
6. Follow `/synth` only if desired to inspect the existing model explorer. Its own
   receipts retain scenario assumptions; a synthetic model is not measured delivery.
7. Simulate a failed read in a local test harness: retained evidence shows failed
   refresh and its original retrieval time; Retry recovers without writing a vote.
