The six existing labels/routes are preserved. Each complete card is now one native
anchor with hover and keyboard focus states, retaining proposal query selection,
including an explicit selection before demo data loads. CSS @starting-style brings
cards up in sequence at 90ms intervals. After entry finishes, a connector highlight
fills in stage order once. Connectors follow the six-, three- and two-column layouts
without overflowing row ends. Reduced motion paints the final cards and connector
immediately. Entrance uses opacity/transform and connector fill uses scaleX;
no animation changes flow geometry or waits for API data. Unsupported starting-style
shows the final cards and ordinary native navigation remains available.

An ordinary card click names only that card journey-stage-N. Its destination's
synchronously rendered Stage N of 6 kicker has the matching name for cross-document
View Transitions. Modified/middle clicks retain native behavior. The source name
clears on pageshow when restored from BFCache. No storage, URL tracking parameter,
API, vote, proposal or governance contract was added.
