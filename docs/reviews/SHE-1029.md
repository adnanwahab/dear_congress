## Implemented contract and boundaries

Wire schema is policy-impact-preview.v1 only: source, legal, baseline,
simulation and optional modelRunId. Canonical legal JSON recursively sorts keys,
preserves array order and exact strings; server-side SHA256 matches the pinned
housing fixture bcb6466a4803cc00cdba7102c4c4d2bc8925d09cb046737a314390af5421be8e.
Validation mirrors upstream bounds, public visibility, operation/text rules,
unique clause/mechanism IDs, baseline equality, unknown-field rejection and body
size. No source identity or text is rewritten. A hash mismatch is invalid locally;
provider immutable-version conflicts remain explicit conflict results.

The validator accepts the provider's 1–100 pairs / 1–24 months schema. Outbound
transport additionally caps the initial rollout at ten pairs. It does not expand
runs or implement HBL's seed derivation locally. HBL owns paired seeds, frozen
model/runtime/mapping versions and actual execution. Raising the local cap needs
measured performance evidence and review; none was collected here.

createPolicyPreview uses trusted server-only origin/token configuration, POSTs
/api/policy-previews and accepts 202 or idempotent 200. No token in source URLs,
redirects, browser routes or UI; cookies omitted, no automatic retries. A bounded
deadline covers fetch and JSON parsing, including transports that ignore abort.
Transport results distinguish accepted, invalid, disconnected, timeout,
unauthorized, conflict, busy and rejected. Success retains the real same-origin
viewer URL and queued/running/partial/completed/failed/unavailable job state,
finite bounded counts and supported/partial/unavailable support state.
An accepted submission is never represented as completed simulation evidence.

No arbitrary text-to-parameter mapping, metrics, uncertainty, replay IDs or model
version fields are invented. Unsupported clauses remain in the legal payload
and HBL reports unavailable effects. A wording-only modify carries exact text.
There is no historical SimulationReceipt decoder in this handoff. POST does not
return modelVersion or outcomes: testing a fabricated modelVersion field or
numerical receipt here would recreate the rejected protocol. The tests instead
reject unknown request fields, malformed responses and non-finite progress,
and preserve HBL's model-unavailable job state.

## Dependencies and remaining acceptance

versions and human-authored sourcePolicyId applicability decisions before calling
this adapter. Public visibility in a payload is not independent source-review
or identity verification. No production mapping is installed. A self-consistent
but stale version cannot be detected by this transport without the producer's
source repository/version lookup. Explicit not-modeled reasons belong to source
review and HBL parameterDiff, not invented POST fields.
