existing regression tests. Read-only open PR search for SHE-799 or journal found

feed and deliberate publication boundary. A button focuses the existing private
working-draft field, with explicit page-only, unsaved, unencrypted and reload-loss
warnings. A closed native details element offers a labeled fictional writing
example, without creating an entry, loading another feed, populating an excerpt,
changing counts or making a write request. No invented author/date/activity is
attached. The independent advisory beta and unverified eligibility are explicit.

Need/date/origin filters, cursors and missing entry permalinks retain no-results
guidance. Loading and failed requests do not claim the feed is empty. README and
public guide describe the new entry paths. Publication consent, existing drafts,
source identities, repository/item kinds, votes, PR revisions, records and receipts
are unchanged. No server or production data migration is involved.
