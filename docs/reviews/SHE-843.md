## Audit and scope

Read repository instructions, README topic-hub contract, SHE-357 review and launch
merge policy. Audited TopicHubs, shared taxonomy/projections, metadata and server
page rendering. GitHub search found no SHE-843 PR; related PRs #115 (hubs), #193
(annotations), #191 (neutral explorer) and #102 (topic identity) overlap existing
modules. No remote patches were imported. PR process success is not acceptance.

The existing housing, childcare, transit and climate paths now have distinct
questions, two representative fictional scenarios each, explicit source caveats,
and one primary next action to compare needs and policy alternatives with topic
context. Existing hub exploration remains available below. Shared editorial copy
renders on the server and in React, before API success is required. Each path has
its own static title, description, canonical and social metadata. Existing sitemap
entries and unknown-topic 404 behavior remain intact. Other topics are unchanged.

The content is identical for all visitors. No partisan or personal targeting,
contact collection, messaging, rewards or participation claims are added. Examples
are editorial scenarios, not invented source records; original sample IDs, lineage,
source caveats and missing official evidence remain in the existing hub lanes.
Independently operated non-binding beta and absence of governmental authority are
visible before the next action. No votes, records, receipts or API writes change.

Focused topic-hub tests: 7 passed, including all four static responses parsed
without executing JavaScript; checks cover distinct questions, exact scenarios,
source caveats, metadata, one orientation link, topic context and sitemap inclusion.
`bun run typecheck`: passed. `git diff --check`: passed.

Usefulness and comprehension remain unmeasured. Human review should ask readers
of each path to explain the question, distinguish fictional examples from measured
evidence, identify the source limit and find the next action. Record confusion and
whether comparison helped; shares or visits alone do not establish meaningful
participation. Native mobile, keyboard and screen-reader review remain outstanding.
No tracking or unsubstantiated usefulness measurements were added.
