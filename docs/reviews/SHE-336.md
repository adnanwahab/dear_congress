A successful Journal publication now inserts its returned entry at the top locally
instead of waiting for a second feed fetch. Only that entry gets starting-style
insertion and staggered labels. Existing loaded records do not animate in.
Each attached category links to /needs?need=<id>; the newly published entry also
passes its entry ID. Needs validates the category against loaded needs, selects
and scrolls to its row, highlights it briefly and pulses its bar once. Invalid
IDs fall back to the ordinary selection. History navigation updates focus too.

For a new publication link, the mention counter visually replays the confirmed
contribution from aggregate-minus-one to aggregate only when the loaded public
state contains that entry with that category. Accessible text always reports the
actual aggregate. This is a display replay, not a vote or additional data write.
Ordinary older-feed links do not request the count replay. Matching collision-safe
view-transition names connect the latest feed labels to Needs rows. Actual morphing
also depends on browser support and asynchronous destination data being ready for
incoming snapshot capture; it is a progressive enhancement, not verified here.

Reduced-motion rules remove insertion, label delays, bar/row animations and the
previous-count frame, showing final state immediately. Scrolling is immediate.
Pending moderation responses and failures do not insert a public story; the draft
is retained. Busy inputs prevent changing the in-flight publication selection.

## Permission boundary

The current SHE-303 implementation is the manual, no-inference slice, not the
complete consent-bound AI suggestion pilot. This form continues sending
inference: none and only author-selected categories after public confirmation.
Unchecked categories are not inferred or revealed; publication without tags has
no Needs link. No inference call or automatic vote was added. Future AI suggestions
must still obtain permission before inference and publish only reviewed labels;
this motion work does not complete SHE-303's outstanding acceptance.
