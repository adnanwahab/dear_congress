inspected GamePatches, LiveRound, GitHub source, wire types, eligibility and API.

reviewed the current open PR metadata, including draft #235 (SHE-613, semantic

requirements were adopted. The live reference could not be fetched by the web

protection requirements are shown when readable; unknown/denied protection data
stays explicit. Organization ruleset enumeration is outside this source's current
coverage, so maintainer verification of all applicable GitHub rules remains needed.

## Preserved policy and remaining acceptance

exposure, current-head approval, empty base/check allowlists failing closed,
protected-base evidence, active kill switch and fixed advisory auto-merge lock.

values are inferred from source defaults. Repository identities, item-kind scopes,
PR head/base version binding, existing ballots, receipts and records are preserved.
There are no auth/check bypasses, merge mutations, production changes or deployment.

Human review must rerun all required checks in a socket-capable environment and
verify desktop, mobile, keyboard and reduced motion against current GitHub receipts
and denied read permissions. Integration with the concurrently drafted microscope
work needs normal conflict review. A draft PR and this implementation are review
candidates only; neither constitutes acceptance or permission to merge/release.
