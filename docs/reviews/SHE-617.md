The station exposes advisory status separately from preview availability and
records structured bug context as compatible feedback text. Its only write is an
explicit consented POST to the existing revision-bound feedback endpoint. Source
refresh disables reporting; server-side stale revision/auth/CSRF protections remain
authoritative. An exact-head verified operator origin is required for launch.
There is no embedded frame or preview health probe: verified-at is the registry's
historical verification time, not a claim that a remote app is currently reachable.
Pending/unavailable previews retain the checklist and report form. Existing
feedback delivery statuses and trusted GitHub/Linear links track follow-up.

LiveRound is unchanged because it records civic stances and has no PR revision or
approved preview binding. No public vote, verified ballot, source identity,
head/base binding, existing record, receipt, auth or governance configuration was
changed. Defaults remain disabled/dry-run, quorum 10, 24-hour exposure, one
current-head approval, empty base/check allowlists, strict yes majority and active
pilot merge lock. Issues never merge; non-HBL scopes remain disabled/dry-run.
Required main checks remain `bun test`, `bun run typecheck`, `route smoke test`,
with human approval enforced through GitHub protection. Hosted policy and runtime
overrides were not independently certified. Production requires human release
ownership and a published tagged release; no merge/deploy/release, external message
or Linear status update was made.
