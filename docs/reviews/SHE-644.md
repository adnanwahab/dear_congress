# SHE-644 · Disconfirmation lab

Refs: https://linear.app/shel-bernstein/issue/SHE-644/civicplaysimulation-lab-disconfirmation-lab-design-a-test-that-could

Implemented a page-memory planner inside the existing native law explorer. It
records a hypothesis, measurable falsifier (metric, units, comparison, timing and
failure direction), proposed dataset/version/coverage/collection plan, allowlisted
evidence-source type and bounded finite numeric failure threshold. Deterministic
JSON receipts preserve reviewed scenario identity, revision, seed, model version,
horizon and uncertainty. Missing model versions remain explicitly unavailable.
All receipts remain proposed tests awaiting review. No review/publication endpoint
or verified-effect state is introduced. Free text never becomes model input.

Read README, AGENTS.md, native law behavior docs and launch merge policy. Audited
LawBehaviorExplorer, civic-law-context, HouseholdImpacts, ScoreInspector and their
existing tests before edits. GitHub search found no SHE-644 PR. Related open PRs
#344 (typed handoff), #339 (failure fallback), #336 (source contracts), #312
(dependency monitoring) and #378 (county first-run) were inspected through their
search metadata; their work was not copied or changed. The live reference page
could not be retrieved with the web tool; no live parity claim is made.

The existing provider request limits, allowlisted inputs, cancellation, loading,
failure handling and recorded playback are retained. Scenario changes remount the
planner so its receipt cannot silently rebind to different inputs. Text is private
to page memory; copy JSON before navigating. Source selection describes planned
evidence, never evidence already collected. Household and score displays now
explicitly disclose source mode, unavailable seed/horizon where applicable,
model version and major uncertainty without inventing effects.
