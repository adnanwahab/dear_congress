The actual before/proposed display lives in PatchChange, not AmendmentEditor.
Added a read-only fictional lens there, available on Draft and Votes. A native
range controls the clipping boundary; paired grid rows align the common prefix,
changed span and common suffix with shared row heights. This is a bounded text
diff, not inferred legal clause numbering. Removed and added text has semantic
strike/underline. Side-by-side mode removes clipping. Complete original text and
existing provenance/citations remain mounted below, selectable and copyable.
The decorative duplicate is hidden from assistive technology. No fetch, storage,
publication or voting is performed by the comparison. Selection resets per item.
The lens has no animation, including under reduced-motion preferences; existing
replay and typed proposal transitions are preserved. Empty text has an explicit
state; loading/error handling remains in the existing stage route.

This source only supplies fictional current approaches, not official clause
imports. Labels explicitly say so. Official metadata remains in its separate
lane. Supporting imported official clause text requires reviewed source/version
bindings and is not claimed by this implementation.
