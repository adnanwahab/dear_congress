## Implementation candidate

The repository guide and module documentation were reviewed before changes,
including the public guide, catalog rendering contract, accessibility acceptance
instructions and launch merge policy. Local history contains no glossary/SHE-491

`CivicGlossary.tsx` provides typed editorial explanations and illustrative examples
for appropriation, committee, quorum, amendment and effective date. Matching is
case-insensitive, supports plurals and requires whole words. It annotates plain
reading text in the public guide, workflow summaries and draft comparisons,
legislative catalog supplement, reported official actions and synthesis law-change
and implementation explanations. Original links and link labels are preserved.
No stored source text, citations, source identity, revision, ballot or receipt is
rewritten. Existing real/sample and provenance labels remain in their panels.

Definitions explicitly identify editorial authorship and jurisdiction limits;
examples do not imply enactment or current legal status. The quorum definition
explicitly disclaims using browser advisory votes as verified merge authority.
Definitions are bundled synchronously with their reading components: there is no
separate glossary loading state, request, retry, remote service or failure path.
Existing parent content-loading/error behavior remains intact. Once loaded, help
works offline. Missing/unrecognized terms stay ordinary escaped text.

Native buttons support tap, Enter and Space. Opening retains trigger focus; Tab
reaches Close. Escape and Close restore focus with `preventScroll`; blur and
outside pointer interaction dismiss without stealing focus. Fixed-position help
does not expand the article or navigate. Narrow screens use viewport-constrained
width/height and internal scrolling; focus outlines and system colors support
forced colors. There is no glossary animation, including under reduced motion.
Decorative draft playback stays plain text, avoiding invisible interactive terms;
help is available again when playback finishes.
