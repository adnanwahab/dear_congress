## Implemented behavior

Each populated `/topics/:id` renders a zoomable, scrollable graph with native node
buttons and an equivalent list containing every node, relationship and provenance.
Zoom is bounded to 75–200%, with reset. Scroll provides touch/keyboard panning;
Tab and Enter/Space use native buttons. Selecting a node reveals source-connected
paths (with explicit edge direction), original source identity and a next-step preview. Navigation requires the
separate source-context link. No selection, zoom or list action writes data.

The projection consumes `TopicHubData` from the existing consent-filtered API.
Namespaced IDs distinguish stories, needs, engine policies and metric targets.
Source record IDs are retained and source URLs encoded; dangling edges are omitted.
Stored sample extraction links use solid lines. Catalog needId associations and
measurement-target definitions use dashed lines and distinct textual lane labels.
Neither is presented as real activity or causal evidence. No official bill title
matching, new classification, synthetic resident inference or model execution occurs.
The list and node preview include the relationship explanation and source field.
Traversal follows the connected component in either direction, so selecting a
metric also reveals reachable sample origins without asserting causal direction.

Human journals remain excluded under the existing curation-consent restriction.
Only the existing public fictional repository sample stories enter the graph.
Official bill bindings and verified measurements remain visibly unavailable.
Metric nodes are catalog targets, not measured values. Engine policy alternatives
are illustrative concepts, not official bills or the separately curated HFL catalog.
This is a bounded sample discovery implementation; reviewed real bill/outcome links
and cross-topic human paths are still missing and must not be fabricated.

Loading/error/retry remain in the parent hub; an empty projection gives a clear
empty state. The graph introduces no animation or automatic layout movement, so
reduced motion has no graph animation to suppress. Shared theme colors, focus
outlines and minimum 44px control heights support keyboard/touch use. Guide and
README document these boundaries. Original hub lists remain available below.
