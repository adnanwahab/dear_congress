## Outcome: local implementation; acceptance remains open

Added a PR/main CI workflow with three independent, stable check names:
`bun test`, `bun run typecheck`, `route smoke test`. All main PRs, including
docs-only changes, run all three without path filters or repository secrets.
Read-only token permissions and checkout without persisted credentials are used.

`bun run test:routes` exercises the actual production HTML build/router on an
ephemeral port with a temporary JSON database, no inherited service credentials,
and a generated disposable cookie secret. It checks nine civic pages, their
bundled JS/CSS, the read-only citizen proposal API, and unknown/missing routes.
It never submits votes, contacts GitHub, or uses production storage. Its source
is included in typecheck. It verifies HTTP/build behavior, not browser rendering.

Fly Deploy now requires a published non-prerelease `v*` release and successful
tests/typecheck/route smoke validation of its tagged commit on main. Deployment
uses the exact validated SHA rather than re-resolving a mutable tag. It remains
paused unless `PRODUCTION_RELEASES_ENABLED=true`; keep it paused pending SHE-281
source recovery and Fly target verification. Main/master and bare tag pushes no
longer trigger deployment in the proposed workflow. Nothing has been deployed.

Added AGENTS.md, a PR template, and
[launch operator instructions](../launch-merge-policy.md): launch agents prepare
draft candidates, humans decide to merge, and analysis leaves its issue open.
These repository files do not reconfigure an external running orchestrator.

## Existing configured merge policy preserved

Source defaults remain quorum 10, strict yes majority, 24-hour exposure, one
current-head approval, disabled merging, dry-run, empty base/check allowlists
(fail closed), 9 AM America/Chicago and at most six-hour recovery. Production
bases require explicit authorization. The kill switch defaults active. Eligibility
requires known protected-base evidence, clean mergeability, successful current-head
checks, no blocking reviews or pending reviewer requests, and maintainer approval
for sensitive changes. Non-HBL scopes cannot merge; issues never merge.

No governance config, auth, CSRF, shared 100-account roster, source identities,
repository/kind isolation, head/base binding, votes, comments, receipts, schema,
or durable data was changed. Advisory browser votes remain separate from verified
ballots. Production environment values were not inspected. A quorum of one was
not enabled or authorized.
