## Audit and scope

Read repository AGENTS.md, readme.md, native law behavior documentation and launch
merge policy. Existing explorer validates paired HBL receipts and allowlisted
scenario links; household presets have no response model and score inspection is
arithmetic, not a model-effect receipt. No seed finder existed. GitHub search
found no SHE-635 PR. Related open simulation candidates include #393
(disconfirmation), #395 (activity profiler), #399 (diorama), and #344 (handoff
contract); their process completion is not acceptance evidence. No other PR was
merged or copied into this work.

Implemented bounded, sequential seed search in the existing explorer. The chosen
allowlisted metric is evaluated at the exact final checkpoint. Reversals require
opposite nonzero signs relative to the reference seed. Requests stop after at most
eight seeds or 45 seconds, with cancellation, explicit partial/failure reporting
and no retries. Identity, strength, population, version, engine and horizon must
match. Each counterexample exposes exact paired JSON and a version-pinned replay
link that requires explicit rerun. Data remains local to page memory. Displays
explain synthetic source mode, seed, model version, horizon, major uncertainty and
sampling limits. Household and score panels disclose unavailable model provenance
rather than inventing a response mapping. Updated public guide and module docs.
