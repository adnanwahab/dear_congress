The home page now provides a categorized discovery rail using the existing typed
sample payload. City/county/state selections use the existing explicit sample-ID
mapping; regional METRO stays outside Houston-only results. No new API is introduced.

category; clearing preference removes the existing browser preference key.

other proposal lists. Reading/filtering creates no votes, records or outreach.
Public guide copy describes the same boundaries. Existing source repositories,
item kinds, PR revisions, ballots, records and receipts are untouched.
