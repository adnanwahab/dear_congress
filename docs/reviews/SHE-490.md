# SHE-490 implementation and verification

Refs: https://linear.app/shel-bernstein/issue/SHE-490/joystory-listen-to-a-60-second-proposal-explainer

Implemented a sample-only explainer in WorkflowScreen's six-stage selected-item
context. Narration derives directly from the current summary, proposedText and
jurisdiction fields with passage-level links to visible originals. It identifies
the fictional source namespace and repository. No real-world benefit/cost claims
are inferred from agency homepages. Missing tradeoff evidence is disclosed rather
than invented. Support, Oppose and Not sure receive equal mention; playback does
not save choices or change data.

Synthetic speech starts on a button click. Transcript remains available during
loading/failure or without speech support, subtitles follow spoken passages, Stop
cancels playback, and selection/revision changes unmount the previous player.
The UI adds no motion and uses wrapping text and native keyboard controls.

Audit: existing ProposalProvenance identifies background-only references;
ArgumentMap explicitly marks outcome claims unverified. GitHub PR searches for
`repo:adnanwahab/dear_congress explainer` and `SHE-490` returned no matches.

Limits requiring human acceptance: platform voice, native keyboard/screen-reader,
mobile and reduced-motion walkthroughs have not been performed. Timing is an
approximation, not a fixed 60-second recording. Subtitles use passage boundaries,
not word timestamps. Missing tradeoff evidence remains an explicit gap: this does
not establish an evidence-reviewed explainer for every real proposal. Citizen and
official records need their own reviewed source contracts before expansion.

Governance unchanged: configured source defaults remain disabled/dry-run, quorum
10, 24-hour exposure, one current-head approval and active kill switch, with all
revision/auth/check boundaries preserved. Runtime settings and remote branch
protection were not verified. Required checks and human review remain as described
in ../launch-merge-policy.md. No deployment, merge, release, issue transition or
production write was performed. This work is a review candidate, not acceptance.
