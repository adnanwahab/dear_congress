PolicyPinball is an opt-in component in DemoTour, BillCatalog and WorkflowScreen.
Its authored triangle follows four fixed hypothetical bounces: budget reduces
scope, jurisdiction adds a shared desk, evidence requires a trial observation,
and staffing creates a two-turn implementation schedule. Each bounce displays
its exact if/then rule and consequence. All rules and outcomes are also available
in native expandable complete text, independently of the decorative SVG.
Native buttons support touch and keyboard without timers, dragging or animation.
Skip, Restart, Exit and Escape are available; closing restores launcher focus.
Tour play pauses on opening and its global keyboard shortcuts yield to the game.
Shared theme variables and the shared chip styling label fictional provenance.

Game state exists only in component memory. It has no requests, storage, proposal
inputs, ballot callbacks, ideological choices, points or rewards. No source
identities, repository/item kinds, PR head/base bindings, existing votes, records,
receipts or server behavior changed.
