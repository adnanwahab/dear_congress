A separate exact SHE-891 search returned no matches. This is a targeted audit,
not exhaustive proof of remote branch contents. CLI GitHub access failed; the
connected GitHub search succeeded. No remote writes were performed.

PlanRow now renders FiscalAssumption for every selected policy, including when
its explanation is collapsed and in either input lane. Each has:

- USD billions/year and jurisdiction; an approximate baseline cost or unknown.
- Catalog sample versus unreviewed citizen concept and existing costEstimate
  flag. Assessed/designed/citizen labels never claim independent verification.
- Independent fiscal source/date and uncertainty range explicitly unknown.
- A plain statement that these are not appropriated dollars or exact predictions.
- A labeled keyboard-native 0–200% sensitivity slider, local modeled cost/delta
  and reset. Bounds are exploratory, not a confidence interval. Missing, negative
  or nonfinite baselines disable arithmetic; zero stays valid.

State is component-local, keyed by proposal ID/cost/estimate flag. Changed fiscal
inputs reset it. The slider has no network, storage, engine or voting dependency.
It deliberately leaves the baseline package and ledger unchanged and says so;
it does not re-optimize selection or calculate policy effects. Ledger wording
now separates arithmetic resolution from accuracy. Public guide and README
explain the same limits. No fiscal evidence or uncertainty interval was invented.
