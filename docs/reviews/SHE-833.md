Implemented self-contained text cards for the twelve current sample drafts.
Each archive entry binds repository, sample kind/ID, title, jurisdiction, exact
before/after text and background source metadata to a full SHA-256 revision.
The dedicated /draft?card= revision view renders only the archive entry, without
loading current samples, browser vote state or private amendments. Unknown and
empty revision parameters fail closed. Changed current content gets no share link
until an exact archive row exists. Old archive rows must remain unchanged;
append revisions instead. Hash and full archive text snapshots guard accidental
rewrites. Persistence of old URLs depends on retaining this bundled archive in
future releases; it is not a separate archival service.

Cards show fictional/demo and legal status, independently operated non-binding
beta disclosure, jurisdiction scope limitations, complete before/after, source
identity, background-only citation and permanent link. Copy is explicit, uses the
current origin, and reports success or falls back to selectable text. A complete
accessibility description is available for alt text on optional manual screenshots.
This implements the text-card option; no image generation/export or social crawler
preview is claimed. No inferred local jurisdiction or imported legal text is added.
Sharing is not measured as meaningful participation; usefulness/comprehension still
need human research. Native browser, screen-reader and narrow-screen review remain
outstanding. Snapshot/SSR tests do not establish those outcomes.
