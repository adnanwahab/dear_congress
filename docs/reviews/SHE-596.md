# SHE-596 implementation and review evidence

Refs: https://linear.app/shel-bernstein/issue/SHE-596/civicplaymotion-seamless-map-to-table-continuity-for-geographic-civic

## Audit and scope

Read repository instructions, readme.md, docs/motion.md and
docs/launch-merge-policy.md; inspected MapScreen, typed motion, Navigation and
county integration/browser tests before editing. GitHub PR audit found no
SHE-596 PR. Open map-related candidates #151 (consensus terrain) and #238 (branch
subway) cover different surfaces; they are not acceptance evidence for this work.

Implemented on the existing /map county sandbox. Its public Census boundaries
and explicitly synthetic county-fips-v1 requirements remain distinct from real
resident evidence. Map/list switches retain selection, search, status filters,
metric labels and revision. A selected county morphs to its focused accessible
row, including when outside the first 60 directory results or current filters.
List mode removes the SVG; native county search and buttons remain available.
Failed visual APIs commit a usable destination. Superseded callbacks and page
exit cannot overwrite newer navigation. Ordinary chapter routes are unchanged.
No requests, public submissions, precise private coordinates or persistent data
were added by these controls.

## Validation

Focused map/motion suite: 10 tests passed, including isolated DOM checks for
selection/focus, filters, visual failure and interrupted deferred callbacks.
Typecheck passed. Browser E2E success/failure journeys added, but not executed:
the local Playwright dependency was missing and dependency installation stalled
under restricted network access. Desktop/touch/native screen reader acceptance
is pending; DOM tests do not establish that acceptance.

Full bun test and route smoke were attempted. Server-based tests fail to bind
inside this sandbox (EADDRINUSE, including port 0); no server/listener or security
configuration was changed to bypass that restriction. Final full suite: 476 passed, 26 failed;
all remaining failures are server-based binding failures. Fixed an existing motion verifier's generic first-status
selector to target the simulation status after adding the mode announcement.

## Preserved merge policy

No governance or deployment configuration changed. Source defaults in
src/server/hbl/policy.ts and api.ts remain disabled, dry-run, quorum 10,
24-hour exposure, one current-head approval, empty base/check allowlists and
six-hour maximum recovery. The kill switch remains active by default; non-HBL
scopes remain disabled/dry-run. Repository/item kind and head/base bindings,
existing records, receipts, ballots, auth and source identities are unchanged.
These are source defaults; production overrides, live branch protection and the
external orchestrator were not verified. The worktree has no local
.mini-symphony/config.json. Required checks remain bun test, bun run typecheck
and route smoke test, plus human approval. No deploy, release, merge, auto-merge,
external message or Linear status change was performed. Human acceptance remains
required and the issue must stay open pending verification.
