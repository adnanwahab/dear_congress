## Implemented

`PolicyMeasurements` now includes a text-first uncertainty stack with measurement,
model, cost and implementation layers. A bounded nonnegative product gives an
explicit scenario envelope; unsupported methods, missing metadata/bounds, invalid
numbers/dates, overflow and unresolved conflicts block combination. It never
labels this a confidence interval or assumes independent errors. Every input has
an ID, classification, date (explicit unknown), source (explicit missing) and
limitations. The original fixture definitions and derivation are recorded in
`docs/uncertainty-stack.md`. Primary source, editorial inference, user claim and
synthetic estimate are distinguished without labeling fictional data primary.

Three local cases cover traceable invented inputs, conflicting invented user
claims and missing provenance. Per-revision logs retain input IDs, rationale,
date and pending human-review state. There is no mutable estimate endpoint or
claim of completed review. Guide copy documents these boundaries. JSON export,
copyable complete record and a fully expanded print record preserve provenance
and blocked-result reasons. Native select/list controls avoid chart-only meaning;
44px controls and wrapping support narrow layouts. Cases need no async fetch and
remain available after initial loading if APIs or networking fail.
