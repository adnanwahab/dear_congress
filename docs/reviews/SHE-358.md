## Implemented local slice

Follow/unfollow appears for the selected sample on feed/votes/draft/outcomes and
on citizen proposal detail. Navigation links to `/outcomes#watchlist`. A separate
versioned browser storage key stores only kind, ID, public title/text and local
observation timestamps. It never reads votes, journals, account IDs, repository
ballots or identities. Following does not make API writes, request browser
notification permission, collect identity or contact offices.

The watchlist supports unfollow, export and delete all. It explicitly describes
browser-profile visibility. Storage failures are reported; malformed data is not
silently overwritten. A successful revisit to a followed detail can record a
changed public title/text snapshot. Exact prior/current text is shown, with a
local observation date; this is not an authoritative source revision or date.
Duplicate observations do not create another change. Only the latest comparison
is retained. No background fetch, push or delivery occurs. Source kinds are
isolated, even for matching IDs. Existing storage and records remain unchanged.

Watchlist cards label fictional vs citizen/unverified evidence and explicitly
state missing source revision, updated date, next step and verified progress.
Missing or withdrawn sources remain saved, without claiming activity, deletion
or withdrawal from a failed fetch. No public subscriber counts exist.

## Remaining acceptance (keep issue open)

This is a local following foundation, not full SHE-358 acceptance. Needed:

- Authoritative repository/source/item/revision-bound event ingestion for revisions,
  official citations, substantive responses, real milestones and measurements.
  Verified withdrawal/deletion state and exact event-level changes are pending.
- Separate confirmed email or web opt-in, unsubscribe, consent withdrawal,
  muted channels, quiet hours, digests, delivery rate limits and durable duplicate
  suppression. No subscription controls are offered until delivery exists.
- End-to-end tests of withdrawal/deleted-source events and muted/withdrawn consent
  with queued delivery. Current model tests cover only retained missing sources,
  revision comparison, duplicate observations, kind isolation, safe projections,
  reversible persistence and corrupt/blocked storage.
- Native browser, keyboard, screen reader, mobile and visual review; cross-tab
  writes use browser storage without transactional conflict protection.
