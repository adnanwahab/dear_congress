## Behavior

Four-entry local shelf on catalog and detail pages, with native Add/Remove/Clear
buttons and optional card drag/drop. Responsive comparison fields cover purpose,
proposed change, jurisdiction, safeguards and proposed metrics. All effects remain
hypothetical; evidence is unassessed and fiscal estimates unknown. Detail links
retain filters and provenance access. No endorsement, vote, measured outcome or
verified evidence is inferred from saving.

Storage contains only ordered catalog ID/revision pairs in a repository/kind/
collection-scoped key. Invalid, duplicate or oversized snapshots are rejected.
Unavailable saved revisions are flagged without substituting current text.
Storage errors retain in-page selection and explain the link fallback. Explicit
shelf links disclose ID/revision snapshots; edited linked shelves produce history
entries, including empty snapshots. Clearing cannot revoke recipients' old links.
The SHA covers existing catalog fields, not the separate HFL-051 supplement.

The shelf uses no animation, network request or polling; the same search, focus,
links and selection buttons work in static/reduced-motion mode. No Dashboard or
TopicHubs sample is recast as an HFL draft.
