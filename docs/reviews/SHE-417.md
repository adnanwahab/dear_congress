# SHE-417 — private civic passport demo

Refs: https://linear.app/shel-bernstein/issue/SHE-417/joyquest-private-civic-passport-for-learning-milestones

Implemented a bounded demo on `/account`, explicitly awaiting review. It is off
until started. Three optional, self-reported badges cover evidence, jurisdiction
and opposing perspectives. The progression map allows any order, no deadlines,
score, leaderboard or reward for votes, public posts or influence. Badges confer
no verified status or voting power. Keep Linear open for human acceptance.

## Privacy and states

Only `{version:1,badges:[allowlisted IDs]}` is written under the new
`civic-learning-passport-v1` browser key. No identity, source/revision, timestamp,
stance or browsing history is recorded. No backend, telemetry or identity binding
is added. Ordinary exploration links use existing route behavior. Shared browser
profiles can read progress; exported files must be kept private.

Reset clears badges while keeping opt-in. Delete removes the key and turns the
feature off; it cannot remove files already exported. Export downloads local JSON
and also allows recovery of invalid saved data without overwriting it. Invalid or
blocked storage shows an alert and retry/delete controls; failed writes do not
announce success. Initial loading has a status and busy state. Native buttons and
links support keyboard/touch, have visible focus and buttons at least 44px tall.
Actions wrap on narrow screens. No new animation exists, including under reduced
motion. Human keyboard, touch, screen-reader, zoom and reduced-motion browser
walkthroughs remain pending; DOM tests do not establish those acceptance checks.
