## Implemented behavior

A shared PatchChange component serves the dashboard, Draft and voting explanation
panels. Explicit playback strikes the illustrative current text over 600 ms,
reveals proposed text in groups of up to four words from 650 ms through roughly
2.1 seconds, then fades the summary from 2.2 to 2.6 seconds. Replaying restarts the
sequence, including while it is running. Proposal-keyed mounting resets playback.

Complete selectable text remains mounted throughout playback. Decorative strike
and reveal layers are aria-hidden, ignore pointer events and cannot be selected.
The summary stays in the accessibility tree while visually fading. Download
handlers still export original complete item fields and are unchanged. Print
styles immediately expose complete text. No text is progressively added to an
ARIA live region.

Proposal selection uses startViewTransition with a synchronous React commit inside
the snapshot callback. The named patch region fades/slides out and in. Browsers
without this API switch immediately. Reduced motion bypasses the transition and
playback; changing the preference during playback exposes the final state
immediately through CSS and cancels playback state.
