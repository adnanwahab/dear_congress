## Implementation

Three original sine-envelope miniatures (navigation 440 Hz/90 ms, sandbox
330 Hz/90 ms, completion 550 Hz/180 ms) use mono 16 kHz PCM. Each is under 6 KB
before base64, generated on demand, cached in memory and played with HTML media
at low volume. No third-party recordings, remote fetch or Web Audio output path.
CSP adds only self/data media sources; other policies remain unchanged.

Sound Off is visible in the shared header, including narrow workflow headers.
The browser-local preference is independent of civic identity; no account or
server preference is created. Storage failure permits page-only choices.
Cross-tab Off stops active media. Enabling or restoring On never plays a cue.
Only explicit same-tab main-navigation activation and the read-only rule compare
button play cues. No mount, loading, empty data, network response, polling,
completion effect, voting, publishing or automated demo generates sound.
All existing text, statuses, fixture labels and revision bindings are retained.
Reduced motion and motion-off suppress sounds; tests are individually invoked
and disabled while Off or reduced motion is active. Hidden pages stop media.
Rejected/unsupported playback fails silently without disrupting civic actions.

The pack needs no sound download and works without networking after shell load.
This does not add a service worker or promise offline application data. Native
media observes browser/device media volume. Browser APIs cannot reliably detect
all hardware silent switches; device-mute acceptance cannot be asserted for all
platforms. The UI discloses this and provides guaranteed application Sound Off.
