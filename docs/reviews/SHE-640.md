## Behavior and boundaries

- 1–8 explicit consecutive seeds, canonical provider/input/revision dedup key,
  compute estimate, one active request, 45-second per-request abort deadline.
- Cancel/retry, retained partial batch results, separate queued/running/completed/
  failed/canceled counts. Late canceled receipts cannot become completed.
- First valid receipt pins model version; input/version/horizon mismatches fail.
  Full JSON receipts and same-input pinned replay links remain inspectable.
- Native labeled controls, live progress, 44px control minimums and no animated
  progress. The queue has no dependency on motion preferences.
- Source mode, seed, model version, horizon and uncertainty disclosed. Household
  effects remain unavailable and score arithmetic stays independent.

No durable queue, cross-tab/global scheduler or provider CPU estimate is claimed.
Provider server limits still apply. Aborting a request cannot certify provider
work stopped. Deterministic client recipe/receipt tests use a mocked provider;
real model determinism/version availability requires staged human verification.
Physical touch, screen-reader, browser keyboard traversal and full responsive
visual acceptance remain to be checked; native DOM tests are not those checks.
