## Implemented scope

Documentation exposes a typed, read-only five-layer explorer using the existing
three synthetic policy measurement contracts. It derives claims with the existing
assessMetric evaluator, preserving pinned baseline/current revision and source
version identities, units, periods, population, comparison rules and missing data.
The source-document layer explicitly identifies the fixture repository/file and
the absence of a provider archive. The main-branch source link is explicitly
mutable. The UI layer links back to Outcomes; Outcomes links into the explorer.
Navigation uses the shared six-stage contract. Stage navigation does not establish
proposal binding or causal lineage across stages.

Synthetic, stale and missing flags have readable text and distinct border styles;
Disputed is defined separately with an explicit statement that no dispute records
exist. No disagreement or provider evidence is fabricated. No real record is
reclassified, and no private input is read. Exported Markdown contains the same
layer text and links as the screen, the assessment date, identities and limits.
The public guide and README describe this bounded implementation.

All layers use native details/summary and ordinary links in reading order. Layout
wraps at narrow widths with no fixed-width table, animations or asynchronous
requests. Consequently this local fixture viewer has no fetch/loading state.
Missing current measurements block comparison. External-link failure guidance
keeps missing evidence explicit and never substitutes a provider. The surrounding
application retains its existing lazy page loading behavior. This implementation
does not test availability of remote source links.
