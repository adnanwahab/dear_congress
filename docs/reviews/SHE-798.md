Implemented for review on November 16, 2026; human acceptance remains open.

## Audit and scope

Read repository AGENTS.md, readme.md, launch merge policy and SHE-544 review
boundaries. The existing sample `/votes` flow already separates browser counts
from synthetic totals and stamps receipts only after server acknowledgement.
GitHub search found no SHE-798 PR. Open PR metadata includes adjacent mobile
acceptance (#375), canonical links (#371), native sharing (#369), and pinned
redline cards (#368). This change supplies an inline explanation and manual-copy
path, without depending on those unmerged features or changing their APIs.

After a confirmed or previously saved choice, all three stances receive the same
optional next steps: See trade-offs, Compare a possible future, Share this
explanation. The first supplies intended-benefit context and questions about
costs and distribution. The second compares the selected fictional current and
proposed text; it supplies no model forecast or invented measured outcome. The
third copies reviewable public sample text with its ID, viewed-text fingerprint
and existing background provenance, excluding personal stance and identity.
Manual selection remains available if clipboard access fails. No external share
or message is sent. Browser-cookie/non-binding limits remain outside disclosures.

The follow-up resets for a different proposal/text; a previously saved Not sure
also qualifies. No vote mutation, server schema, source identity, receipt meaning,
repository ballot, revision binding, or persisted data format changes.
