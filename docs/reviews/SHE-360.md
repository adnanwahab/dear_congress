# SHE-360 — plan budget ledger and waterfall

Refs: https://linear.app/shel-bernstein/issue/SHE-360/synthesisux-make-the-dollar40b-plan-budget-understandable-with-an

Implemented a citizen-readable ledger in both real and blended synthesis lanes.
Each row retains the proposal ID, jurisdiction, annual illustrative cost, estimate
source category, explicitly missing date and uncertainty, and cumulative total.
Integer USD-million arithmetic reconciles all rows exactly; the synthesis engine's
hundredth-billion rounding residual is disclosed separately, never allocated as
spending. Unknown, negative, nonfinite, duplicate, overprecision, over-budget and
inconsistent-total inputs close the ledger visibly and disable export/revision.
Zero budget with no spending is valid. No contingency is modeled; baseline/net
incremental spending and one-time costs are unknown, not silently equated to zero.

The text table describes the waterfall and formula; decorative bars are hidden
from assistive technology. Filters retain full-plan totals. Exclusions list their
engine reason and marginal funding without removals, with explicit warnings that
funding alone does not override other gates. Budget-only previews reuse the exact
replacement IDs computed in engine.ts by cheapestIncumbentsToFree, rather than
creating a second optimizer. Before/after totals, added/removed items, dollar
deltas and unknown uncertainty remain visible. Candidate/source cost mismatch,
missing replacement IDs, rights blocks and infeasibility refuse the preview.

Explicit commit creates a local fiscal-ledger revision and export only. It does
not rewrite synthesis selections, advance stability, or save a server plan. Reset
restores the baseline. Changed synthesis results remount the ledger to discard
stale local revisions. The versioned JSON download contains public fiscal rows
and caveats, no journal text, votes, quotes or identity fields. Numeric fields use
USD millions; display values use billions. It freezes the summary for sharing,
not a URL or private-input synthesis replay.

## Validation and remaining limits

- Focused arithmetic and client interaction tests: 7 passed, 44 assertions.
  Covers zero and infeasible budgets, missing costs/provenance, negative/nonfinite
  values, rounding, formatting, filters, baseline preservation through preview,
  explicit local commit/reset, export and fixed-seed/time synthesis replay.
- `bun run typecheck`: passed after frozen-lockfile dependency installation.
- `bun test`: 409 passed, 24 failed, 433 total. Failures occur in server-listener
  tests with EADDRINUSE on port 0 in this restricted environment. Required full
  test check is not green.
- `bun run test:routes`: blocked at Bun.serve with the same EADDRINUSE/port 0
  failure before route assertions. No route-smoke pass is claimed.
- `git diff --check`: passed.

Human browser verification remains for screen readers, keyboard flow, mobile,
zoom, theme contrast and download behavior. This work adds no independent fiscal
sources, dates or calibrated uncertainty. The preview is the existing fiscal swap
explanation, not a new synthesis optimization under a forced inclusion constraint;
policy eligibility and stability review still apply. Local ledger commitment is
not persistent plan revision. Human product review must decide whether persistent
revisions and reproducible public snapshot links are needed before acceptance.
Leave the issue open; this implementation is a review candidate, not acceptance.
