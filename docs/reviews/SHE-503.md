Refs: https://linear.app/shel-bernstein/issue/SHE-503/joytogether-civic-duet-respond-with-an-alternate-proposal

## Audit and delivered scope

Read repository instructions, readme, citizen-proposals, motion and launch merge policy.
GitHub PR search found no duet PR. Open related drafts include #194 (coauthor
credits), #195 (expert Q&A), #196 (cooperative missions); none establishes a merged
permission or fork-moderation contract. Existing proposals have immutable public
text, anonymous browser ownership and no verified public author identity. The
existing private amendment and guided workspace explicitly lack public moderation.

Added private page-memory duet preparation at citizen details and the recovered
six-stage workflow's sample Draft/Votes views. The action appears after source
loading succeeds; existing loading/error/retry paths remain in charge of loading.
Each copy retains the source kind/ID, title, jurisdiction, origin and exact initial
policy text. Supporting information and journal identity remain visible when
provided; journal text and attachments are not imported. Original author credit
links to the citizen proposal; no person name or verified identity is invented.
Successive copies retain the root attribution and prior copy text/rationale.
Original source objects, votes, comments and database records are untouched.

Comparison uses the existing bounded prefix/suffix redline with explicit Added /
Removed labels and the existing mobile stacking stylesheet. Native buttons,
labelled fields, expanded state, heading focus, status and error roles support
keyboard use. No animation is introduced, including for reduced-motion users.
Source changes block further copies; source selection changes reset the editor.
Leaving edited work triggers the native leave warning where supported.

## Deliberate limits / outstanding acceptance

This is private preparation, not completed public fork delivery. Copies exist only
on the page and are lost on navigation/reload; this is prominently disclosed. No
publication control, network request, local-storage write or path into the legacy
publisher is added. Public fork publication still needs a server-owned immutable
ancestry contract, authenticated attribution/permission evidence for every attached
personal item, moderation/report/withdrawal lifecycle and durable retry behavior.
Client checkboxes alone cannot establish third-party consent. Public fork chains
and consent enforcement therefore remain unimplemented; keep SHE-503 open for
human acceptance. Citations are escaped unverified text, not fetched evidence.
Native mobile, keyboard, screen-reader and zoom acceptance remain manual checks;
Happy DOM does not establish browser layout or assistive technology acceptance.

## Governance

No merge, release, deploy, external message or production data change performed.
Configured source policy remains disabled/dry-run, quorum 10, 24-hour exposure,
current-head checks/approval, fail-closed allowlists and active kill switch. Required
main checks remain bun test, bun run typecheck and route smoke test, with at least
one human approval. Actual GitHub protection and runtime values are not verified
by this work. Human-published tagged releases remain the deployment boundary.
