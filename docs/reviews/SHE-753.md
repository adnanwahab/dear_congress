# SHE-753 — mobile exploration sheets

Refs: https://linear.app/shel-bernstein/issue/SHE-753/civicplayinteraction-craft-snap-point-bottom-sheets-for-mobile-civic

Implemented a shared native-dialog sheet for More navigation and the advisory
proposal's read-only current/proposed comparison. Small, half and full states
preserve mounted content; a handle swipe moves one state without dismissing.
Every size has an ordinary keyboard button with pressed state. Close and Escape
restore trigger focus. Native showModal supplies modal context and focus trapping;
body overflow is restored on close/unmount. No continuous animation, polling,
new motion foundation, theme, personalization, vote mutation or draft storage.
The existing motion helper disables entry transitions for off/reduced motion.
Advisory mutation status changes dismiss exploration sheets before rendering the
result, including receipts arriving while More is open. Sheets never stack over
an already open dialog. Comparison content preserves source provenance and the
same current/proposed text and summary as the inline page.

Fallback: open “Understand the change — inline view” (or “More destinations —
inline view”) to read the same information without gestures or modal support.
Unsupported showModal opens and focuses that disclosure automatically. All sizes
scroll their content; resizing does not remount or clear drafts elsewhere.
Account explains the reading controls. Reload/navigation draft semantics remain
as documented by the existing application.
