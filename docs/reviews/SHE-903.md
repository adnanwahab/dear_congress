## Local changes

The external reviewed-world handoff now uses the same validated public replay
query as Civic's scenario link. This retains model version, seed, local recipe
revision, law, strength, population, parameter, horizon and clock. It excludes
proposal IDs and ambient/private query fields. The external destination and
separate-tab behavior stay the same. No request or run occurs on opening the
portal. The native view explicitly warns that catalog compatibility, code
identity, exact saved-plan replay and external return-query preservation are
unverified. The public guide and module docs describe that boundary.

The regression exercises the actual completed-run portal link, verifies its
query matches the local replay link and parses the outgoing recipe as a
returning query. This tests Civic's serialization/loader; it does not establish
what HappyBearLandia does with those fields. Existing tests verify malformed,
duplicate and incomplete recipes fail closed, mismatched model versions/horizons
are rejected, and exported deltas equal edited minus baseline recorded values.

## Acceptance status and required follow-up

This is a partial implementation, not acceptance of SHE-903:

- **Immutable plan/viewer round trip:** the public sandbox recipe preserves
  seed/version/revision in Civic and its outgoing URL. Its local integer revision
  is not a server-bound immutable saved-plan revision. The frozen Civic package
  is not applied to the model. Provider return behavior remains unverified.
- **Recomputable deltas:** selected-outcome JSON already contains the recorded
  receipt, exact checkpoint, metric, baseline, edited value and subtraction.
  This supports recomputing displayed differences from saved outputs. Rerunning
  the exact model is not guaranteed by a model-version string alone: code,
  catalog and underlying evidence revisions are absent.
- **Catalog mismatch:** v1 receipts and public context have no catalog revision.
  Civic cannot compare absent identities. It now warns that compatibility is
  unverified; it does not fabricate a catalog ID or claim mismatch detection.

To complete acceptance, agree a reviewed provider contract with immutable catalog
and code/content identities, bind a consent-safe public recipe to the actual
immutable Civic plan revision, require all replay identities on both sides,
retain them on the reciprocal return URL, and reject/warn on incompatible or
missing catalogs before presenting comparable results. Archive the necessary
inputs/outputs and independently test replay and delta recomputation. Verify
same seed, plan revision, catalog and model identity across the real two-origin
round trip, including old/changed/missing catalogs and unavailable providers.
These need source, safety and editorial review; arbitrary prose must remain
unavailable without a reviewed parameter mapping. Keep the Linear issue open
until a human verifies those criteria. No issue transition was performed.
