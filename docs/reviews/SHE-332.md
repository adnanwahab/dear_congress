# SHE-332 — Shared civic visual system

Refs: https://linear.app/shel-bernstein/issue/SHE-332/demo-one-visual-system-across-journal-needs-and-synthesis

Implemented one CivicHeader in WorkflowScreen, JournalScreen, LegacyApp,
Dashboard, MapScreen and Documentation: all local bottom-navigation destinations
share the brand, stage pill and Sample data / Advisory · not binding badges.
Legacy loading/error states retain that header. Sample data labels describe the
demo; they do not confer authority on resident inputs or advisory votes.

The root now owns the stage palette, Arial typography, blue #245593 accent and
shared surface tokens. Both shells inherit it, including under dark system
preferences. Vision board headings, buttons, borders and cards consume those
tokens instead of a separate green/serif palette. Legacy controls retain their
specific button cascade and behaviors. Data, source identities, votes, PR head/base
binding, records and receipts are unchanged.

Audit read AGENTS.md, readme.md, source-recovery.md, implementation-plan.md and
launch-merge-policy.md, and inspected navigation, screen headers and CSS.
GitHub PR search for SHE-332/SHE-323/SHE-322 found PR #76 (SHE-322).
Its purple bottom-navigation patch was inspected; this change leaves those
selectors alone so purple navigation remains independent of the blue content
accent. No SHE-323 implementation was found in the checkout/search. The header
has the consistent `civic-header` view-transition-name for that work; actual
cross-page animation and native browser layout remain unverified. This change
does not implement a navigation/transition engine.
