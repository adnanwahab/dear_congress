## Implemented bounded demonstration

The existing expandable synthetic outcomes prototype now offers a local dataset
correction demonstration for each available observation. It keeps the published
claim pinned, computes SHA-256 over deterministic measurement content, retains
both local snapshots, and displays before/after fields and required reviewer
acknowledgment. Detection date is an explicitly invented fixture date; provider
change time remains unknown. Source IDs cannot cross in comparisons or review
matching. Review acknowledgment records bind source and both hashes; there is no
public browser action claiming authenticated review. The displayed review log is
empty. The shared matching helper is a data contract, not an authorization layer.

Primary source, editorial inference, user claim and synthetic estimate are
explained separately. All displayed data remains synthetic with original periods,
limitations and causal warnings. No fixtures, baselines, measurement selection,
source identities, votes, PR revision bindings, records or receipts are rewritten.
This is page-local state: reload returns to the unchanged published fixture.
Hashes identify listed measurement fields, not fetched raw publisher bytes.

Snapshot JSON can be copied without a download API; dedicated print content
includes both snapshots even with the disclosure collapsed. Local computation
requires no network after page load. Loading is announced; hashing failure leaves
the original card and a reload/error explanation. Native button/disclosure controls
support ordinary keyboard/click interaction and a 44px button touch target.

## Validation and remaining acceptance

Focused hash/diff/review and UI tests pass. They cover deterministic hashes and
all factual fields, source mismatch rejection, preservation of the published
claim, exact transition review matching, loading disablement, local offline
interaction/focus and copyable JSON. Existing offline outcomes integration passes.
Typecheck passes. Final full test run: 479 pass, 26 fail; server-dependent failures
encounter port-0 EADDRINUSE in this sandbox. Route smoke fails at server.ts:1824
with the same listener error. No checks or assertions were weakened. Final focused
checks: 9 pass, 0 fail (60 assertions); typecheck and git diff --check pass.

This is partial implementation, not acceptance of SHE-685. Remaining work:

- A steward-approved fully sourced public measurement with archived raw provider
  payload, exact query/release dates, licensing, transform version and reproducible
  hashes. The demonstrated correction is not a real source revision.
- A genuinely conflicting independently cited case and an explicit missing-source
  claim case. Existing missing-measurement cards do not satisfy these criteria.
- Durable append-only source ingestion, published-claim revision references,
  authenticated human acknowledgment storage/logging and concurrent-update checks.
  No live polling, alerts, publication or review endpoint is introduced here.
- Integration with the reviewed shared claim-provenance schema when available.
- Actual browser keyboard, touch, mobile overflow, print preview, screen reader,
  crypto-unavailable/error and fresh offline navigation checks. DOM tests and print
  styles alone do not establish that matrix. Rerun the complete suite and route
  smoke in a listener-capable environment.

Keep the Linear issue open for implementation and human acceptance.
