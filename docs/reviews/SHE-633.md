source origin, allowlisted inputs, actual horizon, seed, version, population,
intervention, scenario and downloadable receipt links. Rename is metadata only;
duplicate preserves receipt and parent identity under a fresh ID. Recorded replay

incompatible versions, seeds, populations, engines or horizons. Each run display
states synthetic source mode, provenance and major uncertainty. No arbitrary legal

simulation provenance while retaining their existing behavior.

previous storage. Records are browser-local and unsigned; a receipt download is
not a verified governance receipt. Clearing browser site data deletes the local
notebook. No import or cloud synchronization is provided.
