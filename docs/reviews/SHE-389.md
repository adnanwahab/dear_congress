## Implemented local slice

WorldPortal opens a native modal without unmounting the source screen. It retains
the same URL in a separate browser history entry; Back closes the modal and
restores focus and scroll. Nested portals recognize their own history marker.
Escape and the Return button request the same Back traversal. No form submission,
storage write, proposal mutation or vote occurs when entering.

Sample draft/voting details and citizen proposal detail retain a labeled source
reference while the existing separate reviewed model is selected/run. Model
controls, cancellation, timeout, receipt validation and errors reuse the existing
LawBehaviorExplorer. Unsupported bill prose is explicitly not applied or sent.
No citizen/sample ID is misrepresented as a bound simulation revision.

Completed synth results stage the existing allowlisted civicLawQuery recipe,
including its model recipe revision, strength and seed, before external navigation.
The external link still uses the supported URL contract and noopener. The handoff
is static and says that external load completion cannot be verified. The original
Civic tab and its full model results remain open. No external return URL or typed
message contract was invented. Native local title transitions use the shared
helper, including reduced-motion/off behavior.

## Acceptance still open

This candidate does not establish the full requested cross-app round trip:

- No upstream acknowledgment of loading/ready/unavailable exists in this change.
  The external link opens a separate tab; browser Back in that tab is not a return
  to Civic. Users return to the retained Civic tab, then close the portal.
- No verified external breadcrumb to the exact Civic tab or server-bound proposal
  revision exists. A model recipe revision is not a published legal revision.
- Source proposal and selected policy do not yet form a two-element shared
  transition into the external world. The local portal title transitions; the
  cross-origin handoff stays static. Source labels remain on the Civic side,
  not guaranteed throughout the external world.
- Native browser Back/Forward/BFCache, rapid traversal, scroll, narrow layouts,
  keyboard focus trapping/Escape, reduced motion, slow network and unavailable
  provider behavior require browser acceptance. Forward does not reopen portals.
  DOM checks do not prove native dialog rendering or browser history traversal.
- Private guided drafting and unsaved new-proposal forms do not gain this action;
  the implementation targets published detail and sample `/draft`.

Complete the remaining behavior with an agreed supported external breadcrumb /
readiness contract, actual source-kind/revision binding, and a disposable local
cross-app browser test. Do not infer a reviewed mechanism from arbitrary titles
or legal text. Keep the Linear issue open for human acceptance.
