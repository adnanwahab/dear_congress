# SHE-499 — collaborative plan lab

Refs: https://linear.app/shel-bernstein/issue/SHE-499/joytogether-collaborative-plan-lab-with-shareable-sandbox-rooms

Implemented invitation-only fiscal suggestion rooms inside the existing Synthesize
budget ledger in both real and blended lanes. Explicit Create sends only the
current ledger's allowlisted public fiscal fields. Explicit Join accepts a pasted
invitation. No auto-join or public invitation listing exists. Invitation URLs use
fragments; credentials travel to the same-origin endpoint in POST bodies. These
are bearer invitations: holders can forward them. Pseudonyms identify sessions,
not verified residents. The joining participant sees their assigned pseudonym.

The separate bounded in-memory store imports no DB, ballot or synthesis code.
One-hour expiry is enforced on every request and expired rooms are purged lazily;
restart also loses rooms. Access requires the invitation and a separate random
membership capability. Joining requires the invitation. History is append-only,
server-attributed and time-stamped. Polling every 15 seconds updates presence;
45 seconds without a successful poll marks a session away. Leave clears local
credentials; it does not erase attributed room history. No credentials persist
in browser storage. Limits are documented in readme.md. There is no individual
revocation or durable recovery; invitation secrecy is the access boundary.

Suggestions name an existing frozen ledger item and an integer-million annual
allocation between zero and the room budget. Suggestions can conflict and never
change the baseline, recompute a package, relax exclusions, save votes, or apply
to official synthesis. Source identities, fiscal source labels, lane and package
binding remain attached to the frozen baseline. Missing estimate dates and
uncertainty remain labeled unknown. Private proposal fields are stripped at the
server, even from custom clients. Snapshot contents supplied by participants are
illustrative and are not verified source receipts or authoritative decisions.

Loading, timeout, errors and retry are explicit. Native details, labels, inputs,
selects and forms support keyboard use without gestures. Controls wrap on narrow
screens; no animations are added, including for reduced motion. No broad polling
live region announces every presence update. Public guide and README describe
sharing consent and real-versus-simulated boundaries.
