# SHE-533 — private civic journey

Refs: https://linear.app/shel-bernstein/issue/SHE-533/joydiscover-private-personal-civic-journey-timeline

## Implementation

`/account` extends the existing public beta participation screen with an explicit-save personal learning log. Topics, drafts, sandbox runs and explicit vote **notes** have separate sections, newest saved time first. Each note retains its declared source: personal learning, citizen advisory activity, seeded fiction or model simulation. Manually entered notes have self-reported metadata; source-specific controls label their source explicitly. Neither is verified civic provenance. No background collection, API request, vote submission or model execution occurs.

The versioned `civic_private_journey_v1` store has bounded validated entries, raw JSON export (including corrupt storage for recovery), per-note delete and a confirmed reset affecting only that key. Corrupt or denied storage blocks saves/deletes and displays an error without silently replacing the data. Reload and storage events refresh the view. Export files contain private text; the UI explains storage exposure to other profile users and same-origin scripts, and absence of encryption, backup and sync.

Existing proposal drafts/workspace, watchlist, votes, receipts, repository scopes and source identities remain untouched by journey saves/deletions. Links lead back to the existing draft/workspace/watchlist foundations. Resetting this journey does not withdraw a server vote. Personal history never establishes eligibility or merge authority.

## Acceptance still requiring implementation/review

Source-specific Save snapshot privately controls now copy existing saved citizen/workspace drafts, explored citizen/sample proposals, a server-loaded current citizen advisory choice, or completed model run metadata. Drafts retain original IDs, saved dates and values; citizen choices retain proposal ID and exact proposed text; model metadata retains law, amendment/revision, engine, manifest/seed and limitations. Actor frames are intentionally omitted. Failed/loading/dirty model states offer no snapshot. There is no automatic telemetry or historical reconstruction. These optional copies do not alter source votes or drafts, and remain editable browser data rather than tamper-proof receipts. Repository PR ballots and eligibility credentials are excluded. Concurrent cross-tab writes are not transactional. Explicit copies are capped at 200,000 characters and 500 entries; oversized saves fail without replacing earlier entries.

Native browser keyboard/touch, mobile/reduced-motion, screen-reader, export download and visual validation remain unverified. Native labels, buttons, status/error roles, 44px controls and a wrapping layout are provided; no new animation is introduced. Happy DOM interaction tests are not native accessibility evidence. Keep Linear open until human acceptance.
