# SHE-422 implementation review candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-422/joyquest-civic-marble-run-trace-a-policy-through-institutions

Implemented a labeled, unreviewed educational sandbox on Draft. An animated marble
advances through drafting, committee review, chamber votes, presidential signature
and agency delivery. Invented constraints branch to revision, stalled passage or
waiting delivery. Native buttons/select support keyboard and touch; manual steps,
reset, live status and an open static decision diagram accompany playback.
Reduced-motion/off modes use manual advancement and suppress marble animation.

Uses DemoItem, existing source provenance and proposal-bound civic navigation.
The existing /api/demo loader handles loading, error/retry, empty and unavailable
selection states; the run mounts only after successful loading with a selected
sample. Proposal changes reset it. No network writes or persisted sandbox state.
Official status remains in the separate source desk. Existing simulator snapshot
API was inspected: it freezes policy packages for effect models, not passage.
The run therefore links to Synthesize rather than fabricating API passage results.

Sources: https://www.congress.gov/legislative-process and
https://www.usa.gov/how-laws-are-made. This simplified federal path assumes matching
chamber text and signature, omits veto/override paths, and explicitly warns that a
sample's local jurisdiction does not establish federal authority. The reference
https://civic-synthesis.fly.dev/ could not be retrieved by the web tool.
