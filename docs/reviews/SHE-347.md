# SHE-347 — Quick switcher implementation candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-347/demo-k-quick-switcher-to-jump-to-any-stage-proposal-or-need

Implemented a shared-shell native modal dialog opened by Command+K / Control+K
or the visible Search button. Editable fields retain their shortcuts. Other open
modal dialogs are respected. Escape and backdrop clicks close and restore the
previous focus without scrolling. The input uses combobox/listbox semantics,
active descendant selection, arrow navigation, Enter activation, result type
labels and a live result count. Empty matches have an explicit message.

Catalog includes six stages, Overview, Map, Journal, Needs, Synthesis,
Documentation, API docs, all 12 fictional proposals (Votes first, with Feed and
Draft alternatives), and all catalog needs. Matching accepts multiple substrings
across title, type and topic/keywords. Navigation uses location.assign, retaining
the existing full-document View Transitions. Need links select the requested
catalog need; invalid query IDs fall back to normal selection. Home metadata now
says Overview instead of Journal. No data writes or new dependencies were added.

Dialog and backdrop use starting-style and allow-discrete transitions for entry
and exit. Reduced motion disables their transitions entirely. The top-layer
modal does not change body overflow, padding or page geometry.

Actions are discovered from existing controls on opening: the SHE-331 home link
`a[href="/?demo=1"]` or `[data-action="play-demo"]`, and theme controls marked
`[data-action="switch-theme"]` or `button[aria-label="Switch theme"]`. They invoke
the existing control. Neither feature exists in this checkout, so neither action
is offered here. The separate guided-tour PR must be integrated before its action
can be verified; a future global action provider may be appropriate if the tour
is made available beyond the home page.
