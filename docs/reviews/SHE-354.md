## Implementation

Both embedded Needs and Synthesize jurisdiction maps now provide a polite status
message independent of the canvas. No style means no MapLibre import. Import,
initialization and resource failures, plus a 10-second initial load timeout,
remove the affected map and expose “Map visualization unavailable; explore needs
below.” Manual retry mounts a fresh attempt without resetting any civic content.
Late completions and events from disposed attempts cannot replace the fallback.
Successful readiness waits for MapLibre's idle event, including initial tiles.
Map load handlers populate needs data and readiness replays current source data,
including changes made while assets were pending.

Rankings, need selection, real/simulated mode buttons, policies and jurisdiction
ordered lists remain independent of map loading. Jurisdiction summaries explicitly
identify real voices, label scores for screen readers and describe empty rankings.
No visitor location lookup was added. Existing aggregate suppression is unchanged.
Status and retry copy interpolate no provider error text or configuration values.
Fixed developer-console diagnostics distinguish initialization, resource and timeout
failures and suggest provider/connectivity/browser-policy checks without raw errors,
URLs or tokens. Missing-style configuration is documented in the operator README.

not paint WebGL, contact tile providers, measure layout, or establish actual
screen-reader output. Native-browser QA remains required for keyboard traversal,

location inference, or retry loop. Existing responsive layout and reduced-motion
handling are retained. Repeat full HTTP checks in an environment permitting local
