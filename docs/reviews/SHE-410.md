# SHE-410 — Five-minute first-visit civic adventure

Refs: https://linear.app/shel-bernstein/issue/SHE-410/joyquest-five-minute-first-visit-civic-adventure

## Implementation candidate

Home now links to `/?quest=1` and an equivalent non-game walkthrough at
`/?quest=1&walkthrough=1`. Five untimed chapters follow Journal → Need →
Comparison → Proposal → Future. Back, Next, Skip, chapter selection, Exit and
Restart use ordinary native controls. Every chapter can be skipped, including the
last; finishing acknowledges learning without a ballot, identity or post.
Chapter heading focus moves after navigation. Controls wrap and have 44px minimum
height. There is no timer, animation, mandatory answer or progress gate.

An optional fictional bus-service story consistently connects all five chapters.
Samples default off, are labeled on every card, and never enter shared journals,
need extraction, tallies, proposal stores, synthesis or outcomes. No new server
endpoint or mutation is introduced. The App entry renders the learning guide
before mounting the dashboard/live provider. This also avoids loading or empty
live-data dependencies: the complete lesson is available immediately, without
fetching resident or demo data. Ordinary stage links are exposed after completion
or in the plain walkthrough, with an explicit notice about leaving the guide.
The existing seven-stop 60-second DemoTour remains unchanged.

`civic_adventure_v1` stores only chapter, completion and sample visibility locally.
Reload resumes; invalid/out-of-range data restarts safely. Blocked storage produces
a visible page-only-use notice. Restart overwrites learning progress. The guide
collects no personal text or identity. The public guide and README describe this
behavior and its limits. All-at-once and chapter views use the same lesson data.
