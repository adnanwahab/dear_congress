## Policy and compatibility

`/embed` previously discarded script, object, base, form and resource restrictions.
It now changes only the frame-ancestors directive, retaining the exact theme
initializer hash, same-origin scripts and existing HBL/CARTO/Bugsnag/worker
allowlists. No unrestricted inline-script or eval allowance was introduced.
Semicolon and newline injection through FRAME_ANCESTORS now fails startup.
Inline styles remain permitted for existing React/MapLibre rendering.

Production code defaults to self framing; fly.toml currently configures `*`.
The README's previous assertion that wildcard framing was removed was inaccurate.
The configured wildcard is preserved to avoid silently cutting off existing
partners. It remains a clickjacking risk for the interactive embed: a human owner
must inventory approved origins and review a separate explicit allowlist change.
CSP frame-ancestors controls inbound framing; default-src self controls outbound
frames. External world behavior is rendered natively from HBL data, not an iframe.
The configured default HBL origin remains permitted by connect-src. Arbitrary
HBL_URL/MAP_STYLE_URL hosts need separate CSP review. Ordinary external source
navigation remains unrestricted by these resource directives; no source URLs,
records or provenance were modified.

COOP same-origin can sever cross-origin opener relationships; COEP require-corp
requires compatible cross-origin resource responses and affects nested frames.
No SharedArrayBuffer/isolation requirement was established here. Leave both unset
until real partner/resource tests pass; do not add credentialless as a workaround
without reviewing credential-dependent embeds. References:
[HTML browser policies](https://html.spec.whatwg.org/multipage/browsers.html),
[COEP documentation](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Cross-Origin-Embedder-Policy).
No report collector or identity tracing was added.

## Validation and measurements

Installed dependencies using the frozen lockfile (unchanged).
Focused header/public-security tests: 13 passed, 104 assertions. Typecheck passed.
Full `bun test`: 655 passed, 27 failed; suite is not green. Server-dependent tests
encounter local listen failures. `bun run test:routes` fails before and after at
Bun.serve port 0 (EADDRINUSE), before any route assertion. Elapsed process time
was 0.11 s before and 0.12 s after; these are failure timings, not site latency.
The smoke assertion now requires `/embed` to retain the ordinary page's full CSP
when the production default ancestors are self.

A bounded in-process comparison constructed 1,000 responses per variant after
100 warmups, applying securityHeaders and then the before/after wildcard embed
CSP. Before p50/p95: 0.000667/0.001500 ms. After: 0.000917/0.001791 ms.
All 1,100 constructions per variant returned 200. This excludes network,
browser enforcement and server routing, is order/JIT sensitive, and establishes
no production latency or availability guarantee.
