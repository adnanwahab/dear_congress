# SHE-344 — Live Synthesis preview

Refs: https://linear.app/shel-bernstein/issue/SHE-344/demomotion-preview-the-plan-live-while-dragging-synthesis-weights

Implemented live previews for the six weights, institutional-change penalty and
annual budget. Native range onChange handles pointer and keyboard value changes.
Each change immediately invalidates and aborts the previous request and resets a
180 ms timer. Responses and deferred View Transition callbacks check the latest
request version, so older results/errors cannot replace a newer setting or commit.
Previews use SHE-329's updatePlan, rank markers and reduced-motion behavior.
The unsaved status appears on changes and successful preview results; only a
successful current Synthesize response clears it. Failed requests retain results
and allow retry. Opening the view now requests a read-only preview rather than
advancing the baseline automatically.

POST /api/synthesize accepts preview: true in both comparison and ordinary modes.
Both persistence blocks skip lastPlan assignment, challengerStreak assignment and
save. Scoring still reads the existing saved baseline/streaks. Synthesize retains
the ordinary persistence path. Preview does not approve or activate a scoring rule.
Existing public request/security wrapping remains intact; no separate preview
rate limiter was added. The 180 ms debounce does not guarantee total latency under
server load; real pointer/keyboard browser timing remains to be measured.
