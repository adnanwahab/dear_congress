## Implementation

Votes starts a round for the selected sample proposal and opens /votes?live=CODE.
The presenter displays a locally generated SVG QR and short /live/CODE URL,
question, running voter count, independent bars, owner-only End round and frozen
results. Phone choices replace that browser's previous choice in that round.
No names or free text are stored. Round browser identities are hashed; no voter
identities are returned in snapshots. Existing persisted votes and sample baselines
are untouched. Live rounds never feed synthesis, repository votes or merge authority.

Writes use the existing signed anonymous cookie, bounded JSON, same-origin checks,
and combined IP/identity limits. Clearing cookies permits a new browser identity;
this is advisory participation, not verified people. The default 60 writes per IP
per ten minutes supports 30 initial phone votes behind one shared IP; additional
changes share that existing budget. No limits were weakened.

SSE sends an initial full snapshot on each connection. Browser EventSource retries
after a disconnect. Vote broadcasts coalesce over 250 ms; cumulative per-stance
pulse counters preserve burst events, which the client plays from a small queue.
Shared bars animate values and shares; reduced-motion disables all animations.
A 15-second heartbeat keeps idle connections active. Expiration sends a final
snapshot after two hours, and all server mutations enforce expiration independently.

Rounds are in memory on one server process. Restarts lose them; multiple replicas
need shared storage and pub/sub before use. Ended results remain available until
cleanup at a subsequent start after expiry plus 24 hours. Capacity is bounded at
1,000 retained rounds and 10,000 browsers per round. QR encoding is fixed version
5-L byte mode (106 UTF-8 bytes maximum for the full absolute link); normal production
and localhost links fit. No external QR service or new dependency is used.

## Validation and remaining review

Focused round/security/bar tests: 8 pass, 52 assertions. They cover replacement,
round isolation, owner authorization, freeze/expiry, invalid proposals, 30 concurrent
votes, stream reconnect, non-disclosure of identities, origin/JSON/rate-limit
boundary and QR envelope/capacity. The burst snapshot arrives in about 250 ms.
Typecheck passes. Full suite: 320 pass, 23 fail before the final added security test;
the failures are HTTP server startup failures with EADDRINUSE in this sandbox.
Route smoke also cannot bind port 0. New smoke cases cover presenter/phone routes,
noindex, SVG, cookie-bound replacement, unauthorized ending and frozen voting,
but could not execute past server startup. Required CI checks must pass before
human merge. No real 30-device frame-rate test, camera QR scan, browser visual QA,
or dropped-network acceptance was performed here. Verify these, mobile keyboard
operation, reduced motion and production proxy streaming during human review.
