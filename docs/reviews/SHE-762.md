# SHE-762 — anonymous draft recovery

Refs: https://linear.app/shel-bernstein/issue/SHE-762/civicplayinteraction-craft-anonymous-draft-crash-recovery-and-conflict

## Audit and implemented scope

Read repository instructions, readme, citizen proposal, motion and launch merge
policy docs. Audited the guided workspace, amendment storage/editor, navigation,
account privacy screen and shared motion helpers before changes. GitHub PR search
for SHE-762, crash recovery and conflict resolver returned no matches. A broader
draft search returned existing motion/catalog/demo work (including PR 87 / SHE-324);
this change does not duplicate those foundations. Search results are discovery
rather than evidence that every historical PR was reviewed.

Implemented recovery in the existing guided private proposal workspace. Legacy
citizen drafts, amendments and journals retain their existing save contracts.
Navigation and Participation & privacy link to that workspace. No motion framework,
first-run demo, theme setting, external submission or new API was introduced.
Exact values remain escaped React text, without semantic/political rewriting.

Autosave waits 500 ms after edits. Return visits ask before restoring; stale saves,
storage events and refocus trigger explicit saved/current comparison. Web Locks
serialize cooperating tabs and exact raw-envelope comparison rejects stale writes.
Envelopes include checksums and UUID revisions; prior envelopes remain in unique
history keys before replacement. Corrupt/unknown storage is not overwritten.
See docs/citizen-proposals.md for storage boundaries and complete copy fallback.

## Validation and remaining acceptance

- `bun run typecheck`: passed.
- Focused recovery, guided UI, documentation and navigation tests: 11 passed.
- `bun test`: 478 passed, 26 failed. Failures report local HTTP child servers
  unable to bind ephemeral port 0 (`EADDRINUSE`); this run is not a green suite.
- `bun run test:routes`: failed at the same port-0 listener startup.
- `git diff --check`: passed.

Regression coverage includes simultaneous stale saves, retained prior snapshots,
checksum corruption, legacy v1 reads, quota and unavailable-lock fallback,
autosave without clicking Save, restore prompt and explicit cross-tab conflict
choice, escaped content and no private-workspace network requests.

Controls are native labelled buttons/textareas with ordinary focus order; saved
and current text are labelled independently of color. Autosave uses no animation
or polling and is independent of reduced-motion/off/slow settings. Native keyboard,
screen-reader, touch, low-power, narrow-screen and zoom checks are still required
before human acceptance. This work does not claim those checks were completed.

Last edits inside the 500 ms window can be lost on crash. Safe persistence requires
Web Locks and cooperating current-version tabs; older tabs must be closed. Storage
is unencrypted profile-local data, without account backup; clearing storage loses
it. History grows until quota, then saving fails without pruning previous work.
Fallback is the complete read-only recovery copy; keep the page open and copy it
to a trusted file, then manually restore fields after repairing storage.
