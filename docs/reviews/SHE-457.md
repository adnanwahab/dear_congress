## Implemented behavior

Three parameter tiles contain native draggable range controls: annual budget,
annual per-household grant and income ceiling. Six fictional household incomes
are disclosed. The only calculation is income <= ceiling and eligible count ×
grant. Bounds and increments are validated by the typed shared calculation.
Over-budget results report the shortfall without automatically selecting or
denying households. No legal or welfare model is inferred. Every tile explains
possible gains/losses and absent evidence. A shared missing-evidence disclosure
covers real household data, take-up, fiscal estimates and legal review.

Undo restores the last parameter state (100-change history); Reset restores
initial assumptions and is itself undoable. Reload discards all changes. The
export is unsigned JSON with repository/fixture identity, parameter assumptions,
result, missing evidence and explicit absence of civic authority. Copyable JSON
is available if browser downloads fail. No endpoint was introduced. Component
state and pure calculations have no dependency on legal text, ballots, private
journals, persisted plans, comparisons, PRs or governance storage.

This is a bounded fixture sandbox, not calibrated policy negotiation. It does
not expose unsupported real policy eligibility or claim verified participation.
The public guide and README describe the demo boundary.
