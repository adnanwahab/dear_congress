## Changes and boundaries

Reports are bounded, same-origin for browsers, rate-limited by the existing IP/ID
budget, deduplicated per entry/reporter, and private. Each shared journal entry has
a Report button with explicit reason submission and visible outcome/error.
Reports do not themselves hide entries.

/admin/moderation requires the existing server ADMIN_TOKEN (Basic browser login;
Bearer supported). The decision API also checks the secret and requires exact
same-origin Origin, bounded JSON and a nonblank reason. Missing configuration
fails closed. All entry text, author names and report reasons are HTML-escaped.
The external same-origin script works with the existing CSP; no token is embedded
in HTML, URLs or JS. Private responses are no-store. The view permits reasoned
hide decisions on all entries and approval of pending entries only. An append-only
decision list retains hide/approval history. Original records and source IDs stay
in storage; demo reset retains moderated entries and moderation evidence.

Common emails, US/local/international phone formats and numbered street-address
formats in text or author trigger an HTTP 202 private hold on all three journal
aliases before LLM calls, emergent needs or answer/ballot creation. Held records
retain source/synthetic flags and privacy-clamped location/tile metadata. Approval
publishes as a journal only. The client displays a held notice and starts no live
publication pipeline. Heuristics can miss obfuscated/localized PII and falsely
hold legitimate prose. Existing entries are not scanned or changed automatically.

Hidden/pending records are excluded from public list aliases, state, SSE snapshots
and updates, map aggregation and both real/synthetic engine contexts (including
needs, synthesis demand and quotes). Approval metadata remains private. Citizen
proposal source lookup and new snapshot creation cannot retrieve moderated
journals. Independently published proposal text, votes, revision bindings and
historical frozen plan artifacts are retained; this is not proposal moderation or
retraction of external copies. Already loaded pages update through existing SSE;
static external copies cannot be recalled.
