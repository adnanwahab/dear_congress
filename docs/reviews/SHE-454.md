Refs: https://linear.app/shel-bernstein/issue/SHE-454/joydeliberation-amendment-family-tree-with-animated-branches

## Audit and implementation

Read repository instructions, readme, citizen proposal, accessibility, motion and
launch merge documentation. Audited existing editor, storage and DOM walkthrough.
GitHub PR search found amendment predecessors #35 and #59; metadata confirms both
merged into main. Neither PR's process-completion wording establishes acceptance.

Implemented browser-local explicit parent revision, fork, compromise and merge
relationships. No ancestry is inferred for legacy snapshots. Each relationship is
validated against earlier records from the exact source snapshot; duplicate IDs,
missing/self/cross-base parents and invalid event cardinality fail closed. Saves
append snapshots without changing earlier records or any public proposal/vote.

Branch links preserve existing route/query/hash and carry source kind/ID plus
revision ID. Selection reveals citation, timestamp, unreviewed state, origin and
exact-text diffs against each parent. Merge and compromise are manually reconciled
private text, never legal enactment or governance approval. Links require the
same local records and do not transfer data; users must open the matching proposal
in its civic workspace. Missing records get an explicit error. Source changes
still require a fresh start. No API, network request or asynchronous loading state
was introduced. No production or live-reference writes were made.

## Verification and remaining acceptance

Focused model and isolated Happy DOM checks pass, including forks, two-parent
compromise/merge, legacy compatibility, corrupt graph rejection, exact source
isolation, deep-link reload, unavailable links and zero network requests.
Native anchors/buttons/selects support keyboard and touch without hover gestures.
Branch entry animation uses motion scale and disables under reduced motion or
motion=off. CSS stacks comparisons on narrow screens and wraps long identities.

Native browser touch, full keyboard-only navigation, back/forward, 200% zoom,
forced colors and screen-reader acceptance remain pending human/browser review.
DOM tests are not evidence that those journeys passed. Broader check results are
recorded below. Keep the Linear issue open pending human acceptance.
