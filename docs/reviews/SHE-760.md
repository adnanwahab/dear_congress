## Scope and audit

Reviewed repository README, AGENTS.md, motion foundation, accessibility acceptance
and launch merge policy before implementation. Baseline: 1305bc0 on this worktree.
GitHub PR search for RTL in titles/bodies returned no matches. Related motion
search returned existing proposal lifecycle/mosaic and route choreography work
(including PRs #142, #139 and #242); these are not acceptance evidence or changes
imported into this older checkout. No first-run demo, theme or parallel motion
foundation was added. Reconcile against current main before human merge review.

Card/ranking and navigation DOM order is retained; CSS uses logical text alignment
and inline spacing. Nothing reverses data arrays, tab order, stance ordering or
priority scores. Back's decorative arrow and stage swipe direction mirror in RTL;
vertical Top and external-link symbols retain their meaning. Page transitions
mirror their horizontal travel using existing motion rules. Top now honors motion
off/reduced motion. No additional animation, polling or low-power work is added.
Native numeric inputs/range scrubbers deliberately retain LTR direction and their
existing numeric values/keyboard semantics in both layouts. No custom slider is
introduced. Textareas use automatic direction; source metadata and final current/
proposed legal text use bidi isolation without rewriting stored strings. Code and
preformatted machine output remain LTR. Citation URLs/identities and download
payloads remain unchanged. These safeguards are a foundation, not an exhaustive
RTL certification of every screen, chart, map or animated intermediate legal text.

## Preview and fallback

Participation & privacy has a labeled Reading direction select. This is explicitly
a layout preview with English copy; Arabic/Hebrew mixed-text fixtures are synthetic
stress samples, not human-reviewed translations. No language approval is claimed.
`?layout=rtl`/`?layout=ltr` applies before initial shell render and persists in
sessionStorage across tab navigation; an explicit valid query wins. Changing the
select updates the root direction without remounting the application or submitting
anything. Return to Left-to-right in the select, or use `/account?layout=ltr`.
Remove an explicit RTL query before navigating back to it. If storage is blocked,
only the current page changes; authored direction remains the next-page default.
Use `?motion=off` and ordinary navigation links when motion or swipe is unsuitable.
Layout never calls write APIs or touches draft content, ballots, authentication,
repository/item-kind bindings, PR revisions, records or receipts.
