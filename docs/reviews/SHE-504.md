# SHE-504 — Cooperative policy-design missions

Refs: https://linear.app/shel-bernstein/issue/SHE-504/joytogether-cooperative-policy-design-missions

Implemented a same-device workshop, documented in ../citizen-proposals.md. It
connects the existing sample Draft stage and citizen details to a separate shared
draft with optional roles, group permissions, reasoned evidence review milestones,
unresolved questions and JSON collaboration-log export. No remote group service,
authenticated membership, source verification or public submission is claimed.
Keep the issue open for human acceptance, including whether a same-device group
satisfies the intended delivery scope. Multi-device collaboration requires a
separate authenticated membership/consent/concurrency design.
