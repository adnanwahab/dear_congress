# SHE-607 — Branch subway relationships

Refs: https://linear.app/shel-bernstein/issue/SHE-607/civicplaypatch-arcade-branch-subway-map-for-related-issues-prs-and

Implemented a read-only relationship map and searchable semantic table in the
repository PR/issue browser. Both render the same typed graph. PR revision,
repository, source status, loading/error/stale state, permissions and eligibility
reasons remain visible. Search and navigation never invoke ballot, feedback,
merge or civic vote APIs. Existing vote records and version keys are unchanged.

## Audit and source limits

Read readme.md, AGENTS.md, docs/repository-voting.md and
docs/launch-merge-policy.md, and inspected GamePatches, LiveRound and GitHubSource.
GitHub searches of this repository found no SHE-607 PR; the open PR search
returned existing unrelated draft review candidates. No external writes occurred.
LiveRound carries advisory civic item data without a GitHub relation receipt;
no synthetic implementation edge was added to it.

GitHubSource now retains head repository/ref and commit parent SHAs already
returned by its existing GET requests. Fork branch links retain their fork
repository. A base target is explicitly not an ancestry claim. Parent edges
represent only the commits reported by GitHub; missing/inaccessible detail evidence
shows ancestry unavailable, and no complete branch history is claimed. Existing
cached entries without the optional metadata remain usable. Explicit GitHub and
Linear description URLs are labeled unverified contributor relationships; IDs
are not extracted from titles or used to invent links. Cross-repository links
retain their full source identity. No change to revision binding or storage schema.

The graph uses static CSS tracks, native links, semantic headings and a table
with column headers. The table has a keyboard-focusable horizontal scroll region;
search is labeled, focus is visible, and cards adapt to available width. Reduced
motion disables animation and transitions in this region.

## Preserved governance

No policy or environment values changed. The pilot's automatic merge capability
lock remains in place. Defaults remain disabled/dry-run, quorum 10, 24-hour
exposure, one current-head approval, strict yes majority and empty base/check
allowlists that fail closed. Protected base/current-head evidence and existing
authentication/CSRF requirements remain required. Issues never authorize merges;
community browser choices remain separate from verified ballots. Production
values and GitHub branch protections were not modified or verified. A human
maintainer must review the current revision and decide on acceptance/merge;
production releases remain human-published tagged releases.
