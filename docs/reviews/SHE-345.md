# SHE-345 — Complete civic themes and circular theme switch

Refs: https://linear.app/shel-bernstein/issue/SHE-345/demomotion-finish-dark-mode-and-add-a-theme-switch-with-a-circular

Implemented complete light/dark semantic palettes on `html[data-theme]` for the
shared civic screens. Cards, fields, notices, workflow progress, outcome badges,
documentation, amendment comparisons, county map panel and neutral policy bars
inherit the selected theme. Separate action/status foreground tokens preserve
text contrast without using a surface token as button text. The established
purple bottom navigation remains consistent with white text in both themes.

CivicHeader owns a keyboard-accessible System → Light → Dark control. The
`civic-theme` localStorage preference survives routes/reloads; missing, invalid
or blocked storage defaults to System. System follows OS changes; storage events
synchronize other tabs. With blocked storage a manual selection lasts only on
the current page. A tiny inline initializer precedes the entry module and CSS.
Its exact SHA-256 is allowed by CSP, and development/production bundle tests
verify the hash and order. No broad inline-script permission was added.

Theme changes use a typed View Transition and animate the incoming root clip
from the button center to the farthest viewport corner in 400 ms. During this
transition only, named chrome/content snapshots are folded into the root.
Navigation transitions retain their own styles. Reduced motion or unavailable
View Transitions update immediately; interrupted transitions retain the choice.
