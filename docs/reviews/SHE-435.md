# SHE-435 implementation review candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-435/joyworlds-animated-simulation-event-heatmap-by-time-and-place

Implemented a clearly labeled local demo on `/map`, using existing county shapes,
county-fips-v1 requirements, revision progression, county selection and motion
helpers. No new dependency, API, persistence or migration.

## Audit and scope

Read repository instructions, README, motion, accessibility, launch merge policy
and native law behavior documentation. Audited MapScreen, county-simulation,
LawBehaviorExplorer's receipt parser, simulation snapshots and package dependencies.
GitHub PR search for heatmap/SHE-435/Worlds returned related #120 and drafts
#155–157, with no matching heatmap. These related candidates are not acceptance
or deployment evidence.

The existing external simulator receipt supplies sampled actor checkpoints in
local x/z coordinates but no event IDs or reviewed geographic binding. Mapping
these onto Census counties would invent evidence. This increment instead logs
exact deterministic county status transitions, replayed from the initial plan
using existing improvePlan/countyVote functions. Each ID binds model, revision
and county FIPS. Revisions are simulation time buckets, not dates. Intensity is
0 or 1 status-change events per county per revision; unchanged states produce no
event. Initial evaluation counts unevaluated → evaluated as an event.

Boundary evidence and synthetic event layers have independent controls. The
selected bucket has a complete scrollable table with inspect buttons; selection
focuses the example and updates the existing county inspector. Playback is
explicit, pausable and bounded to completed revisions. Scrubbing pauses it;
model revision changes and restart reset playback. Reduced-motion/off modes step
manually, and a preference change stops active playback at its next tick. Static
SVG does not require WebGL. Absent SVG, SSR, forced colors and user table-only
selection retain the table. No provider request occurs, so loading/failure states
are not applicable to this local view. Empty buckets and initial state are explicit.

This does not implement external-world event ingestion. That requires a reviewed
provider event contract with geographic identity, time units and provenance.
