# SHE-331 — Guided demo implementation candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-331/demo-add-a-play-the-60-second-demo-guided-tour

Implemented the home-page “▶ Play the demo” link and shareable `/?demo=1` entry.
Seven stops run Published → Feed → Votes → Draft → Sponsors → Outcomes → Map.
The first six dwell for eight seconds each; Map dwells for twelve seconds (60
seconds total plus full-page loading time). The final stop remains visible with
“Demo complete” and Exit. Each stop has a short caption and persistent sample-data
and read-only labels. Existing sample/provenance disclosures remain in the page.

URL parameters carry the zero-based step and pause state across full page loads.
Invalid steps restart at Published. Space pauses/resumes, arrow keys step, and
Esc exits on the current page. Buttons provide the same controls. Stepping while
paused remains paused. Pause preserves the remaining dwell time; reload restarts
the current stop's dwell. Hidden tabs pause. Ordinary page clicks pause and are
consumed before application handlers; the page and bottom navigation are inert
throughout the tour, so keyboard activation cannot cast a vote or save a draft.
Exit restores ordinary interaction. The tour does not perform write API requests
or write local/session storage. Workflow proposal-selection storage writes are
skipped in tour mode, and an old session selection is ignored for tour entry.

Map starts its existing in-memory nationwide simulation automatically, and tour
pause/resume controls it. No resident ballots, snapshots or saved plans are
created. Full-document navigation reuses SHE-323's existing View Transitions,
including reduced-motion behavior and ordinary navigation fallback. Map uses the
existing utility-page fade. A ResizeObserver places the overlay above the bottom
bar as it wraps on smaller viewports. Underlying controls remain visible but
unavailable until Exit; the overlay explains that this is a read-only tour.
