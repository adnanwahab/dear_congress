# SHE-906 · honest simulation fallback

Refs: https://linear.app/shel-bernstein/issue/SHE-906/cs-l100057-provide-an-honest-fallback-when-the-world-simulation-is

## Candidate implementation

The native /synth LawBehaviorExplorer now shows textual assumptions, a static
precomputed fictional bus-wait example and an explicit Retry live simulation
button when a request fails, times out, lacks browser fetch/AbortController, or
returns an unsupported mechanism. The example uses expected wait = interval / 2
under uniform arrivals and regular unlimited-capacity service (20/2=10 and
10/2=5 minutes). It is authored teaching arithmetic, not an archived HBL run,
measurement, official claim, current scenario result or forecast. It never enters
receipt state, exports, postcards or model playback. Reading and advisory views
remain available. No graphics capability is required for the native React viewer.

The 45-second deadline now invalidates the request generation, ends loading and
aborts directly. A provider that ignores abort or stalls while reading its body
cannot leave the spinner running or install late results. Retry clears fallback
and current receipt; existing identity/version/horizon validation remains intact.
Public guide and its contract test explain the distinction.
