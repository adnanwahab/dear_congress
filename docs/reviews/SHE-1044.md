## Exact source and behavior

Vendored full upstream handoff bytes in
src/server/fixtures/policy-demo-hbl-handoff.json, from
adnanwahab/happybearlandia PR563 commit
`bf08f457188e38a277d744c236dfba9fc0b02731`, raw SHA256
`1baf5434cd1f4d28107890e74ce0a06d3da6124617f3ca406e8935a90ef1bf2c`.
This is a deliberate golden input/provenance fixture, not generated screenshots
or a second protocol/engine. Full seeds, metrics definitions/distributions and
output receipts remain in that exact artifact; only selected input metadata
enters the shared client catalog. Local preview IDs/URLs in the source fixture
are not surfaced as successful production links. No network simulation occurs.

Shared catalog deeply freezes exact titles, legal clauses, baseline/proposal
identities, canonical hashes, mapping/model versions, seed42/100pairs/24months,
checkpoint0/12/24 and limits. Tests compare every exported field to source bytes.
Mappings are existing software registry mappings, not completed legal review.
Unsupported constitutional text retains its exact diff with Not Modeled.

Server createPolicyDemoAuthority creates process-local opaque grants. Only a
trusted server-created draft with the exact baseline/proposal tuple and explicit
public-transfer confirmation can prepare the unchanged source payload. Copies,
grants from another authority, changed title/type/text/version and private extra
fields fail. Unsupported input returns no payload. This is intentionally NOT a
persistent authorization or public route. It does not replace owner/CSRF/privacy
checks, acceptance, publication or voting authority.

Picker displays exact amendment, version IDs, legal hash, model/mapping and
limitations for all four drafts. Native select/button/details support keyboard;
text wraps at390px. Without onSelect it is visibly pending and disabled. With an
adapter it only opens the existing save workflow and never reports a successful
save or simulation. Failure gives a neutral retry message without server details.
No arbitrary href, remote ID, iframe, browser credential or fake success is added.
