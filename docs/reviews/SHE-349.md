ProposalProvenance now accepts compact, used only by Feed and Published cards.
Its native details/summary retains the exact visible sample-status phrase,
jurisdiction, named HTTPS source link and freshness. The full existing block,
including publisher, scope and disclaimer, stays inside the disclosure for
assistive technology when expanded. Native activation supports click/tap,
Enter/Space and expanded state without duplicating ARIA state. Following the
source link navigates independently of toggling the summary.

A single source line scrolls horizontally on narrow cards rather than truncating
facts or wrapping into a tall block; the sample-status phrase is first. Full
expanded text wraps. This narrow-card interaction still needs visual/touch QA.
The selected Feed panel now includes the full block (missing in this baseline).
Votes and Draft keep the default full rendering; draft export is unchanged.

Scoped workflow.css motion follows #100's feature-gated intrinsic-size pattern,
with contained margins, opacity and discrete content-visibility for both opening
and closing. Reduced motion disables transitions. Unsupported engines retain
native instant disclosure. It uses the existing motion duration token. Scope
specificity prevents #100's generic summary arrow from adding a second marker;
recheck shared styles when integrating the pending motion/mobile PRs.
