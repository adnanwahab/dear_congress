# SHE-328 implementation and review evidence

Refs: https://linear.app/shel-bernstein/issue/SHE-328/demomotion-let-sponsor-tracker-cards-glide-between-columns

The home and Sponsors tracker now share SponsorBoard. Stage dropdowns and
mouse/touch pointer handles save through the existing parent storage functions,
using the unchanged civic_demo_tracker_v1 key and record format. No cards,
proposal identities, ballots, PR revisions, receipts or server data are migrated.
The local demo/no real outreach wording remains visible.

Card identities become stable CSS-safe view transition names. Stage changes use
startViewTransition with flushSync; browsers without that API update immediately.
Reduced motion skips the transition. Dropdown focus follows the moved card;
a polite live region announces successful saves. Drag cancellation and drops
outside the board leave the record unchanged. Only the handle disables touch
scrolling, leaving card content and dropdowns usable normally.

Outcome totals animate on mount and value changes, expose the final numeric
value to assistive technology, cancel obsolete frames, and immediately finish
when reduced motion is requested. Existing cross-tab storage updates continue
to refresh Outcomes.
