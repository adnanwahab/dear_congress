## Audit and scope

Reviewed the repository instructions, README, launch merge policy, repository
voting documentation, SHE-315 review and native model behavior documentation at
base `1305bc0`. Inspected PolicyMeasurements, AccountScreen, measurement contracts
and existing receipt boundaries. The connected GitHub PR search scoped to
`adnanwahab/dear_congress` for `"time capsule" OR "SHE-767" OR "measurement"`
returned no matching PRs. This is a point-in-time search, not an exhaustive audit
of every PR. No production app or public source data was fetched or modified.

Implemented a bounded synthetic session rehearsal, not full issue acceptance.
The existing measurement baseline supplies revision, population, unit, period and
fixture origin. Required metric, fictional jurisdiction, future UTC date, finite
threshold and explicit prediction become a frozen typed receipt. Controls disappear
after freezing. There is no storage, network request, public publication or vote.
AccountScreen links to the rehearsal and explains its privacy/loss boundary.

Every baseline is explicitly invented, with no external retrieval timestamp;
method is illustrative fixture construction and uncertainty is unavailable.
Thresholds are personal estimates. The timestamp comes from the device clock.
This is neither durable sealing nor protection against browser tampering.
Reloading/leaving loses the receipt. No actual outcome is scored; missing evidence
stays unavailable. Existing model receipts remain in the synthetic sandbox and
are never relabeled as public evidence or fabricated as attached forecast runs.

## Demo and remaining release gates

1. Open `/account`, follow the private forecast link to `/outcomes#time-capsule`.
2. Select Typical bus wait and Fictional transit pilot. Inspect the invented
   baseline provenance; enter a future UTC date, threshold and assumptions.
3. Freeze the session forecast. Inspect its receipt, timestamp caveat, lack of edit
   control and unavailable observed evidence. Confirm no public result is claimed.
4. Reload and confirm the clearly disclosed loss of page-memory data.

Before a real launch, implement authenticated ownership and server-authoritative,
append-only seals with trusted timestamps; define deletion/retention permissions;
add private-by-default storage and explicit consented publication. Register reviewed
real policies and public source snapshots with release/retrieval timestamps,
methods, uncertainty, hashes and revision histories. Match observations to the
sealed metric definition, jurisdiction, population, unit, method and exact horizon;
show publication lag, missing data and revisions without changing the forecast.
Keep forecasts and synthetic model receipts separate from official results and
causal evidence. Do not derive representative consensus from participation.

Cross-device persistence, retry/recovery, public consent/revocation, actual future
comparison, real source receipts, performance measurement and manual desktop/mobile,
keyboard, screen-reader, zoom and reduced-motion acceptance remain unverified.
This increment adds native labeled controls and no motion, but DOM tests do not
establish visual or accessibility acceptance. Keep SHE-767 open for human review.
