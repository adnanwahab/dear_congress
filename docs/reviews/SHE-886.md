## Implemented

Documentation now includes an anchored registry and table-of-contents entry.
Each row exposes publisher, original URL, retrieval date, licensing note, scope
and last review, with an explicit content-kind label. Sample background rows
project existing IDs, publishers, URLs and check dates without altering originals.
The inventory includes learning references, core outcome adapters, the Oregon
study, Senate text citation, Census transcription specimen, Congress provider
and a clearly identified internal synthetic fixture entry. A provider entry is
not a replacement for an individual bill's exact URL/hash/checkedAt.

No source was newly retrieved or license approved. Missing retrieval and review
dates stay unknown; historical document periods and source checks are not relabeled
as retrieval dates. Public accessibility does not imply redistribution rights.
The copy/print JSON retains unknown fields and coverage limits. The registry
never reads journals, browser choices, production records or credentials; source
inspection cannot authorize voting, code merges or policy claims.

## Acceptance remains open

This is a partial inventory, not complete satisfaction of “each nontrivial” source.
Remaining work includes map/geographic asset provenance, other editorial and
learning citations, per-record imported-bill coverage, curated concept sources,
user-supplied citation handling and individually enumerated synthetic fixture
families. Source and item identities must remain separate when the same URL
supports several contexts. A future completeness check should compare registered
source-use IDs with each supported module's structured citation exports, rather
than treating every hyperlink as evidence or silently deduplicating contexts.

Source stewards must record actual retrieval evidence, exact source versions,
applicable license/terms and restrictions, and dated human reviews where required.
Unknown licensing is honestly exposed but does not establish public reusability.
The registry should not inherit a human approval from a source check or a review
of another version. Do not fabricate retrieval dates from fixture generatedAt or
fetchedAt. Starter outcomes remain unverified fixtures. Native mobile, keyboard,
screen-reader and print verification remain outstanding. Keep SHE-886 open until
a human verifies the complete inventory and required source/safety/editorial
reviews; this local implementation is only a review candidate.
