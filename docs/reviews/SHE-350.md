# SHE-350 — Disclosure and dialog motion

Refs: https://linear.app/shel-bernstein/issue/SHE-350/demomotion-smooth-open-and-close-for-every-disclosure-and-dialog

Implemented shared CSS in styles.css for every native details (including nested
ScoreInspector sections, PolicyComparison and ProposalReadingHelp). Content uses
intrinsic block-size interpolation, opacity and discrete content-visibility.
A flow-root contains child margins to avoid endpoint jumps. Direct-child summary
selectors rotate each disclosure's own arrow independently. Feature gates preserve
native instant disclosure behavior where intrinsic interpolation is unavailable.
Reduced motion disables all disclosure/dialog transitions, including pseudo-elements.

Native dialogs share fade/scale, starting styles, dimmed backdrop and discrete
display/overlay transitions. VoteBatch uses closeDialog to keep the dialog open
and modal until its CSS exit finishes, then close and return focus to the trigger.
The helper waits on actual animation completion rather than a duration timer;
cancelled animations settle safely. Effect cleanup cancels a stale close on reopen
or unmount. Missing platform capabilities and reduced motion close synchronously.
New native dialogs inherit CSS automatically; use closeDialog for Close and cancel
paths when focus must stay trapped until exit. Keep the element mounted through
exit. Direct native close() inherits exit CSS but restores native focus immediately.
