# SHE-459 — Fact-check detective implementation candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-459/joydeliberation-fact-check-detective-game-with-real-citations

## Implementation

`ArgumentMap.tsx` mounts a local practice game only within its existing exact-text,
repository/fictional-demo namespace and transit proposal binding. Available on
Published, transit Votes and an exact-revision comparison containing transit.
Other proposals, stale text and foreign namespaces cannot inherit it. Existing
stage links, argument disclosures and advisory controls remain available.

Four editorial statements about historical H.R. 3684 cover claim, inference,
uncertainty and opinion. All choices reveal the teaching classification and
reasoning, including mismatches. Definitions explain that a claim is checkable,
not automatically true, and that statements can overlap. No political score,
leaderboard, timer, storage, requests, participation credit or receipt is added.
Practice resets when unmounted or reloaded. Original proposal identities, source
links, votes, PR head/base bindings, records, receipts and production data remain
unchanged. No new API was necessary.

Citation: [Congress.gov enrolled text](https://www.congress.gov/bill/117th-congress/house-bill/3684/text/enr),
Division J, Title II, NTIA, Broadband Equity, Access, and Deployment Program.
The bundled short excerpt preserves the $42,450,000,000 appropriation and its
availability until expended. Checked November 14, 2026 against the original.
[Congress.gov actions](https://www.congress.gov/bill/117th-congress/house-bill/3684/all-actions)
confirms enactment November 15, 2021. The UI distinguishes enactment from source
check date and current program outcomes. The inference, uncertainty and opinion
are authored teaching examples, not attributed quotations or verified outcomes.
The real bill is explicitly separate from the fictional transit proposal.

The exercise has no asynchronous load: its source excerpt and reasoning are bundled.
The parent retains its existing loading/failure/retry states. An external source
failure cannot be detected across origins; visible guidance retains the excerpt
and locator and suggests retrying the original link. This is not a live link-health
or current-law verification service. Public guide and README explain these limits.
