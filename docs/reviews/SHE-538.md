# SHE-538 — weekly civic discovery

Refs: https://linear.app/shel-bernstein/issue/SHE-538/joydiscover-weekly-civic-festival-and-themed-learning-events

## Audit and implemented scope

Inspected Dashboard, DailyQuestion, typed demo payload, public guide, citizen
proposal documentation, accessibility/motion and launch policy. GitHub connector
searches for SHE-538 PRs and open festival PRs returned no matches on November 14,
2026; this is a targeted overlap audit, not an exhaustive review of every PR.
The shell GitHub client could not connect.

Dashboard now offers optional weekly themed self-guided trivia, evidence tours
and a proposal walkthrough, all available anytime. It reuses Dashboard's typed
GET /api/demo result; no new endpoint, write, attendance record or reward is added.
The walkthrough retains the sample proposal ID when linking to the existing feed.
Loading, unavailable and empty states leave the other sessions usable. A failed
vote with an already loaded sample does not become a walkthrough loading error.

Official external event discovery links to https://www.loc.gov/events/.
The official calendar search result was reviewed November 14, 2026 and includes
online and physical location filters. Direct fetching returned 403; no individual
event, location, availability, partnership or local gathering is asserted verified.
Users must confirm details with the organizer. A hypothetical picnic has its own
explicit unscheduled label. Sample proposals, real advisory choices and simulated
sponsor outcomes remain distinct. No rewards depend on ideology, real/advisory
votes or recruiting voters.

## Acceptance gaps

This is a bounded self-guided learning implementation, not full hosted-event
acceptance. No organizer, hosted recurring schedule, verified individual event or
operational moderator/reporting workflow is supplied. Public event discussion is
explicitly unavailable, so it cannot expose an unmoderated event comment channel.
A human must establish those operations before publishing hosted sessions.
No existing citizen-proposal comments are repurposed as event discussion.
Leave the Linear issue open pending human acceptance.

Native details/summary disclosures provide ordinary keyboard and touch controls,
44px summary targets and explicit focus outlines. Layout wraps narrow text and
introduces no animations, so reduced motion needs no new animation override.
Browser keyboard/touch, 390px layout and OS reduced-motion visual validation have
not been performed; native semantics and static markup tests are not that evidence.

bindings, records or receipts changed. Source defaults remain disabled/dry-run,
quorum 10, 24-hour exposure, current-head approval, fail-closed allowlists and an
