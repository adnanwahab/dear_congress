## Audit and changes

Read AGENTS.md, readme.md, launch merge policy and the SHE-319/SHE-303 module
reviews. Inspected JournalScreen, JournalSharing, SharedJournalFeed, live feed,
existing App deletion control, publish contract and server ownership deletion.
Read-only GitHub journal PR search returned earlier privacy/inference work
including #21/#73 and #37/#57. Inspected #73's changed-file patch: its sharing
implementation follow-up is historical documentation. SHE-800 search returned no
PR. This bounded audit does not establish the state of every remote branch.
No remote code was imported and no external messages were posted.

The current route already freezes the normalized excerpt, display name and
selected labels; shows the public feed/API data notice; requires an initially
unchecked confirmation; and clears review/consent on edits, cancellation,
submission or offline failure. The UI publish handler independently guards against
missing confirmation and duplicate clicks. The checkpoint sends only the reviewed
allowlisted excerpt, never the working draft. Legacy public API clients retain
existing contracts; this is a journal-writer UI checkpoint, not proof that an API
caller actually read a preview.

Added explicit preview origin/source disclosure for the built-in synthetic sample,
and removal instructions beside the data notice. Existing names, selected-category
preview and public-data/deletion limitations remain visible. Updated public guide
and README with the review behavior.

Found that Delete my entry was implemented only in the older App journal view.
The active route now reads ownEntryIds from the existing signed-browser state
response and exposes deletion beside owned feed entries, including after reload.
Newly published entries receive the same control. Cancel sends nothing; errors
retain the entry and show retry guidance; confirmed success removes the visible
entry/result. The server remains the ownership authority and its endpoint is
unchanged. No foreign ownership is inferred from display names or advisory votes.
