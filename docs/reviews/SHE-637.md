## Implemented

Native disclosure nodes have solid coded and dashed inferred borders plus text
labels, responsive single-column layout, touch-sized controls and visible focus.
No automatic model runs or topology animation are introduced. The validated
receipt, amendment revision, consumer identity and exact scenario inputs are
inspectable as a local JSON reproduction receipt. Sharing preserves the existing
version-pinned scenario flow, without storing or sending private data. Typed
request construction validates the existing law/strength/seed allowlist and
sends only the four provider fields. No new simulation mechanism is invented.

The board exposes source mode, seed, available model version, requested/recorded
horizon and major uncertainty in initial/loading/failure/completed states.
Household readiness and scoring views disclose their own absent/inapplicable
simulation provenance. Household selections remain local, with no fabricated
cohort effects. Score arithmetic remains separate from HBL observations.
Reduced-motion playback advances one checkpoint per activation instead of
starting a timed sequence; ordinary playback behavior is preserved.
