# SHE-593 preview lens implementation review

Refs: https://linear.app/shel-bernstein/issue/SHE-593/civicplaymotion-preview-lens-with-inert-hoverfocus-route-thumbnails

Audited README, repository instructions, motion foundation, chapter catalog,
Navigation and launch merge policy before implementation. GitHub searches for
SHE-593 returned no PR; open preview search returned #236 (build readiness pulse),
which does not implement destination previews.

The lens lazily imports only authored chapter metadata. It does not load destination
HTML or mount interactive route components. React escapes all summary strings.
The existing link retains its exact topic/proposal identity and normal navigation.
Hover/focus opens a summary; a separate Preview button supports touch. Escape,
Close preview, blur and pointer exit dismiss it. Late results are ignored after
cancellation; slow/error loads offer a fallback after four seconds. Animation
uses the existing motion helper and never controls navigation.

Validation in this workspace:
- Focused tests: 3 pass, covering lazy/inert idle markup, route allowlist, escaped
  text, successful focus, failure and interrupted completion.
- `bun run typecheck`: passed after the final test addition.
- Full `bun test`: 475 pass, 26 fail; failures occur starting local servers with
  EADDRINUSE on port 0. No server behavior was changed.
- `bun run test:routes`: blocked by the same port-0 listen error.
- Browser success/failure tests added to the existing Playwright suite. Execution
  blocked by missing Playwright; dependency installation made no progress and was
  cancelled. Browser rendering, real touch and screen-reader acceptance remain
  unverified. Run these checks in an environment with browser tooling and local
  listening available before acceptance.

No production records, ballots, receipts, source/revision bindings or governance
configuration were changed. Existing governance remains disabled/dry-run, quorum
10, 24-hour exposure, current-head checks and approval, fail-closed allowlists and
active kill switch. Main protections require human approval and the three checks
listed in docs/launch-merge-policy.md; external enforcement was not verified here.
No merge, deployment, release, external message or Linear status change occurred.
The issue remains open pending human verification; this implementation is a review
candidate, not acceptance evidence.
