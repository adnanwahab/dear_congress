## Reproduce

Run `bun test`, `bun run typecheck`, `bun run test:routes`, and
`bun run test:policy-impact-ui` after installing the accessibility package's
Playwright dependencies and Chromium. This run used
`PLAYWRIGHT_MODULE=/Users/wahabma/happybearlandia/node_modules/playwright/index.mjs`
to select the already installed browser driver. The harness creates and removes
its own temporary database, obtains publishing authority through the normal UI,
and restarts its server with the same database and cookie signing configuration.
It never supplies a forged browser identity or production database.
