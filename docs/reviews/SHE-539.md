## Implementation

One RealityLens component in CivicHeader appears across Dashboard, Feed, Votes,
Needs, Synth, Map and Outcomes, including the generic loading shell. Removed the
blanket default SAMPLE DATA badge, which incorrectly described mixed pages.
Explicit caller-provided labels remain supported. Actual browser activity is
unverified, sample stories and tallies are fiction, models are model output,
and source-backed records retain their own source/date limitations. Missing
origin or unavailable counts are unknown, never evidence of zero or verification.

Compact/expanded is a legend detail preference, not an origin filter or synthesis
mode. It persists under civic-reality-lens-v1, handles invalid/blocked storage and
cross-tab changes, and never enters an API request or tally calculation. Existing
item labels remain visible regardless of preference. No vote conversion,
aggregation, migration, source reclassification or data write was introduced.
The public guide describes these semantics.

The native button exposes aria-expanded/aria-controls and retains focus. Its touch
target is at least 44px; the layout wraps, with no new animation. Expanded mobile
workflow headers stop being sticky so long explanations can scroll. This does not
constitute native browser or assistive-technology acceptance evidence.
