# SHE-836 — Evidence-question sharing

Refs: https://linear.app/shel-bernstein/issue/SHE-836/cs-l100026-share-the-strongest-evidence-question-not-a-fabricated-poll

## Audit and implementation

Reviewed this repository's AGENTS.md, readme.md, citizen-proposals module docs,
launch merge policy, citizen feed/detail route and separate sample advisory share
builder. GitHub PR search for SHE-836, evidence question and advisory share found
related PRs #185 (SHE-535 sample advisory share cards) and #266 (SHE-684 data gaps
atlas); neither provides the citizen question share flow. No duplicate SHE-836
implementation was returned. No PR or issue state was changed.

Citizen proposals have immutable published text and free-form supporting notes,
not a structured unresolved-question registry. This implementation asks the
reader to select one factual question and explicitly review/copy the payload.
It does not fabricate or automatically rank questions. The original title/ID,
repository/item kind and available safe HTTPS citation links are retained.
Source links and unresolved status remain unverified. Empty citations are explicit.
The recipient's URL opens/focuses evidence after asynchronous proposal loading.
No totals, inferred stance, browser choice, comments, journal contents, receipts
or identity fields are read by the payload builder. Reader-entered public text
is not independently vetted. Query text is escaped and never saved to a proposal.

Scope is published citizen proposals, reachable from Feed and Votes. Existing
fictional sample cards are separate. No question backend, moderation registry or
automatic sharing is introduced. Questions are public in link/history/hosting
logs; the preview warns to exclude personal information. Clipboard denial offers
selectable plain text. The public guide and module docs explain these limits.
