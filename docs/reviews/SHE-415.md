The existing source-keyed editor now offers a collapsed sandbox with three
bundled fictional before/after clauses: permission becoming duty, a lower
eligibility age, and an ambiguous replacement for a numeric deadline. Native
radio selection and an explicit reveal gate feedback, the existing redline
comparison, local source chips linking the exact fictional clauses and edge
cases. Wrong guesses receive an explanation without blocking progression.
Next case resets selection and focuses its heading; replay restarts the set.

The game is independent of the selected citizen/sample proposal, drafts, storage,
ballots and projections. It reuses existing comparison/styles and civic route
placement, without adding a navigation stage. The simulator accepts bounded
reviewed model parameters, not these arbitrary fictional clauses; no speculative
API adapter or simulated impact is presented as legal effect. Source chips point
to exact local invented text, not official links that might imply authenticity.
The public guide and module documentation describe these boundaries.
