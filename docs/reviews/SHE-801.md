# SHE-801 — Needs map dependency fallback

Refs: https://linear.app/shel-bernstein/issue/SHE-801/cs-l100012-fix-the-needs-page-map-visualization-unavailable-state

## Audit and implementation

Read AGENTS.md, readme.md, launch merge policy and the SHE-354/SHE-289 map
reviews. Baseline 22a64db; repository origin is adnanwahab/dear_congress.
Read-only GitHub PR search found related #108 (SHE-354), #3 and #49 (SHE-270).
Their process completion is not acceptance evidence. The prior optional-map
implementation and source-specific geographic evidence list already exist here.

The unavailable state has multiple possible causes: absent MAP_STYLE_URL,
MapLibre import/initialization failure, resource failure, or initial idle timeout.
The server defaults MAP_STYLE_URL to empty. Missing configuration skips importing
MapLibre. The client previously conflated all these states in user copy and logged
no request ID. Geographic API failures were silently represented as empty cells.
The actual production cause is unconfirmed: web reads failed and local curl could
not resolve civic-synthesis.fly.dev. No provider configuration was invented or changed.

Local changes explicitly explain disabled maps, retain the searchable list's same
selected need, aggregate coordinates and separate submitted/simulated counts, and
identify geographic-data failures separately from missing/suppressed results.
Existing rankings and jurisdiction text remain independent. Configuration and
runtime dependency failures log a sanitized reason and browser-generated UUID
request ID to the developer console. These are local dependency-attempt IDs, not
server request traces or centralized production logs. Raw errors, URLs, private
inputs and credentials are never copied into these diagnostics.
