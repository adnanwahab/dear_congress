# SHE-502 — inline clause marginalia

Refs: https://linear.app/shel-bernstein/issue/SHE-502/joytogether-inline-clause-marginalia-with-source-anchors

Implemented a private browser pilot through the existing AmendmentEditor on sample
Draft/Votes and citizen proposal views. Repository README, amendment source/model,
SHE-305 review, workflow composition, motion guide and launch merge policy were
read before changes. GitHub searches found no existing SHE-502 PR; open PRs include
adjacent amendment family-tree work (#150/SHE-454). No external messages were sent.

Notes bind exact line numbers and quotes to SHA-256 revision IDs including the
source repository, kind, ID, origin, title, jurisdiction and full source text.
Repeated lines remain distinct. This is a local immutable snapshot contract, not
an official legal revision registry. Existing source text is not modified.
Changed snapshots orphan notes; explicit reattachment preserves prior anchors.
Corrupt or unavailable browser storage fails closed, retains editing text and
offers retry. Native buttons, selects, labels and focus outlines support keyboard
use; mobile stacks each margin beneath its source line. No animation is introduced,
so reduced motion uses the same static presentation.

Private note, Share for review and Report abuse are separate actions. Sharing
opens a selected-note excerpt for manual copying with disclosure of included
source text; nothing is sent. Reporting explicitly states that no report was
submitted because there is no reporting service. This deliberately does not claim
shared comments, moderation delivery, authenticated ownership or official legal
citations. Full acceptance still needs a consented server review/moderation service,
official clause ingestion and human mobile/keyboard/screen-reader verification.
Browser storage remains user-editable and device-local, not a durable audit log.
Concurrent tabs do not coordinate writes.

Validation: focused model tests cover revision identity, Unicode/repeated lines,
reload, source isolation, orphan/reattachment history and corruption. The isolated
DOM walkthrough covers saving, review excerpt, report disclosure, reattachment,
existing amendment behavior and /draft and /votes composition without network.
Typecheck passed. Full `bun test` ran 504 tests: 478 passed, 26 failed, including
server-dependent tests unable to bind a listening socket in this environment.
`bun run test:routes` also failed to start Bun.serve (EADDRINUSE on port 0).
These environment failures are not acceptance evidence; rerun required checks in
an environment allowing listening sockets. Focused checks passed after final edits.

Governance remains unchanged: disabled/dry-run defaults, quorum 10, 24-hour
exposure, current-head approval/check and protected-base gates, active kill switch.
No votes, PR bindings, records, receipts, auth or production data were changed.
Required main checks remain bun test, bun run typecheck and route smoke test plus
at least one human approval enforced by GitHub administrators. No merge, release,
deployment or live automation was performed. Keep the issue open for human review.
