The product shell owns one EventSource, shared by the ticker, legacy workspace
and Journal. The first snapshot establishes a baseline; later new IDs enter a
bounded queue. Each item stays eight seconds, pauses on hover or keyboard focus,
and disappears immediately when absent from a public snapshot. Session storage
remembers dismissal across page visits, with in-memory fallback when unavailable.
The link opens Journal with an entry query and highlighted story anchor, including
stories outside the first page. The server includes canonical need labels in
snapshots, without changing stored entries or source IDs.

Public journal projection deliberately omits all coordinates and tile IDs under
SHE-284. No approved neighborhood field exists, so the ticker says “Location not
shared”; it does not invent Alief or derive locations from text/coordinates.
Only a canonical need label, this location placeholder, Sample/Simulated provenance
and relative arrival label appear. Untagged stories say “Shared experience”.
Initial history is not advertised as new. Reduced motion disables entry animation.
A separate polite live region announces at most once per 30 seconds; withdrawn
items are cleared. Moderation continues to filter before public serialization;
client snapshot reconciliation removes retracted items even while paused.
