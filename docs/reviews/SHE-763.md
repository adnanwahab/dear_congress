## Implementation

`/playground` is lazy loaded and discoverable through Participation & privacy and
Navigation's utilities (including mobile More). Six deterministic local fixtures
cover success, pending, blocked, offline, synthetic and empty. They have no live
repository item IDs and no vote, submission, persistence or data API integration.
The shared participation notice retains advisory/verification boundaries.
The state selector uses the existing typed `filter` transition helper. Native
buttons, details disclosures and the existing native modal sheet styling support
keyboard and touch; modal close returns focus. No policy choices are presented.
No draft field, existing preference write or personalization is introduced.

## Fallback and contracts

Use Static preview / low power for immediate updates without snapshots or sheet
transitions. Existing `?motion=off` and OS reduced motion also skip shared motion.
All six states and provenance disclosures are always available in the static
gallery. Without showModal, the sample sheet appears inline with the same text.
Offline is a simulated fixture, not a promise that an uncached app loads offline.

Bun snapshots pin each fixture's text, source identity and semantic markup.
Interaction regression checks preserve the static gallery during all state
changes, verify immediate unsupported-transition behavior, inline dialog fallback,
focus restoration, no requests and no storage writes. Route smoke includes
/playground. Browser/assistive technology manual acceptance should check Tab,
Enter/Space, Escape and modal focus confinement at 390px and 1440px, both themes,
forced colors, reduced motion and motion=off. Markup snapshots are not pixel or
real screen-reader acceptance evidence.

## Governance

Existing configured source defaults are preserved: disabled, dry-run, quorum 10,
24-hour exposure, one current-head approval, empty base/check allowlists and an
active kill switch. Browser advisory choices remain separate from verified
membership/ballots. No auth, source, PR revision, vote, record, receipt or deployment
configuration changed. Main requires bun test, bun run typecheck and route smoke
test plus at least one human approval; live protection settings were not modified
or verified. A human-published tagged release is required for production.
Leave Linear open pending human acceptance. No merge, deploy or external write.
