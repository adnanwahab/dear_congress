# SHE-337 — Simulated journal story grouping

Refs: https://linear.app/shel-bernstein/issue/SHE-337/demo-collapse-near-duplicate-simulated-stories-in-the-shared-journal

Implemented display-only grouping in JournalScreen's Shared journal. Consecutive
explicitly synthetic entries with the same nonempty set of need IDs and exact
source label are compared to the first story using normalized token Jaccard
similarity >= 0.6. Comparing to the first story prevents transitive chaining.
The three known empty-fridge template sentences normalize to one phrase; the
three generic world-template closing sentences are ignored for comparison.
Original text is never rewritten. Unknown paraphrases may remain separate.

Each run shows its first story and a native, keyboard-operable details/summary
control, e.g. “+3 similar stories from simulated residents”. Expansion exposes
all original authors, dates, text and need labels. Real, unflagged, and seeded-only
entries always remain visible and break runs. No author-name or template-based
inference of simulated status occurs. Grouping runs over the loaded array, so
adjacent entries across appended pages can group. The count still uses the raw
loaded array length, including entries inside closed groups. Load-more and its
existing ID deduplication are unchanged. No reordering or automatic fetching is
added; varied needs move up when preceding duplicates collapse. Viewport fit
still depends on actual story lengths and viewport size.
