## Implemented

Each existing sample retains its ID, source URL, jurisdiction, wording and tally.
Added background page name, publisher and scope metadata; checkedAt is explicitly
null for every reference. These are editorial labels for the existing URLs, not
new verification of page content or availability.

A shared provenance component appears on source cards, feed cards and selected
feed detail, votes and draft details. It labels each sample “Sample scenario /
not introduced bill,” shows scenario jurisdiction, publisher and named external
link, and separates background context from authored scenario/current/proposed
wording. Federal USDA data beside a county scenario is explicitly background,
not proof of a county pilot. Generic city/county homepages explicitly do not
substantiate the scenario's detailed claims. Existing city/county/state/federal
scenario labels remain unchanged across routes; they are illustrative assignments,
not verified legal authority or an assertion that an agency can enact the text.

Links use HTTPS, reject credential-bearing or unsafe URLs, and have
`target=_blank` and `rel="noopener noreferrer"`. Missing/invalid, future or
more-than-30-day-old check dates show “Source not available / not checked.”
No dates derive from demo API activity. That activity label now explicitly says
it is not a source check. Downloaded drafts include the same provenance.
Citizen-authored cards/details distinguish their text and unverified official bill
status; publication dates do not become evidence-check dates. User supporting
information remains escaped text and is not promoted to official evidence.
