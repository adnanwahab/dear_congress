reproducibility documentation and launch merge policy before implementation.

native paired behavior receipt viewer. Its documented boundary remains: this

The candidate adds an HTML schematic town and list alternative to the existing
bounded viewer, showing available sampled status/occupancy at exact recorded
times. There is no GPU scene, invented building geometry, synthetic causal
explanation or interpolated event. Each branch preserves its own actor IDs;
missing fields remain unavailable. The expandable receipt and seed/model/time
link make the data inspectable. An explicit model run is still necessary after
opening a shared link. The existing input allowlist, request identity checks,
45-second deadline, population and checkpoint limits remain intact.

Household presets and package score arithmetic disclose their distinct source
mode and unavailable simulator provenance. They are not silently connected to
this separate sandbox. A real household response model remains unavailable.
