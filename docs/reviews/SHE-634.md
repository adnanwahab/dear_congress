# SHE-634 implementation review

Refs: https://linear.app/shel-bernstein/issue/SHE-634/civicplaysimulation-lab-one-variable-at-a-time-intervention-bench

## Audit and scope

Read repository readme, launch merge policy and native law behavior module docs.
Repository origin is adnanwahab/dear_congress. GitHub search found no SHE-634 PR;
open PR results were inspected before changes (including separate vote/homepage
work, which this patch does not alter). The supplied live /synth reference was
unavailable through the read-only web fetch; implementation follows this repo's
existing reviewed provider contract.

The existing explorer bounded requests, paired worlds and rejected stale responses,
but did not pin cross-run baselines or check deterministic replay. This change
pins the first completed run and retains up to five accepted strength receipts.
Law selection locks until explicit reset; subsequent runs reject baseline,
model/version, horizon or checkpoint drift, and same-strength output drift.
Typed request construction validates the reviewed input allowlist before fetch.
A receipt disclosure includes provider identity, request and recorded outputs.
No arbitrary prose is enacted or modeled. Effects remain synthetic, not forecasts.

Household impacts remain unavailable: no validated response model exists. Scoring
inspection identifies its arithmetic version and unavailable simulation metadata.
No fabricated household outcomes, seeds, horizons or uncertainty intervals added.
