## Behavior

The new optional object-navigation helper captures sample ID, displayed title,
origin bounding rectangle and exact anchor identity with source/destination
navigation entry keys and URLs. It uses native cross-document snapshots and
matches the same sample heading on arrival. Back/forward resolves the recorded
anchor rather than a globally remembered last proposal. Native anchors, history,
focus and scroll restoration remain in charge. Records expire after five minutes
and are bounded to twenty edges in session storage.

Loading/empty data, missing/offscreen/virtualized elements, changed display
identity, expired metadata, blocked storage and missing APIs retain ordinary
navigation. Reduced motion and motion off omit capture. Modified clicks and
prevented actions do not create a record. No hidden origin clone is fabricated.

Scope is sample proposal links and headings in the existing home/workflow views.
Topic badge navigation, official bills and citizen proposal records remain
separate; extending object transitions to their detail views requires distinct
identity namespaces. In-page proposal selection keeps its existing typed motion.
