# SHE-731 — civic problem neighborhood implementation review

Refs: https://linear.app/shel-bernstein/issue/SHE-731/civicplaydiscovery-civic-problem-neighborhood-map-as-force-directed

Implemented a topic-hub neighborhood from explicit need/proposal/sample-source
edges, bounded deterministic force layout, selectable zoomed SVG and equivalent
static list. Search, selected record, display mode and zoom are URL-backed;
selection focuses details, including related-record navigation. Reduced motion
forces the static experience. Dashboard and the bill catalog link to the hubs.
