## Scope and audit

Reviewed readme.md, AGENTS.md, launch merge policy, accessibility acceptance and motion docs, WorkflowScreen, ArgumentMap and ProposalProvenance. GitHub open PR inventory was inspected; repository PR search for “jury” returned zero results. The live reference could not be retrieved by the web tool. No live writes were attempted.

Implemented a page-memory, shared-device rehearsal in the existing Votes stage, scoped to the selected fictional proposal and exact proposal/source context. Existing stage navigation and provenance remain intact. No new API, persistence, ballot, roster or governance path is introduced. Initial proposal loading/failure uses the existing workflow gating; the room is unavailable until a proposal loads successfully.

Three individual opt-ins, editable pseudonyms, three agenda items, one 60-second turn per seat per item, voluntary passes, pause/resume, hidden-page pause, local concern reporting and facilitator review are included. The timer pauses on expiry; advancement is explicit. The facilitator should allow accommodation breaks. This shared device does not authenticate independent participants or a moderator.

The cited card quotes the exact proposal clause and displays its repository/sample identity. Reused provenance distinguishes background references from claim evidence; no empirical effect is asserted as verified. Summary text allows dissent and uncertainty. Preview requires completion and all three seats consenting to the exact draft; edits, withdrawal or reports revoke consent. Preview includes three rehearsal seats, non-representative group wording and no verified participation. There is no public publishing action.

## Public pilot blockers

This is a local rehearsal, not acceptance of a public multi-user room. Before public pilot: authenticated room-scoped membership and consent receipts, independent participant authorization, trained moderators, private report intake and escalation, moderation audit/appeal policy, server-enforced deletion/retention, claim evidence review, authenticated publication consent to a versioned exact summary, and summary withdrawal handling. Public publication must remain disabled until those controls and human acceptance exist. No issue state was changed.
