# SHE-609 — screenshot filmstrip with build provenance

Refs: https://linear.app/shel-bernstein/issue/SHE-609/civicplaypatch-arcade-screenshot-filmstrip-with-real-build-provenance

## Audit and implementation

Read AGENTS.md, readme.md, docs/pr-previews.md, docs/launch-merge-policy.md,
docs/motion.md and the preview, repository API and LiveRound modules. Reviewed
existing PR search results including #124 (attachment pairs), #236 (readiness),
and #234 (keyboard carousel). Those drafts are review candidates, not acceptance.
The live reference could not be fetched in this environment. GitHub CLI network
access failed; the connected GitHub search supplied the PR audit.

Existing attachment parsing pins the image file to an immutable same-repository
commit. That does not prove the revision of the app depicted in the image.
Attachments now remain separately disclosed and explicitly unverified. Only an
operator registry receipt with exact full SHA, capture time, local image endpoint,
verified preview URL/route and verification time enters the build filmstrip.
Current uses the PR head; Before uses GitHub evidence's base SHA. Missing base
identity never guesses a baseline. No real captures or previews were created.

The public wire contract advances to v2 for optional beforePreview. Existing
registry data and image endpoints remain unchanged. Registry lookup is restricted
to HBL PR scope in the API and checked again in the filmstrip. Other repository
scopes show unavailable instead of borrowing HBL receipts. Missing receipts do
not claim a job is queued. Incomplete receipts show verification pending.
Image loading/error/retry are local UI state; access restrictions are presented
as a possibility, not an inferred HTTP permission result.

The filmstrip is two columns on desktop and stacks below 600px. Native links,
buttons and focus outlines support keyboard use; there are no animations or
swipe handlers, including under reduced motion. LiveRound contains civic
proposals rather than PRs and remains untouched. Filmstrip code has no mutation
API or vote callback.

## Validation and remaining review

Focused tests cover blocked, checks-pending and review-ready PRs; stale heads,
changed bases, missing identity, invalid timestamps, wrong PR/repository and
unsafe preview URLs fail closed. A DOM test exercises loading, image failure,
focused retry, successful load and head changes, asserting no fetch writes or
input mutation. Typecheck passed. The full suite and route smoke were run;
server-binding tests cannot start here (EADDRINUSE on port 0). Final full run: 481 passed, 26 failed (server-binding failures).
Focused preview/attachment/registry tests: 11 passed, 0 failed.
`bun run typecheck` and `git diff --check` passed. Desktop/mobile browser rendering and real
capture-host access still need human verification in an environment able to
start the app. DOM/CSS tests do not establish full visual acceptance.

No production state, receipts, votes, authentication, checks, quorum or merge
settings changed. Source defaults remain disabled/dry-run, quorum 10, 24-hour
exposure, one current-head approval, empty base/check allowlists, and active kill
switch. Browser advisory votes remain separate. Human approval and all required
checks remain necessary; production releases require a human-published tag.
Actual production overrides and GitHub branch protections were not changed or
verified. Leave Linear open for human acceptance. No merge, deployment, release
or external message was performed.
