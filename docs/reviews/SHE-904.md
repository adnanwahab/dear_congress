# SHE-904 — evidence and model-input manifest

Refs: https://linear.app/shel-bernstein/issue/SHE-904/cs-l100055-export-a-machine-readable-evidence-and-model-input-manifest

## Implemented scope

Adds a native JSON download to the completed paired-world law sandbox on
`/synth`. The public projection retains repository/item-kind, source law ID,
proposal/scenario revision, provider URL, response retrieval timestamp, seed,
engine/model version, population, implementation strength, horizon and checkpoint
count. It includes assumptions, limitations, unknowns and explicit synthetic,
unreviewed and non-binding advisory status. It never exports journals, ballots,
credentials, actor records or private saved drafts. No persistence or write API
is added. Changed, loading, failed and unavailable scenarios offer no download.
The existing selected-outcome trace remains a separate export of model output.

The response retrieval timestamp is captured after successful response validation;
it is not generated at download time and is not an underlying evidence date.
The provider's catalog revision, code revision, calibration weights and underlying
evidence sources/retrieval dates are unavailable in the current receipt contract.
They remain explicit nulls and unknowns; civic package scoring weights are not
substituted for this separate model's weights. No new official or measured claim
is made. This is a usable export of available provenance, not a fully sourced or
calibrated simulation bundle, and cannot establish exact source-code replay.
