# SHE-356 — Public journal discovery

Refs: https://linear.app/shel-bernstein/issue/SHE-356/journaldiscovery-add-trustworthy-filters-dates-and-deep-links-for

Implemented origin, need and UTC date filters before cursor pagination with
shareable query state and popstate restoration. Public submissions exclude seeded
and synthetic flags; labels explicitly avoid claiming verified people. Added UTC
posting times, seven-day freshness, stable entry permalinks, entry-bound need
links, filter reset, first/next page controls and recoverable empty/error states.
Requests are generation-guarded against stale responses. Existing server public
projection and moderation filtering remain authoritative. Snapshot updates only
remove unavailable entries; refreshing fetches new matching entries.

Reuses SHE-337 display-only synthetic grouping. Each page keeps native expandable
originals; a group may split across pages. No clustering implementation changes.
No public locality is inferred or disclosed. The jurisdiction control explains
that consented public jurisdictions are unavailable. A complete jurisdiction
filter requires a separately designed consent/storage/publication contract.
Unflagged legacy entries are public submissions, not proof of real humans;
SHE-271 provenance/migration and vote separation remain unresolved. Relevant sort
is not added; recent is deterministic and needs filter supplies topic relevance.

need-cluster-pilot and SHE-271/337 reviews; inspected JournalScreen,
SharedJournalFeed, JournalLive, server read/projection paths and shared types.
