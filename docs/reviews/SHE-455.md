# SHE-455 implementation review candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-455/joydeliberation-plain-language-impact-diff-between-bill-revisions

Read the repository README, amendment model/editor and SHE-305 review, citizen
proposal, catalog, motion, accessibility and launch policy docs. GitHub search
found amendment PRs #35 and #59; #59 is merged to main and its private editor is
present here. Its automated process-completion body is not acceptance evidence.

The implementation adds a structured evidence checklist after every redline,
including saved details. Five areas have explicit Before/After evidence, exact
line anchors, and Needs review. Only author-labeled lines are quoted; ordinary
prose, rationale, citation notes and cost notes are never treated as verified
impact claims. Semantic consequences remain unknown pending review. Saved UUIDs
can be compared without loading their text into the form or writing storage.
Comparison rejects differing source snapshots; same-ID comparisons are permitted
and state that text is identical. Live edits are explicitly unsaved. Existing
snapshots, author text, source IDs, public records, votes and receipts are intact.

This is a bounded private-draft implementation. Arbitrary prose interpretation,
official bill revision ingestion, reviewed semantic summaries and durable public
revision audit infrastructure remain outside this slice. Needs review is the
intentional fallback, not a claim those assessments are complete. Browser storage
remains editable and not a durable audit ledger. No API or schema was introduced.

- Comparison is synchronous and local, so it has no network/loading state.
  Existing storage-read/save failure handling and focused persistence tests remain
  intact; no loading delay or asynchronous effect calculation is introduced.

Human review must run full checks and native acceptance before acceptance. Check
unlabeled input yields Needs review; labeled quotes match exact revision lines;
selecting A/B does not change unsaved fields or stored versions; reload retains
versions; compare revisions saved against different source snapshots is blocked.
Test mobile tap/select/anchor navigation, keyboard focus and reduced motion.

Governance is unchanged: disabled/dry-run defaults, quorum 10, 24-hour exposure,
one current-head approval, fail-closed base/check allowlists and active kill
switch. Browser activity is not verified participation or merge authority.
Required main checks remain `bun test`, `bun run typecheck`, `route smoke test`
and at least one human approval through GitHub protection. Live protection and
runtime overrides were not verified. No deploy, merge, release, external message,
production write or issue-state change occurred. Leave SHE-455 open for human
