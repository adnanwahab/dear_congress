# SHE-463 implementation candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-463/joylocal-real-world-next-step-action-cards-for-every-policy

Added optional, read-only action cards for every selected fictional proposal in
WorkflowScreen across all six civic stages. Cards bind to the selected sample ID,
title and scenario jurisdiction. Loading, failed fetches and missing selections
hide cards rather than retaining potentially misleading actions. Unknown
jurisdictions have an explicit unavailable state.

Each card offers agenda research, hearing planning and office-directory research.
Official directory sources reviewed November 14, 2026:
- City of Houston: https://www.houstontx.gov/council/
- Harris County: https://www.harriscountytx.gov/
- Texas Legislature Online: https://capitol.texas.gov/
- Library of Congress: https://www.congress.gov/

These are jurisdiction directories, not proposal-specific agenda matches or
verified recipients. Dates, attendance rules and contact details must be checked
at the official source. Transit users are told to confirm METRO jurisdiction.
No proposal source URL is promoted to action authority. Existing provenance,
source IDs, navigation, votes, tracker records and receipts are unchanged.
Links explicitly identify external sites/new tabs and use noopener noreferrer.
No API, storage, sending, click telemetry, attendance or completion authority was
added. Wording is optional and neutral; demo progress remains unverified.
The live reference could not be retrieved by the web tool; no live parity claim.
GitHub PR search for SHE-463/action cards/next-step returned no matching PRs.
