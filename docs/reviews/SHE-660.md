## Implementation candidate

OutcomeMetricPuzzle is an explicit opt-in entry in DemoTour, BillCatalog and
WorkflowScreen. It uses the shared theme tokens and source-status chip class.
The fictional Lantern Bay library promise has five native-select scenes:
denominator, measure, timeframe, data source and failure criteria. Each option
has practical and gaming-risk feedback; the final review preserves the player's
choices and flags skipped components as undefined. There is no political
priority ranking, scoring, reward, API call, storage write or ballot binding.
No catalog identity or content is copied into the fictional scenario.

Skip advances without a choice; Restart clears choices; Exit clears and restores
focus to the entry button. Scene headings receive focus. A native details element
contains the complete explanation and every option's feedback without playing.
State exists only in component memory. Starting inside the tour pauses its timer,
disables Resume until exit and exempts puzzle controls from tour key shortcuts.
