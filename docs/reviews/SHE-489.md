# SHE-489 — Life of a law implementation candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-489/joystory-interactive-graphic-novel-the-life-of-a-law

Home now includes a collapsed, six-chapter motion comic, “A bus home after dark.”
The fictional transit journey covers lived need, source checking, deliberation,
drafting, a possible sponsor and measurement after hypothetical implementation.
All six existing civic stages are linked with the same explicit demo-transit ID.
The reading order starts at Feed for the lived need and then Published for source
checking; it does not change the application's configured stage order.

Typed chapter contracts separate the stage binding, scene, narration and reality
boundary. Every chapter labels its hypothetical content. The official METRO link
is background only, not support for the invented pilot; regional transit authority
and congressional/city legislation are not conflated. Outcomes claims no verified
implementation or benefit. Original source records, citations and data remain
unchanged. Publication, real outreach and reuse of private stories require separate
choices; the comic has no API, storage, vote or sending actions.

Readers select chapter buttons or Previous/Next with native keyboard controls.
No timed advancement or global keyboard shortcuts interrupt reading. Updated
chapter text has a polite live region. Inline SVG drawings are decorative; all
scene meaning appears in text. The complete text edition contains all six full
chapters, disclosures and links and removes drawings. Controls wrap on narrow
screens and have 44px minimum height. Motion is a single 700ms arrival, has an
explicit pause control and runs only under prefers-reduced-motion: no-preference.
Text and drawings are bundled, so there are no network loading/failure states for
the comic. The existing stage pages retain their API loading/retry behavior; the
reader can return to the story if a linked stage fails.
