Refs: https://linear.app/shel-bernstein/issue/SHE-681/civicplayevidence-studio-human-reviewed-public-dataset-import

## Audit and implemented scope

Read repository `readme.md`, `AGENTS.md`, `docs/launch-merge-policy.md`,
`docs/repository-voting.md`, and measurement module review `docs/reviews/SHE-315.md`.
Baseline: `1305bc0`. Inspected ProposalProvenance, PolicyMeasurements,
Documentation/public-guide, shared measurement types and isolated DOM verifier.
This checkout has no common claim-provenance type containing the four requested
categories. The new isolated import type introduces those categories without
reclassifying existing scenario backgrounds or synthetic measurements.

GitHub SHE-681 search returned no PRs. Related search returned provenance review
candidates #175 (unified badge/schema), #203 (provenance explorer), and #265
(source revision diff). Their descriptions are not acceptance evidence or authority
to import unmerged contracts. This change does not import their branches.
Read-only access to the reference outcomes page and Census pages failed through
the web tool. No live parity, agency-source verification or remote snapshot
retrieval is claimed.

`/outcomes` now includes a local-only staging workbench. Paste CSV or read a local
file, inspect schema and first five rows, map value/period/unit/scope columns,
enter a civic metric contract and exact source/release, publisher, terms URLs,
retrieval date and limitations. Validation covers every row (maximum 500), not
only the preview. Units and population scope must match exactly; ambiguous
schemas, missing values, invalid dates, conflicting duplicate observations and
non-primary claim categories block local acceptance. HTTP/credential URLs are
rejected. Metadata completeness and URL shape do not prove source authenticity,
license suitability or statistical validity: a reviewer must inspect them.

A named, self-reported reviewer explicitly attests to source, licensing, units,
scope, dates and limitations before creating an immutable local snapshot.
Changing any source/data/contract field invalidates current acceptance; prior
accepted snapshots remain in session history and JSON export. Export preserves
raw CSV, mapping, dates, limitations, validation errors, reviewer and timestamp.
Export failure leaves copyable text, and print has a separate complete preformatted
packet outside closed disclosures. Files/paste work offline; no remote fetches,
server writes or automatic publication exist. Reload loses local drafts/history;
export is required for retention. Local review is neither authenticated nor
trustworthy publication authority. No data enters synthesis or observed metrics.

Examples cover a citation-complete Census transcription specimen, invented
conflicting rows and a missing-source user claim. The Census specimen explicitly
awaits independent verification and has no fabricated retrieval date. The user
must enter an actual retrieval date after inspecting the release. Its population
count is descriptive, not an estimate of policy effects. Conflict/missing cases
remain blocked and labeled. No example is preaccepted.

The public guide documents this boundary and export/reload behavior. Existing
source identities, scenario background metadata and measurement fixtures are
unchanged; no vote, PR, receipt, storage or production data migration occurs.

  offline operation with zero requests and complete printable/export text.

- Full suite and route-smoke results are recorded below.

This is a bounded local preparation tool, not full SHE-681 acceptance. A fully
sourced case still requires independent reproduction against an archived official
release and license review. Authenticated durable reviewer acceptance, retained
source snapshots/hashes and an authorized publication workflow remain unbuilt.
A human must verify real-browser keyboard-only navigation, touch at narrow widths,
focus/read order, zoom and actual print/export output; DOM tests and minimum touch
target CSS are not substitutes. No native-browser verification was performed.
Keep the issue open for those requirements and human acceptance.
