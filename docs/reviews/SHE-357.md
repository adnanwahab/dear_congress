## Behavior

Stable indexed routes exist for all eight existing topics, including transit,
housing and childcare. `/topics` searches topic labels. Sample-card topic chips
link to hubs, filter chips retain filtering with adjacent hub links, and shared
navigation exposes Topics. No new taxonomy or inferred personal labels.

An uncached `/api/topics/:id` projection uses the existing catalog and current
stored sample entries. Only public, non-synthetic seeded journals are eligible;
human and simulated text are excluded. Held, hidden, deleted and untagged samples
cannot appear. Original source IDs and stored extraction need/proposal IDs remain
inspectable, with exact public-source JSON and original Needs links. Recorded
proposal IDs link to the matching catalog alternative. Catalog options retain
multiple alternatives and rights constraints; no consensus is inferred. Workflow
samples are a separate lane and explicitly have no recorded journal derivation.

Sample proposals reuse the existing provenance component, including unsafe URL
rejection, missing dates and stale-source handling. Official metadata is not
keyword-matched to topics: no reviewed topic/proposal binding exists. Official
sources, human stories, curated simulations and verified outcomes therefore show
explicit not-yet-available explanations. Background sources are not asserted to
be bills, authority or outcome evidence. The simulation link opens the existing
illustrative model and explicitly does not claim a topic-specific frozen run.

Topic/proposal query parameters persist through workflow and shared stage links.
A validated topic return link appears on destination pages. Search query state
is URL-backed and responds to popstate; normal document links support browser
back/forward without storage. Responsive hubs wrap navigation and long IDs.
The existing jurisdiction mapping filters only the sample-proposal lane; catalog
alternatives retain their labeled scope. Regional METRO is not relabeled Houston.
