# SHE-501 implementation review

Refs: https://linear.app/shel-bernstein/issue/SHE-501/joytogether-structured-public-design-workshops-for-proposals

Implemented a bounded facilitator preparation tool on loaded citizen proposal
pages: six agenda sections, evidence prompts, an explicitly consented read-only
summary for manual sharing, attributed text export and opt-out clearing. The
existing six-stage routes are linked as context without moving notes across
source kinds. No workshop data is sent to the server or persisted.

Audit: read repository instructions, readme.md, citizen-proposals module docs,
launch merge policy, proposal detail, private amendment and discussion-guide code.
GitHub search for workshop PRs returned no matches; open-PR audit showed adjacent
share cards, clipping notebooks and reality-label work. Those draft candidates
were not treated as merged implementation. Existing public comments lack workshop
reporting, consent and withdrawal, so public collaboration remains disabled.

Remaining acceptance: moderated public session storage and authorization,
participant-specific permission/attribution/withdrawal, reporting and response
workflow, durable read-only sharing, and native mobile/keyboard/screen-reader QA.
This is a preparation slice, not an accepted public collaboration service. Keep
Linear open for human verification. No deployment, external message or merge.

Source proposal IDs/text, journal references, comments, votes, receipts and PR
head/base bindings are unchanged. No governance configuration changed: source
defaults remain disabled/dry-run, quorum 10, 24-hour exposure, current-head approval,
fail-closed base/check allowlists and active kill switch. Required checks remain
bun test, bun run typecheck and route smoke test; human approval and human-published
tagged releases remain required. Production settings were not inspected or altered.

Validation: focused agenda/provenance and isolated Happy DOM consent/summary tests
pass (2 tests). Typecheck passes. Full-suite and route results recorded below.

Full validation attempt: `bun test` reports 477 pass / 26 fail. Failing integration
cases cannot start local Bun servers (`EADDRINUSE`, port 0); the focused workshop
checks pass in that same run. `bun run test:routes` also fails while binding its
isolated server with the same error. No sandbox escalation or production testing
was attempted. `bun run typecheck` and `git diff --check` pass. Native browser
visual verification was not performed; existing before screenshots were preserved.
