# SHE-755 — local branching sandbox history

Refs: https://linear.app/shel-bernstein/issue/SHE-755/civicplayinteraction-craft-multi-step-sandbox-history-with-branching

Implemented a local immutable snapshot tree in Advanced synthesis on `/synth`.
Each changed scoring weight, institutional-change penalty, annual budget model
input, or selected package filter creates a step with an explicit parent.
Undo restores the parent. Redo follows the sole child, or asks the explorer to
choose a branch. All steps remain inspectable and individually restorable;
editing an earlier step does not discard later branches. Identical edits are
ignored. Snapshots contain only the allowlisted settings, never AppState,
public journal text, votes/casts, official updates, results, records or receipts.

Restore invalidates obsolete preview requests, restores controls synchronously,
and schedules the existing debounced read-only synthesis preview. It does not
call the explicit saved-plan action. Results are recalculated against current
data; deterministic setting snapshots are not a frozen historical data receipt.
Existing Synthesize and citizen-idea budget actions retain their existing
semantics. The law-behavior explorer, public drafts and unrelated page filters
are outside this settings history; no new free-text model editor was introduced.

## Fallback and remaining acceptance

Open Advanced synthesis, change a weight and budget, press Undo, edit again,
then expand Inspect steps and restore either branch. Native buttons and details
support keyboard Tab/Shift-Tab/Enter/Space and touch; all snapshots have complete
text descriptions, parent/step identity and a current-step status announcement.
No global shortcut intercepts native text Undo. Copy settings before navigation
or reload: history is explicitly page-memory-only, with no storage requirement.
No public draft is captured, reset or overwritten by restore.

Human keyboard/focus, actual touch/reflow, low-power and VoiceOver/NVDA review
remain required under docs/accessibility-acceptance.md. DOM regression tests do
not establish those criteria. Very long slider sessions can create many steps;
the panel uses a collapsed native disclosure and does not silently truncate
branches. Cross-navigation persistence and frozen result replay are not offered.

## Governance preserved

No voting, auth, merge, production-data or deployment configuration changed.
Configured source defaults documented in docs/launch-merge-policy.md remain
disabled/dry-run, quorum 10, 24-hour exposure, current-head approval, fail-closed
base/check allowlists and active kill switch. Browser advisory choices confer
no merge authority. Required checks remain `bun test`, `bun run typecheck`, and
`route smoke test`, with at least one human approval and current-revision review.
Live branch protections and environment configuration were not verified here;
a repository file cannot activate them. Production release requires a
human-published tagged release. Keep Linear open pending human acceptance.
