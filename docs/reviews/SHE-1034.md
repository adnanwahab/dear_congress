Usage: `createPolicyPreviewClient().create(input)` returns `{status: 202 | 200,
value: receipt}`. `manifest(id)` and `results(id, optionalRunIndex)` return validated
upstream payloads. These call HBL's `/api/policy-previews` endpoints. No local
route composition or shared entrypoint was edited: mounting Civic routes remains
SHE-1032's responsibility. Do not expose an unauthenticated arbitrary publish
proxy; use existing owner/consent/publication gates at the integration boundary.
The existing HELIOS protocol, proposal persistence and #450 files are untouched.

`HBL_URL` must be an HTTPS origin (HTTP loopback allowed for development).
`HBL_POLICY_PREVIEW_TOKEN` is read only in the server module, required only for
POST and sent only as a Bearer header. Public GETs send no service credential.
Redirects are rejected. Requests default to a 20-second timeout. Responses are
stream bounded to 64 MiB (the upstream 100-pair fixture is approximately 25.3 MB).
No retries, tokens in URLs, raw upstream errors, mock successful URLs, logs or
production writes are introduced. Configuration/transport/validation failures
throw a sanitized `PolicyPreviewError` with an explicit state.

## Acceptance evidence

The real housing fixture matches its committed upstream schema and canonical
SHA-256 `bcb6466a4803cc00cdba7102c4c4d2bc8925d09cb046737a314390af5421be8e`.
Canonical serialization sorts recursively, preserves array order and exact text,
and rejects non-JSON/nonfinite values. Direct tests include integer-like key
sorting and exact newline preservation.

Validation rejects private/unlisted sources, extra properties, bad hashes,
unsupported versions, duplicate clause/mechanism IDs, baseline mismatch,
credential/query/fragment-bearing source URLs, incorrect add/remove/modify text,
invalid uint32 seeds and out-of-bounds simulation settings. Text remains exact.
Results require finite numeric city metrics, recorded monthly/checkpoint shapes,
valid job counters and unique run indices; failed pairs cannot contain successful
arms. HTTP 401/409/429/404/5xx, malformed payloads, network failures and timeouts
are distinct sanitized failures. POST supports 202 queued and 200 idempotent.
Tests exercise a fake transport, not a live model execution or deployment.
