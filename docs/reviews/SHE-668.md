# SHE-668 — Spot the missing voice

Refs: https://linear.app/shel-bernstein/issue/SHE-668/civicplaygame-studio-spot-the-missing-voice-deliberation-puzzle

## Implementation candidate

Three explicitly fictional consultations cover meeting-time exclusion, app-only
surveys and mailing-list self-selection. Each asks which perspective might be
missing, then explains the sampling limitation and practical outreach alternatives.
Missing perspectives do not imply predictable opinions. There is no score, reward,
ideological preference or claim that broader outreach establishes representativeness.

`MissingVoice.tsx` is opt-in from BillCatalog, WorkflowScreen and DemoTour. Its
React state lasts only while mounted; it has no API, storage, identity, source-item,
proposal or ballot inputs. Restart resets the scene and selection; Skip advances
without answering; Exit returns focus to the entry button. Native radio controls,
buttons and disclosure provide keyboard access and complete text for all scenes
without completing play. Shared theme variables and the existing source-status
chip class label educational provenance without borrowing official source identity.
Tour timing pauses on entry, tour shortcuts yield to puzzle controls, and exit
leaves the tour paused until explicitly resumed.

No server, data, receipts, source identities, revision binding, advisory participation,
authentication or governance behavior changes. Rollback is removal/reversion of the
component, its CSS, three entry points and tests; no data reset is needed.
