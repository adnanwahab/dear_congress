## Implemented increment

Each completed recorded model comparison now shows a model-versus-observation
gap assessment for the selected observable. It explicitly rejects pairing the
starter fixture's annual commuting shares, insurance claims and street-request
closure durations with synthetic model travel/housing observables. No public
numeric values are loaded or assumed verified. This avoids inventing a matched
measurement or claiming that a low residual validates all model predictions.

The expandable JSON receipt preserves exact validated checkpoints, inputs,
source identity, selected observable/unit, seed, model version and actual clock
range, with null observation and fit. It is deterministic for the same inputs
and can replay the recorded display without a provider request. It is not signed
or a guarantee that a future provider version regenerates the same world.
Pre-run/error states disclose requested horizon and unavailable model version;
score and household views disclose missing simulation metadata and uncertainty.
No new endpoint, persistence, inference, external write or automatic model run
was added. Existing legal prose, votes, PR revision bindings, records and source
identities are unchanged.
