# SHE-537 — Personal evidence clipping notebook

Refs: https://linear.app/shel-bernstein/issue/SHE-537/joydiscover-personal-evidence-clipping-notebook

Implemented a browser-local notebook on the existing Participation & privacy
page, with save controls on selected workflow proposals and synthetic policy
measurement cards. No identity or backend foundation was duplicated. A clip
freezes claim text, provenance citation, source URL, access time, source revision
and an optional user note. Export Markdown includes these fields and stale status.
Remove operates only on this notebook. Unreadable or blocked storage shows an
error and never overwrites the existing notebook. Storage is capped at 200 clips.

Source observation compares the full captured app record within kind and ID.
A changed record sets stale permanently, preserving the original note, timestamp
and citation. Detection requires revisiting that record in the app; no external
page fetch, background polling or verification is claimed. Deleted or unvisited
sources cannot be detected. Review external sources manually. Browser storage
is private from publication, not encrypted or protected from shared-profile users.
No cloud sync is offered. Original notes are never silently updated.
