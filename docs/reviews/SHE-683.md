## Behavior and provenance

/outcomes now includes an independent bundled exercise during proposal loading,
API failure and offline operation after the page loads. Two fictional groups keep
fixed preferences while users change response multipliers. Equal multipliers show
50% support; a 3:1 composition shows 65%. Zero total responses shows undefined
percentages. This cannot infer population opinion or correct unknown selection.
There is no cookie, tally, storage or write API dependency.

Three selectable cases demonstrate a complete fictional source record, a fictional
claim contradicted by that record, and a missing-source claim. The fully sourced
case is fully sourced **within the fictional exercise**, not an externally
validated real-world poll. Original records are primary by origin and synthetic
by content. The UI distinguishes primary source, editorial inference, user claim
and synthetic estimate, with fixture authorship date, limitations and pending
human review. Fixture identifiers retain repository identity. Background agency
links from ProposalProvenance are not promoted into support for these counts.

Changes to weights, evidence case and reset append session events containing date,
exact weights, case, fixture revision and pending human-review status. JSON export
and a selectable full report preserve this history and source/limitation metadata.
Reload clears session state, as disclosed. Nothing claims a human has approved the
exercise. Print includes an expanded report rather than a clipped textarea;
failed export/print leaves copyable text. The public guide documents the exercise.
