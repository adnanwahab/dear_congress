# SHE-322 — Purple bottom navigation

Refs: https://linear.app/shel-bernstein/issue/SHE-322/civic-synthesis-make-the-bottom-navigation-purple

Implemented in the shared `src/client/styles.css` navigation rules. The shared
`BottomNavigation` mounts in App's product shell. Mobile rules change layout,
not colors; the opaque #5b4b9a background also stays consistent under either
system color scheme. This uses the existing light-palette purple explicitly,
since `--new` switches to a lighter purple under dark system preferences.

White destination icons/labels, utility buttons and external app links have
7.20:1 contrast against the bar. White on the #493b80 hover fill has 9.46:1;
active #493b80 text/icons on #f0ebff have 8.12:1. Icons use currentColor.
The active tile has a pale fill and inset underline, retained on hover.
Keyboard focus has a white outline against the surrounding purple.
These ratios exceed WCAG AA text contrast; native-browser visual, keyboard and
production acceptance remain for human review.
