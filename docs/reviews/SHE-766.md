## Acceptance boundary

This is a functional first tabletop slice, not completion of the city-scale
vision. The provider contract cannot model arbitrary intervention coordinates,
multiple simultaneous mechanisms, drainage or fiscal costs. The board's slot is
a discussion aid, not a claimed spatial simulation. No invented effect, source,
price, confidence interval or observation date fills those gaps. Existing model
version, seed, units and checkpoint clock identify returned synthetic values;
model reference numbers and control increments are configuration, not measured
policy estimates. Synthetic results do not establish real causal effects.

Remaining engineering: reviewed versioned spatial/combined mechanism contract,
revision-bound run identity and durable source/cost receipts, drainage support,
reproducible city-scale performance evidence and externally reviewed model
uncertainty. Do not describe this slice as a tested city-scale intervention model.

## Demo script and release checklist

1. Open /map; read its county/synthetic-participation disclosure. Follow the
   Policy Holodeck link to /synth. Confirm Simulation not forecast is visible.
2. Open tabletop. Select transit with keyboard or touch and Place selected
   intervention, or drag it onto the slot. Confirm no network run or vote occurs.
3. Explicitly run two futures. Inspect the provider/model version, fixed seed,
   synthetic population, checkpoint clock, browser receipt timestamp and WHY
   limitations. Only actual validated provider checkpoints may populate results.
4. Change strength and rerun; inspect paired baseline and edited values. Place a
   housing card: prior effects disappear until a new model receipt returns.
   Fixed upzoning must disable partial strength. Drainage stays unavailable.
5. Cancel a run, retry, and exercise provider outage, unsupported context and
   mismatched receipts. Never substitute illustrative success data. Model fixture
   tests are not evidence of production model availability.
6. Before release, a human must verify real provider/CORS/version parity, 320px
   and phone touch drag/select equivalence, keyboard and screen-reader journey,
   reduced motion, forced colors and actual zoom. Check no clipping, hidden focus
   or unintended write. These browser/manual gates have not been performed here.
7. Review resource limits and real city-scale load separately. Existing bounds
   (24 synthetic population, 45-second deadline, 100 checkpoints, 12 tracked IDs,
   2-million-character post-read display limit) are not a city capacity benchmark
   or a streaming network-size cap. Run required main checks on the final revision.
8. Human approval and a human-published tagged release are mandatory. No deploy,
   merge, external comment, issue-state change or production data change occurred.
