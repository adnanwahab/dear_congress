# SHE-541 compatibility implementation and verification

Refs: https://linear.app/shel-bernstein/issue/SHE-541/joyquality-cross-browser-view-transitions-compatibility-layer

Inspected readme.md, docs/motion.md, docs/launch-merge-policy.md, motion.ts,
view-transitions.ts, associated tests and CSS. GitHub search found foundation
PR #98, navigation #83 and related pending motion/backstack work including #147;
this change extends the checked-out foundation rather than importing those PRs.
Search results are overlap discovery, not evidence of acceptance or review approval.

Implementation adds immediate JS fallback on native startup failures, preserves
exactly-once updates and application errors, and makes type-scoped CSS work when
engines accept options without exposing types. Filter/theme CSS uses the attribute
compatibility path. Native anchors, focus, history and existing component fallback
motion remain in charge; no router or synthetic snapshot layer was added.

Focused tests cover unavailable/callback-only APIs, startup failures, reduced
motion, focus retention, interrupted transition ownership and update exceptions.
Typecheck passed. The full suite and required route smoke check were attempted
but could not pass in this environment: Bun server binding fails with EADDRINUSE,
including PORT=0. No passing full-suite claim is made.

Browser verifier was attempted: Chromium and WebKit terminate during launch;
Firefox's executable is absent. An isolated local server also cannot bind.
Consequently Safari, Firefox and Chromium navigation acceptance remains unverified.
Run scripts/verify-motion-browser.mjs in a browser/listener-enabled environment,
then manually verify shipping Safari/iOS (including BFCache restoration), mobile
viewport/touch, modified clicks/new tabs, hash links, focus and rapid repeated
navigation. Validate journal loading, empty and failed-load/retry states alongside
filter/theme changes with reduced motion. These gaps keep acceptance open.

No production data, votes, provenance labels, PR/repository revision isolation,
records or receipts changed. Governance remains disabled/dry-run by source default,
quorum 10, 24-hour exposure and kill switch active; production values are unverified.
Required checks remain bun test, bun run typecheck and route smoke test with at least
one human approval required through GitHub protection. No protections, auth, quorum,
merge settings, Linear state, releases or deployment were changed. A human must
verify acceptance and decide any merge/release under docs/launch-merge-policy.md.
