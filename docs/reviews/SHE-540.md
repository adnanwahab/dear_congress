# SHE-540 — animation performance budgets

Refs: https://linear.app/shel-bernstein/issue/SHE-540/joyquality-animation-performance-budgets-on-low-power-devices

Implementation extends `src/client/motion.ts`; no second motion settings system.
See [budgets, benchmark protocol and sources](../motion.md#low-power-budgets-she-540).
Reduced motion, exposed low discharging battery and sustained dropped foreground
frames share an immediate rendering fallback. Native controls, update callbacks,
records, provenance and advisory/fictional/simulated labels are unchanged.

five benchmark runs against base main and candidate on the same idle machine;
retain raw artifacts and compare the documented absolute and 10% thresholds.
Perform actual old-phone/integrated-GPU checks; CPU throttling cannot certify GPU
or thermal behavior. Review the battery fallback on supported hardware and
unsupported/denied API behavior. Until then this is a review candidate, not verified
performance acceptance; leave the Linear issue open.
