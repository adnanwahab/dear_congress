# SHE-988 — private feedback intake

Refs: https://linear.app/shel-bernstein/issue/SHE-988/cs-l100099-create-a-public-feedback-intake-with-safety-and-response

Implemented a guide-linked `/feedback` form and protected intake, separate from
resident/voting data. Five categories assign duty roles and initial review dates.
Only an authenticated maintainer can read raw reports; there is no public list,
public receipt lookup, automatic posting, AI forwarding or outbound delivery.
See [operator handoff](../feedback-intake.md) for staffing, queue pagination,
response triage and manual retention. No live secret or named duty roster was
configured. Actual staffed response coverage still needs human verification.
