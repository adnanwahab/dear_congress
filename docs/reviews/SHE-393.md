# SHE-393 implementation scope and validation

Refs: https://linear.app/shel-bernstein/issue/SHE-393/joymotion-morph-a-legislative-clause-into-its-plain-english

Audited readme.md, citizen-proposals.md, launch-merge-policy.md, the private
amendment editor/storage model, sample stage composition and shared motion helper.
GitHub search found no SHE-393 PR; adjacent clause work #120 concerns a separately
labeled synthetic mechanism sandbox, not a general legal-text interpreter.

Implemented a bounded fictional-sample terminology reader in amendment preparation.
Exact original phrases morph into annotated plain-English readings. It retains
original text, origin, sample/citizen identity and private revision labels, and
states uncertainty, citation limits and uninterpreted scope. No official legal
text is currently available in this editor. Arbitrary citizen/draft text is not
paraphrased. Unsupported or revised text explicitly shows no interpretation.

Validation: focused reader, amendment DOM walkthrough and shared motion tests pass
(7 tests), including exact identity/revision isolation, empty/long drafts, source
focus/return anchors, text-only mode, synthetic touch activation and reduced-motion
fallback. Typecheck passes. Full suite attempt: 475 passed, 26 failed; server-backed
tests could not bind their local listener (EADDRINUSE, port 0). Route smoke likewise
failed to start its server. Native browser animation, keyboard activation,
screen-reader announcements, touch-device layout and zoom remain human review
items; DOM tests do not establish those. Stage loading behavior was not changed.

Governance is unchanged: source defaults remain disabled/dry-run, quorum 10,
24-hour exposure, current-head approval, fail-closed allowlists and active kill
switch. Human approval and required main checks remain required under
launch-merge-policy.md; no live settings were inspected or changed. No production
data, ballots, receipts, publication, merge, release or deployment was changed.
This implementation is a review candidate; leave the issue open pending human
acceptance. Complete official-text coverage requires independently reviewed,
revision-bound phrase annotations and official legal-source ingestion.
