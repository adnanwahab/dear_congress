# SHE-882 implementation review candidate

Refs: https://linear.app/shel-bernstein/issue/SHE-882/cs-l100043-add-a-permanent-official-vs-fictional-data-lane-switch

Audited repository guidance, readme.md, docs/bill-catalog.md,
docs/legislative-metadata.md and docs/launch-merge-policy.md. The prior feed
combined separately stored fictional sample UI and official metadata on one page;
the unreviewed editorial catalog already lived independently at /bills.
GitHub PR searches for this issue and open feed PRs returned no matches. This is
a limited search, not proof that no overlapping work exists.

The feed now has three exclusive data lanes with Fictional samples as the default.
A shareable lane query parameter restores on reload and popstate; invalid values
fall back to samples. Sample resets retain the lane; concept filters reset only
concepts. Official references have no search filters and show retained-record
counts only after loading, never a fabricated empty count on initial failure.
Concepts load lazily from the existing catalog with original IDs/detail links.
Sample-specific discovery, comparisons, jurisdiction counts and journey panels
are hidden in the other lanes. No mixed result total is calculated.

Source identities, existing records, ballots, receipts, PR/base/head isolation and
all data APIs remain unchanged. Background references do not substantiate sample
claims. Metadata does not establish current law or measured outcomes; concept
cost/effect review remains outstanding. No modeled future is represented as data.

Validation: focused proposal-search and official-metadata tests pass (5 tests),
including the isolated DOM journey through all lanes, concept zero-result/reset,
empty official references, sample restoration and popstate. Typecheck passes.
Full `bun test`: 745 pass / 26 fail; server-backed failures report local
listen EADDRINUSE (including the unnamed server fixture). `bun run test:routes`
also fails at Bun.serve before route assertions with EADDRINUSE on port 0.
These required checks must pass in CI before acceptance. `git diff --check` passes. Native
browser, mobile and screen-reader review remain pending; DOM checks do not
establish human acceptance. Leave SHE-882 open for source, safety and editorial
review and acceptance by a human maintainer.

Governance defaults are unchanged: disabled/dry-run, quorum 10, 24-hour exposure,
one current-head approval, strict majority, fail-closed base/check allowlists and
active kill switch. Remote protection and production overrides were not audited.
Main requires bun test, bun run typecheck and route smoke test plus at least one
human approval. No merge, release, deployment, production data mutation or external
message was performed. Production requires a human-published tagged release.
