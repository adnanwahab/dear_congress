## Behavior and isolation

Every open game identifies the hypothetical library-editor scene as fictional.
No signup, ideological choices, rewards, API requests, storage writes, voting,
synthesis, source identities or PR revision bindings are introduced. Page-memory
letters clear on exit, skip or reload. Restart clears letters and focuses the first
square. Escape exits and returns focus to the launch button. The grid supports
native touch text input, Tab, arrows and Backspace. Hints reveal one missing or
incorrect letter. Completion is checked automatically; incomplete checks offer
hints and the explanation. All answers and the full hypothetical narrative are
available through a native details control. There is no service worker: offline
play means the already loaded page; offline initial navigation is not promised.
