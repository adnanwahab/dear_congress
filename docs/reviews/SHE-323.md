# SHE-323 — stage navigation motion

Refs: https://linear.app/shel-bernstein/issue/SHE-323/demomotion-smooth-stage-to-stage-page-transitions-with-view

Implementation candidate, November 13, 2026. Leave acceptance and issue closure to
human review. No PR, external messages, merge, release or deployment was performed.

Read AGENTS.md, readme.md and docs/launch-merge-policy.md; inspected Navigation,
App, WorkflowScreen, shared civic stages, HTML entry and browser build. Read-only
GitHub PR searches for SHE-323 and transition returned no matches. The open-PR
search returned other issue candidates; none in those results implements this motion.

CSS opts into same-origin cross-document transitions. Header and bottom bar receive
stationary named snapshots; the active navigation item receives a shared name so
its pill and contents glide to the new tab. The content/root slides left for higher
stage numbers and right for lower numbers. Other navigation crossfades. The stage
order comes from the existing shared civic stages, with /vote matching /votes.
Query strings, proposal selection and ordinary anchor navigation are preserved.

pageswap and pagereveal use NavigationActivation source/destination URLs, avoiding
stale session-storage state on reload, BFCache or unrelated navigation. Missing
transition/types/navigation APIs do nothing. Unsupported CSS falls back to normal
navigation. Stage shells render synchronously before incoming capture; asynchronous
demo data retains its existing loading state. Bun drops the HTML script's blocking
attribute, so the served build restores it on module scripts in the head.

Shared tokens in src/client/styles.css: --motion-fast (150ms), --motion-base
(260ms), --ease-out (cubic-bezier(.2,.8,.2,1)). Reuse these for demo motion.
The global reduced-motion rule disables transition snapshot animations and reduces
ordinary animations/transitions to near-zero duration, including smooth scrolling.
Implementation follows the platform lifecycle described in
[Chrome's cross-document guide](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document).
