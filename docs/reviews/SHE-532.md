## Audit and scope

Read repository AGENTS.md, readme.md, launch-merge-policy.md, existing stage-state
review SHE-294, Dashboard, WorkflowScreen, demo API types, source provenance,
and related UI tests before changes. GitHub PR search for "side quest" returned
no matches. Open-PR discovery included #187 (private civic timeline), #186
(weekly digest), #183 (evidence notebook), and #174 (daily curiosity mission).
Their descriptions are adjacent work, not acceptance evidence or foundations
copied into this change. Existing DailyQuestion and comparison UI are retained.

SideQuest reuses the selected sample identity from the existing typed DemoPayload
on Dashboard and WorkflowScreen. It introduces no endpoint, ranking service or
mutation. It offers at most one fixed editorial read for housing, food access
and medical-price samples; other samples honestly show no reviewed association.
Suggestions depend only on the selected sample ID. Vote stance, counts, profiles,
publications and model simulations are not selection inputs. There are no
completion rewards, tracking events, deadlines, auto-opening links or replacements
on dismissal. Every suggestion explains its association and limits.

Dismissed IDs and the off preference use a new, isolated browser-local key
`civic_optional_reads_v1`. Turning on does not clear dismissals. Blocked storage
keeps the preference for the mounted page and explains its lifetime. Cross-tab
live preference synchronization is not implemented; a page reload reads the
latest saved preference. Native buttons and source links have visible focus and
44px minimum targets; actions move focus to the panel heading. The layout wraps
without animation, including under reduced motion. Existing loading/error state
hides source actions; retry stays with the existing proposal-loading controls.
The off/on control is available even when loading fails.

- [CMS Hospital Price Transparency](https://www.cms.gov/priorities/key-initiatives/hospital-price-transparency):
  official hospital transparency background for reading alongside the medical
  price sample, not verification of its fictional combined-estimate clause.

The review date belongs only to these reading suggestions. Existing demo source
metadata (including null checkedAt fields), original URLs and source identities
are unchanged. Fictional clauses remain fictional; no real advisory counts or
model results are represented as evidence. Public guide and README explain the
controls and privacy boundary.
