# SHE-599 — decision boundary brush

Refs: https://linear.app/shel-bernstein/issue/SHE-599/civicplaymotion-animated-decision-boundary-brush-for-scoring-weights

Implemented locally in the existing `/synth` scoring rule sandbox. The fixture
endpoint already calculates baseline and candidate scores with `scoreAll` and
selections with `synthesizePackage`. No scoring, persistence or endpoint changes
were needed. GitHub connector searches for SHE-599 and open synthesis PRs returned
no matches; this is search evidence, not an exhaustive review of every remote PR.
Read repository README, motion documentation and launch merge policy before edits.

Each package exposes a native range and a Next score threshold button. The brush
sweeps across sorted candidate results, with ties crossing together. Thresholds
use inclusive comparisons against the actual three-decimal engine scores. The
rounding formula is shown, including the separately rounded institutional-change
penalty. Text distinguishes score highlighting from actual baseline/candidate
package inclusion: rights, budgets and stability prevent a single universal score
cutoff from explaining selection. It makes no causal weight tipping-point claim.
Changing settings clears comparison results via the existing request-generation
guard; retry remains explicit. Comparing requires the existing separate button.
No brush action requests a public submission or persists a plan.

The new typed `score-boundary` transition uses the shared motion helper, scoped
snapshot styles and scaled plan duration. Unsupported APIs/off/reduced motion
commit immediately. New input skips the previous transition; generation checks
prevent superseded callbacks from changing the brush, including after unmount.
Native chapter navigation in Navigation.tsx remains the route authority. Range
controls support keyboard and touch; text and an aria-valuetext/live status expose
thresholds without relying on the line or color. Component-local transition names
isolate package brushes.
