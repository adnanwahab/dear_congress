# SHE-909 — Source-to-ballot and source-to-simulation contract

Refs: https://linear.app/shel-bernstein/issue/SHE-909/cs-l100060-create-an-end-to-end-source-to-ballot-and-source-to

Implemented `server.source-contract.test.ts` against the real importer, HTTP router,
ballot store and snapshot builder using disposable local files. No production
source refresh, provider request or data mutation is performed.

Pre-edit audit read readme.md, AGENTS.md, legislative-metadata.md, bill-catalog.md,
launch-merge-policy.md and the existing demo, provenance, synthesis and snapshot
tests. GitHub PR search found related work #175 (shared provenance), #203
(provenance explorer), #120 and #123 (modeled behavior), #101 (source chips), and
#18 (source recovery); no SHE-909 candidate was returned. Search results and draft
PR descriptions establish overlap, not acceptance. This change reuses the local
merged contracts rather than introducing a new provenance schema.

The integration fixture archives Congress.gov-shaped metadata and reads it back
through `/api/legislation`, retaining identity, raw hash, checked time and the
metadata-only boundary even for an action mentioning public law. It loads the
repository measurement fixture through `/api/outcomes` with source, units, period,
fetched time and caveats intact. Those fixture values are not independently
verified real-world measurements. Editorial catalog IDs and official metadata IDs
are rejected by the sample ballot endpoint. One deliberate advisory choice adds
exactly one browser response; synthetic sample totals stay unchanged and verified
participation remains unavailable. Snapshot capture/replay retains package identity,
does not fabricate results or legal status, and preserves existing DB fields,
ballots, source metadata and measurements. A separate non-HTTP regression adds
100 synthetic voices and checks an unchanged real-input package and unchanged DB.

Existing `src/client/proposal-provenance.test.tsx` and its DOM helper cover Published,
Feed, Votes and Draft with sample labels, background limitations, retry behavior
and separate advisory counts. This new test connects server boundaries; it is not
a browser end-to-end assertion for every public view. Arbitrary official text or
editorial catalog drafts do not currently compile into simulator mechanisms or
ballots. Their intentional exclusion is tested, not presented as implemented
source-to-model support. Human source, editorial and safety review remain required.
