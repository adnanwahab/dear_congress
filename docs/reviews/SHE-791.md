## Audit and implementation

Reviewed this repository's AGENTS.md, readme.md, launch merge policy, sample
workflow, daily question, journey history, jurisdiction filters and existing
selection/vote regression tests. GitHub PR searches on 2026-11-16 found no
SHE-791 or “featured question” PR. The open PR list includes related navigation
work (#375 / SHE-807) and canonical proposal links (#371 / SHE-830); reconcile
these at human integration review. No PR was modified or externally posted to.

The daily question already links the correct ID and advisory-section fragment.
The workflow could instead select the first filtered item when a remembered
jurisdiction, query or topic excluded that ID. Proposal selection replaced the
current history entry, losing the previous selection.

Explicit proposal IDs now resolve against the complete sample payload. Browsing
filters continue to constrain the list; an explicitly linked item outside those
filters stays available in the selector with an explanatory notice. The same
item supplies the title, summary, draft details and advisory submission ID.
Unknown and empty explicit IDs remain unselected, retain their URL, expose a
fallback notice and never silently acquire another voting target. A deliberate
selector choice adds a history entry. Default selections acquire a proposal URL
without adding an entry or dropping the current fragment/history state.

No server, ballot persistence, receipts, source identities, repository/item scopes,
PR revision binding, authentication or voting requirements were changed.
